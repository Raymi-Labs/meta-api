# 文档域名部署

默认入口为 `https://docs.meta-api.com`；旧 `docs.meta-api.vip` 配置保留兼容。

主站镜像更新不代表独立文档站同步更新。发布时使用相同提交构建的文档静态产物（`web/docs-dist`），先发布带版本的目录，验证后切换现有 `current` 指向。不要覆盖 TLS 文件或把文档代理成完整业务站。

新增虚拟主机时使用 `docs.meta-api.com.conf`，先确认 DNS、证书路径与现有监听配置，避免重复 server_name。已有该域名虚拟主机的部署应核对差异后更新，而非再次安装一份。共享 `public-api.conf` 只允许两个公开只读端点，不发送认证头或 Cookie；续期钩子兼容两张证书。

部署后核对新旧域名深链刷新、canonical、导航及其他语言的复制示例。文档域名的账户、生成和登录入口保持拒绝；公开 status/pricing 不携带认证信息。若另外安排旧文档重定向，需要保留路径和查询参数；不要把旧模型 API 域名改成重定向。

本仓库的配置样例和构建测试不表示已经执行线上部署。
