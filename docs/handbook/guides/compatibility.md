# 兼容范围与功能边界

本页帮助从其他模型平台迁移的用户确认差异。兼容协议不是完整复制某个厂商的所有云服务；SDK 中存在的方法，也不代表本网关提供同名接口。

## 已有协议入口

文本调用包括 Chat Completions、Responses、Messages 和 Gemini 原生生成；网关也有图像生成与编辑、语音合成与识别、视频任务、Embeddings、Rerank 和 Realtime 入口。实际开放范围仍受模型、渠道和分组约束，详见[API 总览](/docs/reference/overview)。

结构化输出、函数调用、缓存、联网搜索、思考强度和多模态输入属于模型与协议的组合能力。请逐项验证，不要将参数被接收等同于上游已执行。

## 暂不能按通用服务使用的功能

| 功能 | 本站边界与替代方式 |
| --- | --- |
| Files、Uploads、Vector Stores | 不提供通用文件托管或向量数据库服务；在自己的应用保存文件并按模型支持的方式传入 |
| Assistants、Threads、Batches | 不提供完整同名生命周期；由应用维护会话、队列和批处理 |
| Fine-tuning | 不能通过兼容入口创建训练任务 |
| Responses 后台模式 | 不承诺 `background`、后台轮询、取消和结果保留；使用普通响应或应用自己的任务队列 |
| 图像 variations | 不作为已支持入口；使用模型支持的编辑接口 |
| Gemini 文件上传、缓存管理、countTokens | 不作为通用代理服务开放；生成接口与这些管理服务分开看待 |
| 统一搜索、代码执行、MCP 托管 | 工具字段不是平台托管执行环境；应用需要实现执行、权限和结果回传 |
| JSON 自动修复 | 不保证把不合法输出自动修复成业务可接受结果；应用仍须校验 |
| 自动选模与排行榜路由 | 不保证名为 `auto` 的模型或其他平台的智能路由策略；参见本站分组与渠道回退 |
| 广播与通用异步回调 | 账户通知不是任意生成任务的完成回调 |
| 3D、数字人及专有应用套餐 | 只有当前模型广场和对应接口明确开放时才能使用 |

部分历史路由可能仍在代码中，但这不能用作当前生产服务承诺。遇到未实现接口应修改集成方式，而不是重试同一个请求。

## 企业与支付差异

本站提供账户、令牌、分组和管理员管理能力；不把参考平台的团队工作区、成员角色、共享预算、工作区审计或系统密钥原样宣称为已有企业产品。企业需求请通过[企业定制](/enterprise)沟通。

付款方式以钱包页面为准，不承诺保存银行卡、自动充值或参考平台的优惠、兑换比例和活动。数据处理约定以本站[服务条款](/user-agreement)与[隐私政策](/privacy-policy)为准，不默认承诺全模型零数据保留或固定可用性 SLA。

## 迁移原则

保留应用自身的业务状态、权限和文件存储；先迁移一次最小模型调用，再逐个验证工具、流式、多模态和计费。每次只改变一个关键变量，失败时使用请求 ID 定位问题。
