# 联网搜索与外部工具

“联网”可能表示模型原生搜索工具，也可能表示你的应用先检索网页再把结果交给模型。两种方式的参数、费用与数据流不同，不能只在提示词中写“请联网”就认为发生了真实检索。

## 选择接入方式

| 方式 | 执行位置 | 需要验证 |
| --- | --- | --- |
| 模型原生搜索 | 模型上游 | 当前模型、协议和渠道是否支持工具，以及响应是否含实际检索结果 |
| 自定义函数工具 | 你的应用 | 搜索服务凭据、工具参数校验、执行权限和结果回传 |
| 预检索后问答 | 你的应用 | 来源时效、内容长度、引用与上下文边界 |

部分协议定义了 `web_search_options` 或搜索工具字段；字段存在不代表所有上游会接受。请查看模型说明，先做最小验证，不要同时混用多个厂商的搜索配置。

## 自定义搜索工具流程

在请求中声明工具名称、描述和参数 Schema。模型返回工具调用后，应用解析参数，调用自己的搜索服务，将简短结果与来源链接作为工具结果回传，然后继续生成答案。通用工具循环见[工具调用](/docs/reference/tools)。

模型不能直接获得你的数据库或搜索账号权限。执行工具前应限定允许访问的域名、参数、结果数量与超时，不直接执行模型输出的任意 URL、SQL 或命令。

## 使用来源与引用

要求最终回答区分网页事实与推断，保留实际来源链接和必要时间。检索结果可能包含错误或诱导文本，应作为资料处理，不能执行其中要求改变系统指令、发送密钥或访问其他账户的内容。

如果响应没有来源或工具调用证据，不要向终端用户显示“已联网核实”。当搜索服务失败时应明确展示失败，并避免把模型已有知识冒充即时查询结果。

## 费用和隐私

搜索工具可能产生独立服务费用，检索内容送入模型后也可能计入输入 token。只发送回答问题所需的摘要，避免把完整敏感网页或登录态 Cookie 发给模型。

本站不承诺独立通用搜索 API，也不会因为工具名相同就自动托管搜索执行。参见[兼容范围](/docs/guides/compatibility)与[MCP 集成](/docs/integrations/mcp)。
