# 账户登录与安全设置

在[个人设置](https://meta-api.vip/console/personal)的“账户管理”中核对邮箱、第三方绑定和安全设置。登录方式是否可用取决于站点是否启用以及账号绑定状态；不要因为其他网站支持某种登录方式，就认为本站一定已开放。更换登录方式前，应先确认自己仍有一种可用的登录或恢复方式。

## 绑定与密码

“账户绑定”展示邮箱和已开放的第三方登录入口。绑定时确认跳转页面的服务名称与当前账号，完成后返回核对状态。邮箱用于验证、恢复或接收通知时应保持可访问；通知配置中的独立收件邮箱不会自动改变登录绑定邮箱。

通过“修改密码”按提示填写原密码、新密码和确认密码。不同服务使用不同密码，并用密码管理器保存。第三方登录用户如需设置密码，应按当前页面提示完成，不要假定原第三方账号密码可以在本站直接使用。

## 启用两步验证

1. 在“安全设置”打开“两步验证设置”，按提示开始配置。
2. 用可信验证器扫描二维码或输入密钥，输入当前验证码完成启用。
3. 将备用码保存在与日常设备分开的安全位置；不要截图发给他人。
4. 验证器不可用时按登录页面提示使用备用码。重新生成备用码后，以新保存的列表为准。

验证码连续错误时检查设备时间和所选账户；不要通过关闭安全功能来处理未知登录风险。禁用两步验证会删除验证设置和备用码，应先确认已有可用的替代保护。

## Passkey 与两类令牌

| 功能         | 用途与注意事项                                               |
| ------------ | ------------------------------------------------------------ |
| Passkey      | 在站点启用且设备支持时注册，用设备或密码管理器完成免密验证   |
| 两步验证     | 为密码登录及需要验证的敏感操作增加验证步骤                   |
| 系统访问令牌 | 用于允许的站点管理接口；重新生成后需更新使用旧令牌的管理工具 |
| 模型 API Key | 在令牌管理创建，供模型接口调用，可独立设置额度与访问限制     |

Passkey 的注册、解绑可能要求已有两步验证或 Passkey 验证，按页面提示完成。不要把“系统访问令牌”填入模型客户端，也不要将两类令牌、Cookie、验证码、备用码或 Passkey 恢复资料发送给客服。

怀疑凭证泄漏时，先停用相关模型 Key，修改受影响的登录凭证并检查[使用日志](/docs/account/request-logs)。管理访问令牌泄漏应重新生成并更新对应工具。无法登录时保留账号标识与错误提示，通过站点恢复或支持流程处理，避免反复尝试未知凭证。
