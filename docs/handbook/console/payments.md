# 充值、兑换码与支付状态

在[钱包管理](https://meta-api.vip/console/topup)中查看余额，并从页面当前开放的方式充值。可用支付方式、可选额度、最低金额和优惠会随站点配置变化，以提交前的报价和收银台为准。支付图标或服务商名称不代表所有银行卡、地区或币种都可使用。

## 完成一次在线充值

1. 确认登录账号，选择充值额度并查看预计到账额度与实际支付金额。
2. 选择页面提供的支付方式，核对订单确认信息后进入收银台。
3. 在收银台确认商户、订单号、币种和金额，再完成付款。
4. 返回钱包管理，打开“支付记录”，刷新核对订单状态及余额。

付款页面返回成功并不总是表示平台已经入账；请以支付记录和余额为准。本站目前没有已确认的银行卡托管自动充值流程，不要把一次银行卡支付理解为已绑定卡片、余额不足自动扣款或已开启自动续费。

## 订单状态怎么处理

| 状态   | 建议操作                                               |
| ------ | ------------------------------------------------------ |
| 待支付 | 未确认入账；已付款则先刷新核对，不要为同一问题反复付款 |
| 成功   | 查看完成时间与到账情况，再核对账户是否正确             |
| 已过期 | 不继续向旧订单付款，按页面提示重新创建订单             |
| 已取消 | 查看订单说明，需要充值时创建新的有效订单               |

使用数字资产支付时，只选择当前收银台明确支持的资产与网络。订单标价币种、收银台结算币种和实际转账数量可能不同，应严格核对当次订单的地址、网络、金额及有效期，不复用旧地址或从历史截图付款。

## 使用兑换码

在“兑换码充值”输入兑换码并提交，然后检查兑换结果与余额或所发放权益。兑换码不是模型 API Key，不应放进客户端认证配置。页面若允许“创建兑换码”，其来源是可转赠额度，不能把所有余额、奖励或已领取额度都视为可再次转赠。兑换失败先核对输入与使用状态，不向他人发送仍可使用的完整兑换码。

## 已付款却未到账

先核对支付记录中的订单号、账号、状态和时间，保留支付平台交易号与脱敏凭证。不要仅凭银行扣款截图推断平台完成结算，也不要重复支付期待覆盖旧订单。将这些信息交给站内支持核查，到账、退款或异常处理以实际订单结果为准。

发票入口与资金记录说明见[消费、账单与发票](/docs/account/billing)；避免余额不足中断调用，可配置[账户通知](/docs/account/notifications)。
