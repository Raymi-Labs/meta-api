# 控制台入门

[元衡控制台](https://meta-api.vip/console)用于管理自己的模型调用、令牌、余额与账户设置。顶部导航连接模型广场、模型体验、企业定制和文档；点击左上角标志返回主站首页。首次使用建议先完成一次小请求，再根据日志配置额度和提醒，避免一次接入多个工具后难以定位问题。

## 第一次进入控制台

1. 登录后确认右上角显示的是自己的账号，进入“个人设置”核对邮箱与安全设置。
2. 打开“令牌管理”，为当前应用创建一把独立 API Key。名称写清应用和环境，选择账号可用的分组。
3. 在模型广场确认模型 ID 和支持的接口，按[API 总览](/docs/reference/overview)或[客户端接入](/docs/clients)配置。
4. 发起一次简短调用，回到“使用日志”核对模型、实际分组、消耗和 Request ID。
5. 在“通知配置”设置额度预警，在“钱包管理”查看余额和支付记录。

## 主要入口怎么用

| 入口         | 适合处理的事情                                 |
| ------------ | ---------------------------------------------- |
| 数据看板     | 查看账户累计数据和指定时间范围的用量趋势       |
| 令牌管理     | 创建、限制、测试、停用或删除模型调用 Key       |
| 使用日志     | 按时间、令牌、模型、分组或 Request ID 定位请求 |
| 钱包管理     | 查看余额、充值、兑换码、支付记录和发票         |
| 个人设置     | 管理登录方式、安全验证、通知与显示偏好         |
| 顶部通知铃铛 | 阅读平台公告和服务调整信息                     |

普通用户查看自己的数据；渠道、用户、系统设置等管理入口需要相应权限。截图里的管理菜单不代表每个账号都会显示。部分入口也可能受站点配置或个人侧边栏设置影响，隐藏入口不会扩大或取消账户权限。

## 页面和数据排查

左侧菜单内容较长时，在菜单区域上下滚动即可找到下方入口，也可收起侧边栏增加工作区宽度。窄屏使用菜单按钮展开导航。文档站右上角可选择语言，切换后应同时检查导航和正文是否更新。

遇到空图表，先核对时间范围和账号；“暂无信息”也可能表示管理员尚未配置该面板。余额、累计消耗与当前区间统计不是同一口径，不应直接相减判断计费异常。刷新仍失败时记录页面、时间和错误文本，再按[错误排查](/docs/troubleshooting)处理。
