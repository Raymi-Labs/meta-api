## 采购限制与缓存

复用[原厂限价](openrouter-price-routing.md)：price 排序、允许限价内回退、审核后的服务商名单、标准服务等级、输入/输出硬上限；地区、加速和其他未审核端点不进入候选。未知模型、跨模型回退、收费搜索、非 function 托管工具拒绝，全局和渠道请求体透传关闭，出站 plugins 为空。特殊入口和新增模型不自动同步启用。

长上下文仍保守使用标准档输入/输出硬限价，可能因无满足预算的端点而拒绝，不自动放宽。缓存报价只按本次端点快照核实，没有上游独立的动态缓存 max_price，不承诺未来涨价实时拦截。

[官方缓存说明](https://developers.openai.com/api/docs/guides/prompt-caching)规定新一代型号默认 30m 写入按普通输入 1.25 倍收费。真实上游返回 6022 输入、6019 写入、5 输出；旧程序丢失 cache_write_tokens，已作为必要计费修复处理。此渠道只审核默认 30m；顶层参数与内容块 breakpoint 内扩展 TTL 均拒绝，不借用 Claude 的 1h 计量表示 OpenAI 12h。
