# MiniMax H3 文生视频接入

## 当前范围

通过现有 MiniMax 渠道接入官方兼容的 H3 V2 文生视频接口。支持准确模型名 `MiniMax-H3`、`MiniMax-H3-Highspeed`、`MiniMax-H3-Lite`、`MiniMax-H3-Max`；请求别名可通过渠道模型映射关联。模型权限、令牌分组、渠道鉴权与原视频任务接口一致。

第三方必须提供相同的 V2 提交/查询协议；仅 OpenAI 兼容的第三方应使用其匹配适配器，不因模型同名自动切换渠道类型。本地模拟测试不证明真实账户权限、上游在线可用性或成本。

首期只支持文生视频。不接收图片、音视频参考、回调、自定义 extra 或未声明参数，避免静默丢字段和少收素材费用。旧 Hailuo 型号仍用原 V1 适配器。

## 参数

| 模型 | 时长（整数秒） | 分辨率 |
| --- | --- | --- |
| MiniMax-H3 | 4–15 | 768P、2K |
| MiniMax-H3-Highspeed | 4–15 | 768P |
| MiniMax-H3-Lite | 4–15 | 480P、768P |
| MiniMax-H3-Max | 5–15 | 480P、768P |

使用 `prompt` 或仅含一个 text 项的 `content`；两者同时存在必须相同。必须明确填写 `duration`、`resolution`、`ratio`，无收费参数默认值。ratio 支持 `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`，不支持 adaptive。

兼容 `seconds`（整数或整数字符串）、`size`（明确的 480P/768P/2K 档位）、`aspect_ratio` 别名。metadata 只允许这些参数；冲突直接返回 400，不能覆盖 model 或提示词。规范后的请求快照既用于计价，也用于出站；原始请求不被修改，重试重新规范化。

## 本站定价

H3 必须为用户请求的模型名明确配置按次价格或表达式；不使用通用默认价格。后台选择 H3 → “视频按秒 / 表达式”，按各分辨率填入 **USD/请求输出秒**，点击“生成秒价表达式”，核对后再“应用更改”。生成模板不会保存或发生成请求，已存在的请求倍率规则保留。切换模型不会携带模板输入。

该入口是现有表达式引擎的秒价模板，不是新的后端计费模式；重新打开可见保存后的完整表达式，模板输入框本身不反解任意旧表达式。别名模型仍可在高级表达式中按规范后的字段设置，模板仅对已知 H3 名称显示。

模板生成公式：`每秒售价 × duration × 分组适用倍率 × 时间倍率`。输入价格不预乘倍率。系统引擎内部以百万单位表示金额，模板负责换算，不能直接把 USD/秒当作 Token 单价输入。

配置校验会用空请求预览；模板的 `configuration_preview` 分支只为该预览返回 0。正式 H3 请求在计价之前强制验证时长和分辨率，缺参数不能走免费兜底。不要把此模板用于未经参数验证的其他模型/协议。

按提交的规范参数收费，不按完成结果的实际时长补差额；V2 usage 内的换算 Token 不作为文本 Token 再次收费。退款及终态处理复用既有钱包/订阅/令牌资金源和 CAS；重复终态不重复退款。原有 CAS 与资金调整非崩溃原子事务的限制不由本次解决。

## 调用方式

以下仅是请求体示例，不代表已执行测试。向本站 `POST /v1/videos` 或 `POST /v1/video/generations` 提交：

```json
{
  "model": "MiniMax-H3",
  "prompt": "A peaceful shoreline at sunset, gentle waves",
  "duration": 5,
  "resolution": "768P",
  "ratio": "16:9"
}
```

返回本站公开任务 ID。随后 `GET /v1/videos/{本站任务ID}` 或对应 generations 查询入口；输出使用本站任务 ID 和视频结果地址，不暴露上游任务 ID/密钥。查询沿用提交时保存的密钥和映射后型号，即使渠道轮换 Key 或修改映射也不更换该任务协议。成功必须有有效视频 URL；查询异常保留上次状态，不当作成功或业务失败退款。

## 免费检查与真实验收

H3 开始提交后不自动重发，即使遇到 429、5xx 或响应解析失败；上游是否已受理可能不确定，需核对供应商任务/费用再决定手动重试。本站错误退款不代表上游一定未产生费用。

H3 的“本地估价”填写与正式请求相同的完整参数（含 prompt 或文本 content、duration、resolution、ratio），复用同一规范化规则，别名与 metadata 冲突会拒绝。估价不生成视频、不预扣额度。

H3 系列的渠道测试、批量测试与令牌测试只走既有本地预检，不生成视频。该检查不证明模型、参数、密钥或实际生成可用；真实验收需另外确认上游文档、参数、售价与预算。未实现上游取消接口，不应把本地 `cancelled` 状态解析理解为可从元衡取消正在生成的任务。

参考资料（2026-10-26）：MiniMax 官方文档 `https://platform.minimax.io/docs/api-reference/video-generation-v2-create` 与 `https://platform.minimax.io/docs/api-reference/video-generation-v2-query`。
