# 视频模型的低成本检查

在 **渠道管理 → 模型测试 → 检查配置** 打开视频检查窗口。私有模型名称未被识别时，端点选择 **视频（仅本地配置检查）**。视频家族识别只控制测试方式，不表示已经支持该厂商的全部模型。

- **检查配置与最近记录**：检查本站配置并查看已有任务摘要，不提交视频任务、不产生生成费用。
- **本地估价（不生成）**：选择该渠道分组，填写计划请求的 JSON 参数，例如实际模型支持的 `duration`、`resolution`。后台按现有任务定价表达式、当前管理员账户分组优惠和时段倍率计算。没有可计算表达式时明确提示，不套用默认价格。
- **令牌管理 → 测试**：视频模型同样进行本地预检，只允许本人令牌及其当前允许的模型/分组，并且只返回本人历史摘要。

预检通过表示配置项通过本地检查，不证明上游密钥有效、模型有权限或参数合法。历史记录没有当前配置校验，一律作为参考；每次最多扫描 200 条可见任务，展示同名模型最近 10 条。

本站估价使用 USD 标注，是参考金额，不是提交或扣费授权，也不是供应商成本。正式请求还可能经过适配器默认值和参数转换；请使用具体模型文档的实际参数，不统一使用 1 秒/480p。本站价格为零不能保证上游免费。

批量检查和自动巡检不会为视频生成付费任务，也不会因为预检通过而启用渠道、更新响应时间或清除待禁用状态。真实验收继续使用正式视频 API；检查页面不提供付费生成入口。
