## 多语言与同步

内置审核的四型号17语言介绍，无运行时翻译费用。旧人工译文只有与审计原句精确一致才替换，其他人工内容保留。修改原文改变翻译hash，旧自动翻译缓存保留但不用于新原文；审核译文优先于自动缓存。即便查缓存失败也先完成安全原文/审核译文投影。

数据库初始化事务清理历史原文/匹配人工覆盖/厂商说明；同步快照仅释放匹配旧介绍的自动所有权与字段来源，Provider、Source和未知字段保留供管理审计。导入和公开输出共享规范函数，重复同步与重启不能恢复同类模板。MySQL/PostgreSQL批次读取加行锁，防止整理期间覆盖同条记录的并发人工编辑；SQLite使用事务写入冲突语义。

## 升级验收

生产必须先备份，再走受保护更新入口。升级后核对匿名及普通用户pricing、模型卡片/详情、管理端多语言介绍与厂商说明，确认17语言无旧提供商占位句；逐项比较分组说明和倍率不变。代码合并与测试通过不代表生产已执行整理。

不是任意自由文本的自动保密系统：新增供应商自由描述、不同语言新模板仍需审阅。回滚原始资料依赖升级前数据库备份，不通过篡改历史账单或路由恢复。无数据库schema变更。
