# 邀请档位与周期返佣

在管理控制台的运营设置中打开“邀请档位与结算”。默认关闭；启用前为部署配置稳定的 `CRYPTO_SECRET` 或 `SESSION_SECRET`，备份数据库和密钥。修改配置会验证所有一级、二级、奖金与部长位组合不得超池；比例填写小数，例如 5% 填 `0.05`。

## 用户流程

钱包邀请卡显示当前档位、一级比例、本月达标人数和最低提现额。点击邀请人数打开“周期账单与明细”，可查看应发、实发、欠款抵扣、池调节、排除基数及预计发放时间，历史汇总继续保留。

普通、晋级 A/B 使用北京时间自然月，周期结束三天后出账和发放。专员、成员、部长使用周一开始的 ISO 周，结束三天后出账、七天后发放。所有支付均至少观察七天；冻结、未通过要求的实名审核或账单冻结会延后发放。异议截止为出账后十五天，可通过已有工单入口提出异议。

“推广者申请与实名”可申请专员、加入部门或部长，提交姓名和证件、申请改绑以及确认他人改绑。B 档以上可申请成员。成员签约永久切断上游，主动退出次月生效；三十天没有新增成功邀请会移出部门，退出后按专员一级比例处理，上游不恢复。

专员及以上每周可申请一次提前发放，仅涉及申请前已出账、已过观察期且未发放的记录。管理员审核时再次检查当前档位、冻结和欠款。提前发放不免除后续退款追偿。

划转与提现是不同操作：划转钱包沿用原最低额度；提现最低人民币金额按当前档位决定。未结欠款先从后续返佣抵扣，退款不足不会把新台账收款人的钱包扣成负数。已划转返佣额度会从本人后续充值的可返佣基数中累计排除，明细可查看排除额。

## 管理流程

运营设置中的账单、晋级与部门申请、提前发放审核、实名审核、风险线索和处置记录支持分页。管理员可冻结账单/推广者、覆盖档位（含到期时间）、扣回收益或清退。撤销按同一用户未撤销处置的逆序进行，避免覆盖后续处置；关系恢复遇到已改绑或成环时不会强行重写。

实名审核只展示脱敏姓名和证件。超级管理员填写查看原因后可临时查看原文，系统记录查看者和原因；不要把原文复制到备注、日志或工单。没有配置“发放要求实名”时允许未实名发放，默认不强制实名。

集中注册风险仅建单，**由管理员判断并冻结**。检测组合为三日内相同 IPv4 /24 或 IPv6 /64 网段、相同充值金额；它不代表已证实违规。设备标识是浏览器本地随机值，可被清除，不能保证识别同一物理设备；服务端仅保留 HMAC。同实名、同设备或可取得的同付款主体的第二个账号会跳过返佣并记录风险。未提供付款主体的渠道没有该项信号。

## 迁移与回退

- 历史邀请不补发注册奖励，启用前注册的下级不计入新晋级人数。已存在台账不迁移收款人。
- 新启用时间只写一次，关闭再开启不会重置历史边界。旧 pending 按原规则结算，新版本台账按周期快照结算。
- `enabled=false` 让新支付回到旧返佣路径；已有周期账单、冻结、欠款和补足仍保留。停用不会解冻资金。
- 迁移替换旧两列台账唯一索引为三列索引，金额使用 bigint。发现重复记录时不自动删账，需人工核对。
- 月度超池只调整未发放记录，差额按时间顺序进入下一周期补足；付款撤销同时撤销关联补足。任务重启会补扫遗漏月份。
- 应用发布不自动部署生产。生产更新仍使用 `scripts/newapi-release` 提供的受保护入口，并在相同数据库引擎上预检。

接口：用户 `/api/invite/*`，管理员 `/api/admin/invite/*`，原文查看另需 Root。用户查询不会接受其他用户 ID 来扩大数据范围。日期固定北京时间，不随服务器系统时区改变。
