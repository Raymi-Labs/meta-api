# Agent Note: 看板独立指标覆盖范围

Status: implemented

## Problem

全站统计中少量缓存语义不明确的日志会令缓存率和综合单价同时消失。普通用户范围内没有这些记录时正常，说明全局保护错误扩大了不确定性的影响。长 Token 数字还会断开最后一位。

## Decision

沿用统一日志快照、认证范围、精确时间、金额和请求总数。两个派生指标独立筛选：缓存率需可信且大于零的输入分母；单价需可信总 Token 与 Token 计费金额，零用量正费用排除；明确的 Token 退款只进入单价金额不影响缓存率。每项暴露纳入/排除记录数，覆盖率仅为记录比例。无可计算分母才显示破折号。旧统计缓存更换命名空间，旧响应缺覆盖字段时前端不伪装已核实。

大 Token 使用语言感知紧凑格式，卡片 tooltip/可访问说明保留完整数值；指标卡可见标注部分统计。金额与请求数不因指标排除而消失。

## Existing notes audit

[统一结算日志](../../implemented/bug-fix/2026-11-03-dashboard-settlement-statistics.md)保留扫描边界、时段、权限与结算规则；本篇替代其全局隐藏决策，两个笔记互链。五卡布局与日志解析入口已有，不另建查询、不按模型名猜测缓存含义。

## Alternatives considered

- 移除未知保护能立刻恢复数字，但会把缺语义缓存和零 Token 收费混入分母，不采用。
- 继续全站隐藏最保守，但一个账号影响全部用户，不能满足管理员查看可核实部分的需求。
- 采用独立可核实子集和明确记录覆盖率，保留不确定性又提供可用指标；不把子集结果声称为完整站点单价。

## Verification

后端隔离测试及 race 验证混合可信/未知、全部未知、零输入有输出、零 Token 正费用、按次、退款、inclusive/non_cache、覆盖计数守恒、金额不变、权限与扫描边界。前端回归验证覆盖字段、紧凑数值、旧响应拒绝，沿用普通用户/管理员、迟到响应和宽窄屏隔离浏览器脚本；请求全部模拟，不调用生产或付费模型。

## Consequences

覆盖率以记录数计算，不代表金额或 Token 比重。已删除日志与语义缺失不能恢复；总 Token 延续既有展示回退，部分口径时明确限制。生产只读样本不替代上游验证。本轮仅代码发布，用户自行部署。

缓存率候选只包含已识别 Token 计费的请求，单价候选包含已识别 Token 计费的结算事件（包括明确的退款）；非 Token 与未知计费类型不在候选分母，卡片提示明确范围。损坏 JSON、负用量和越界数值仍按既有规则失败，不静默吞掉。缓存 namespace 升为 v2，旧响应缺少覆盖字段时前端拒绝，不跨版本复用未知子集。大 Token 数值仅展示压缩，原值和后台计算不改变。

缓存候选范围由[模型测试排除](2026-11-04-cache-rate-exclude-model-tests.md)进一步收窄；测试不计入缓存覆盖率的纳入或异常排除数，综合单价与总量仍沿用本篇规则。
