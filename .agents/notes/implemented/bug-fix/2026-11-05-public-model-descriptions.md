# Agent Note: 公开模型介绍去除接入来源模板，分组文案保持不变

Status: implemented

## Problem

公开pricing中四个Claude/Gemini型号的原文和17语言译文带venice/qihang-ai/vivgrid提供商介绍，43条厂商说明为“通过 OpenRouter 接入”。社区目录提供者不等于模型作者，更不能证明实际调用渠道。用户要求修复这些公开文案和同步复发，但明确排除分组说明，所有分组名称、备注、权限和价格保持原样。

## Decision

2026-11-06 补充：ember-1及其fireworks/ember-1命名空间描述中，实际hostname为openrouter.ai的Markdown链接转为原标签文字；其他正文、作者、域名及模型不变。精确ember-1补充现有17语言清理版本，复用原文hash/人工覆盖/缓存/启动迁移与再同步边界；只修正紧邻链接的旧译文重复右括号。

复用现有模型介绍/译文缓存/同步所有权，不新增翻译服务。四型号按精确ID和已确认提供商模板换成审核后的作者介绍，内置17语言译文，保留Sonnet/Haiku型号不翻译。其他模型仅精确匹配完整英文提供商占位句时移除提供方子句，不全局删品牌。已有手工译文仅匹配本次公开审计的旧原句才替换；其他人工文本不动。原文变更使用新hash，旧缓存不再命中；公开填充在查库失败前也提供内置译文，缓存和手工旧译文精确清洗后返回。

厂商仅完整匹配既有OpenRouter接入模板时换成作者系列说明，模板无厂商例外，真实厂商名称及正常协议说明不做全局删词。模型CRUD/两种同步入口和厂商写入共用规范函数，公开pricing/模型元数据读取再做防御投影。启动事务对历史模型原文/匹配译文、厂商说明持久化；同步快照只清除与旧原文相等的owned description及该字段旧来源归属，让审核文案不再被导入源持有，保留Provider/Source及未知字段。部署备份保留完整原始数据。无分组设置、价格、模型名、权限或路由更改。

## Alternatives considered

- 仅中文前端隐藏：API、外语和再次同步仍暴露，不能解决。
- 按品牌词全局删除：会删真实作者、厂商/协议文档和人工内容，不采用。
- 只改后台四条：手工翻译覆盖、共享缓存与周期同步可能再次带入；需要共同边界。
- 重建公共资料审核系统：可控性更广，但本轮确定模板和既有字段足以修复，不新增无关设置。

活跃笔记：模型介绍全语言、能力同步/官方默认部分重叠，保留人工优先与来源审计规则；厂商归并仅统一身份，本篇调整说明；首页展示稿未提交，独立工作树隔离；分组公开说明提议按用户最新指令不实施。
