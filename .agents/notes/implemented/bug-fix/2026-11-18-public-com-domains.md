# Agent Note: 公开文档统一 com 域名

Status: implemented

## Problem

新主站及文档域名已经可访问，但教程、导航、规范地址和动态示例仍混用旧域名，用户复制得到不同入口。

## Decision

公开主站默认使用 meta-api.com，文档使用 docs.meta-api.com。复用首页地址规范化与文档链接逻辑，只规范已知 HTTPS 根地址；保留自部署路径、端口、旧 API 线路及登录兼容。教程正文与动态样例同时更新。旧文档链接的语言处理兼容两域，导航转向新域。下载 CDN 与真实部署证书不机械替换。

## Alternatives considered

- 全局替换最省维护，但会破坏兼容白名单、已部署证书及历史记录，拒绝。
- 只改正文变更更小，但导航、canonical 和后台返回旧地址会继续产生旧链接，不能解决完整用户流程。

## Verification

80项相关回归通过，覆盖新旧教程深链、语言参数、代码样例、自部署域名、带路径和端口地址、相似恶意域名、无凭据公开API、旧下载地址与私有查询参数。手册索引、独立文档构建和主站构建通过；主站显式跳过浏览器预渲染，未做生产DNS/TLS配置验收。无收费调用或生产部署。

## Consequences

合并代码不代表文档静态站已重新发布。旧站 TLS 和重定向需独立部署验收；外部客户端仓库与已安装 Skill 不由本次强制迁移。

正文、SEO与默认链接统一降低新用户误配风险，兼容白名单仍保留旧域名，因此仓库中存在 vip 字符串不再意味着迁移遗漏。新版视频Skill本来已默认com，不重打包无关技能；下载CDN仍用已配置的download.meta-api.vip。
