# Agent Note: 故障回退预算与低流量健康证据闭环

Status: implemented

## Problem

生产 RetryTimes=5 仍在 Gemini 响应头超时后最多尝试两路；Claude 上游明确转换拒绝被当作普通400终止。健康快照不足10次提前返回，使突发失败规则失效，失败历史过期后重新放行；模型测试仅进入分组展示统计。

## Decision

复用授权分组顺序、正文交付保护、现有测试调度和逐渠道健康表。安全的响应头超时按实际已尝试次数限制为 RetryTimes+1，包含先前其他失败，不重置跨组实际预算。仅明确来自上游的 Claude 转换拒绝允许安全回退，思考参数错误仍需保留严格匹配且不修改客户参数。Responses、状态引用、服务端工具、透传和已输出继续拒绝重放。

健康以渠道+精确模型为单位；短期突发判定独立，24小时真实调用聚合作为低样本历史，测试单独标记并只记实测模型，不把同渠道其他型号或展示补样作为直接成功。近期失败优先；恢复须近期真实成功或多次通过测试，旧历史保留且不被测试刷成功率。5分钟内连续3次失败或独立突发规则会避开该路；24小时内至少3次失败且成功率低于阈值时，低流量不会因15分钟静默直接恢复。

模型测试证据默认保留5分钟；开启自动测试时覆盖两个配置周期加1分钟余量，最短5分钟、最长24小时。近期有效测试任一失败优先，两次成功且无近期真实失败才能解除历史低样本故障；真实15分钟充分失败证据不会被测试覆盖。过期测试不能永久保持恢复。不新增调度或额外供应商调用。

24小时历史在后台以SQL按渠道/模型聚合，不在请求路径查库；测试窗口查询只影响后台快照，真实短/长窗口继续为5/15分钟。后台仍15秒刷新；上线前对生产已有表做等价24小时聚合只读采样，390个渠道/型号聚合耗时约249毫秒（单次观测，不是容量压测），长历史查询增加数据库成本；保留原快照失败与过期降级策略。

## Existing capabilities and audit

- [有序健康选路](../../implemented/feature/2026-11-07-ordered-health-routing.md)：部分替代其短窗口不足10次一律未知的判定，保留顺序、权限、优先级和探测。
- [测试展示补充](../../implemented/bug-fix/2026-10-31-uptime-channel-probe-history.md)：保留原展示契约；新的路由证据只认精确实测模型。
- [响应头切换](2026-11-15-header-timeout-failover.md)：部分替代一次切换的预算，保留安全重放边界。
- [保活与诊断](../../implemented/bug-fix/2026-11-18-stream-wait-continuity.md)：保留写入保护，心跳不是有效输出。
- 现有 header timeout、upstream capability、route insight/controller测试与健康API均复用；不修改客户令牌、不新增付费定时探测。

## Alternatives considered

仅增加RetryTimes不能突破独立超时上限与不可重试分类。直接使用24小时整组成功率会掩盖突发故障及型号差异；直接混入展示测试会用其他型号成功误恢复故障型号。放开所有400会重试真实参数错误；采用窄匹配与未输出保护。

## Verification

完整Go测试、关键回退与健康逻辑race测试通过；HTTP回归覆盖第三/第五渠道成功、进入enterprise组并按该组记录消费、RetryTimes=5最多6次实际尝试、连续超时及后续500、Claude明确拒绝和心跳后切换。固定渠道、白名单、关闭重试、有效输出/取消/状态引用继续禁止相应重放；普通400不扩大重试。只结算成功一次，全部失败退款。

SQLite、MySQL8.0、PostgreSQL16真实实例验证旧表新增probe默认false、按来源分离及历史聚合；已有跨副本持久化回归通过；迁移用例接入现有数据库CI矩阵，覆盖MySQL5.7/8.0及PostgreSQL9.6。路由迁移用例经过应用DSN选择器，PostgreSQL测试连接必须使用postgres://格式；企业用例直接打开driver的key=value格式不能照搬。首次远端矩阵因CI连接格式错误失败，修正工作流后重新检查，不改已有应用标签。精确型号测试记录OriginModelName，避免上游映射别名和同渠道未测试型号污染；测试窗口不纳入真实成功率。自动测试30分钟间隔回归覆盖两次成功相隔30分钟仍能恢复，以及证据过期重新采用历史判断。

前端Bun生产构建、语言资源检查通过；本地Chromium默认路径不存在，预渲染按原流程跳过，不代表浏览器实测。新增测试列复用已有翻译；目标文件既有header规则违规，本次仅关闭该规则执行其余ESLint检查。发布策略、29项发布工具测试通过；笔记结构由make verify-notes核验。生产只读调查不代表部署后成功率，需受保护升级后复核实际调用。

## Consequences

更多超时尝试延长最坏等待并可能增加供应商成本；按实际授权组计费。新增probe列兼容旧行默认false；历史测试不伪造回填。发布不等于生产部署。
