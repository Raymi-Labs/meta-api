# Agent Note: 分组健康跟随模型广场筛选

Status: implemented

## Problem

模型广场选择供应商后，filteredModels 已缩小，但分组健康汇总忽略模型集合，继续显示所有可用分组。有调用样本的其他供应商分组也不能作为当前筛选的匹配依据。

## Decision

复用模型列表筛选后的模型与 enable_groups，在供应商、标签、计费、端点或搜索条件有效时，仅展示匹配模型关联且当前用户可用的分组。分组名称不用于猜测供应商，共享分组保留；零匹配显示已有空态。

保持未筛选汇总的故障组可见性。具体模型查询仍可展示该模型已有调用记录的故障组。汇总数据沿用后端整组统计，不在前端平均指标，也不冒充供应商统计；保留整组口径提示。健康模型下拉框复用相同的 filteredModels。

## Alternatives considered

- 按分组名匹配供应商：改动直接，但无法处理共享分组和自定义命名，采用 enable_groups 关系。
- 新增按供应商聚合的后端接口：可计算供应商专属指标，但会改变现有整组口径及缓存契约；本次修复可见卡片筛选，沿用已标明的整组指标，具体模型统计继续使用已有接口。
- 始终限制在当前模型启用组：无需判断筛选状态，但未筛选时会隐藏全部渠道停用后的故障组，因此仅在模型筛选有效时收窄汇总。

## Consequences

筛选汇总仅根据当前可用模型关联显示分组，不能展示已从定价目录移除模型的供应商归属。未筛选概览保留这些故障组；共享组指标仍是整组指标。
