# Agent Note: 模型对比与详情价格显示口径一致

Status: implemented

## Problem

用户截图中 Haiku 对比卡标记 standard、输入为 $0.6600，详情同组 standard 为 ¥0.1320、long_context 为 ¥0.6600。公开 pricing 表达式首档输入为 3.30、分组倍率为 0.2；对比页强制基础 USD，详情另经充值/套餐倍率换算。首档选择正确，但入口切换丢失显示口径造成混淆。

## Decision

对比页复用详情默认价格模式及导航显示偏好、共享设置组件及格式化函数。详情普通/固定栏进入对比、添加移除模型、返回详情保留白名单显示设置，价格重新获取。卡片、价格表及估算使用同一币种；K/M切换不改变月费用。保留首档标签和原始表达式，不调整计费配置。

## Existing notes audit

- [跨模型对比](../../implemented/feature/2026-10-31-model-detail-sticky-compare.md)：部分取代强制 USD/M 显示决定；权限、动态不估算和链接只带模型 ID 继续有效。
- [分组阶梯价格表](../../implemented/feature/2026-11-01-group-tier-comparison-table.md)：复用逐档计算，不改变标准/长上下文系数。
- [缓存价格](../../implemented/bug-fix/2026-10-28-catalog-cache-prices.md)、模型目录/详情和分组折扣：保留共享计算与币种转换。
- 官方同步、视频/图片计费、体验工作区和健康展示不受影响。

## Alternatives considered

- 改标签为 long_context：表面吻合数值，但公开表达式证明取的确实是首档，会造成错误标签。
- 保留固定 USD 并加说明：改动小，但仍改变用户在详情的选择；采用统一模式及共享控件。

## Verification

- 截图表达式与分组倍率下，充值倍率0.2显示 standard ¥0.1320/¥0.6600/¥0.0132；基础模式显示 $0.6600/$3.3000/$0.0660。
- 覆盖套餐、自定义货币、K/M、时间及零倍率、无权限分组；估算同币种且K/M不改总额。
- Chrome 真实项目壳使用模拟接口验证截图表达式、详情普通/固定栏进入对比及往返、添加移除、设置切换、390px暗色；卡片与表格同价，K/M往返保持，零费用和不可用分组通过。
- 28项相关函数/真实组件测试、ESLint、完整前端构建（含语言资源、生图子应用、五页Chrome预渲染）通过。相关笔记、功能地图及发布说明随代码提交。
- 公开 API 仅只读核对表达式及分组倍率；未调用付费上游或部署生产。

## Consequences

共享链接不包含个人套餐偏好，新会话使用相同默认设置。套餐异步加载沿用现有充值价回退。发布与生产部署分开。
