# Agent Note: 媒体Skill按接口格式保留用户参数

Status: implemented

## Problem

视频固定实测档位与模型白名单、GIF已测型号/尺寸限制将未实测误判成不可调用。Gemini参考图尚未编码，删除检查仍会丢失输入。用户要求正常提交，由接口决定真实能力，保留Veo退役决定。

## Decision

实测记录只作证据，不作客户端模型能力门禁。视频保留协议映射与默认值，增加显式协议选择，未知型号默认统一OpenAI视频接口；任意格式有效的时长、分辨率、比例及参考图传递，Veo新提交继续拒绝。图片增加显式Images/Gemini路由，原生Gemini编码参考图；GIF保留默认但新增帧数/间隔，显式型号、尺寸和质量不覆盖。安全边界、单次POST、原任务恢复、资源上限及真实文件检查保持。原生协议没有对应字段时明确格式冲突，不能悄悄丢弃或伪造语义。

## Alternatives considered

- 仅删raise最快，但参考图/未知比例会丢失或被改成720p；增加实际参数构造。
- 尝试失败后换协议可能重复扣费；协议必须提交前确定，不自动回退。
- 关闭资源和凭据限制没有助于模型兼容，保留本地保护。

## Testing

独立视频43项、安装视频47项、图片127项（一个Windows条件跳过）本地测试通过，覆盖所有原模型及新型号显式参数、单次POST、图片/GIF编辑和原生Gemini多参考图；请求正确且恢复不重发。同步安装版、两类ZIP及源码逐字节核验。无真实收费请求或生产变更。

## Consequences

服务端和渠道参数覆盖仍可能拒绝/重写，Skill放行不代表上游一定支持。GIF既有渠道覆盖来自数据库配置，提供精确迁移说明而非全站删除覆盖。服务器部署及配置由用户处理。
