# Agent Note: Playground 账户存储隔离

Status: implemented

## Problem

配置和消息使用全站共用 localStorage 键。同浏览器切换账户时不能确认旧数据归属，异步回复和延迟保存还可能跨身份写入。

## Decision

复用现有存储模块，以账户 ID 命名空间保存配置和消息。身份切换重建工作台状态并关闭流连接；延迟保存绑定创建时账户且确认当前身份仍一致。未登录不持久化。清理无法确定归属的旧共用键，不迁给首位登录者。

## Existing notes

活跃笔记未发现 Playground 存储决定；图片工作台独立应用不在本次范围。

## Alternatives considered

仅退出时清空可避免部分残留，但不能保留各账户历史，也覆盖不了无退出的身份变更。把共用历史迁给当前账号有泄露风险，采用清理旧键。

## Verification

存储测试覆盖 A/B 往返、匿名、清空与延迟写入。真实本地服务中以两个普通账号登录，验证刷新、B 不见 A、返回 A 保留其历史、旧缓存不加载，以及跨标签身份变化立即隐藏旧内容并提示刷新。覆盖 390px 暗色；未请求真实模型。

## Consequences

旧版未归属聊天和配置会被清理，已导出的文件仍可手动导入。
