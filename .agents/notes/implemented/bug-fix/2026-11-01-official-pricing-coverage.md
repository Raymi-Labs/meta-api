# Agent Note: 官方参考价缺失盘点与条件价格解析

Status: implemented

## Problem

线上 v1.12.1 的 224 个模型中，121 个没有可展示的厂家官方参考价。Haiku 5.5 官方页采用 100K 输入长度分档及两种缓存时长，现有 Claude 解析器只接受纯数字单价，因而静默丢弃价格。其它缺失包括未适配的厂家、名称不对应官方 API ID、不同计价单位，以及已支持但尚未同步的条目。

## Existing notes audit

- [官方价格同步](../feature/2026-10-31-official-pricing-sync.md)：部分重叠，扩展现有解析和定时同步，不新增写入链路。
- [厂家来源边界](2026-11-01-manufacturer-official-pricing.md)：部分重叠，继续严格采用厂家证据，代理报价不冒充官方价格，保护人工维护和旧有效值。
- [自动默认值](../feature/2026-10-31-model-official-defaults.md)：部分重叠，继续逐字段所有权及重试；不改变介绍翻译、销售计费或上游配置。此前展示布局及描述翻译笔记与本次取价边界无关。

## Decision

先以公共目录逐模型审计现有同步，复用官方文档取价入口。解析价格时必须同时确认模型身份、币种、计量单位和适用条件，按上下文/区域/缓存时长保留独立档位；不可识别的变化保留旧有效价。对未覆盖来源补齐解析，对没有可核实厂家 API 价的条目记录具体原因，不用相似型号或代理价格填空。加入可重复、只读的目录覆盖审计，正常测试不依赖网络。

Haiku 条件价格必须构成完整互补范围；HTML 表格只解码一次，保留小于号后的 Token 条件。多模态 Token 与字符增加独立单位，前端展示继承币种换算，但不同单位不生成折扣。AWS 仅从固定官方 JSON 解析报价占位符，OpenAI 图片统一价格表优先于个别型号卡片，合并顺序不再依赖请求完成时间。共享厂家页按来源去重，保留已有六并发上限和单请求超时。

源证据和剩余型号清单见[覆盖审计](../../../../docs/audits/2026-11-01-official-price-coverage.md)。89 个原缺失模型取得报价，32 个因未公开可验证价、已下线或平台别名无法确认而继续未知；总覆盖数字不是生产落库结果。没有新增生产写入工具或冻结价格种子。

## Alternatives considered

- 仅手填 Haiku 数字：能修单个展示，但下次官方变更仍丢失条件，不能覆盖同类缺陷。
- 放宽为“看到美元符号就读取”：可能读到其它型号、起步价或不同单位，导致错误折扣。
- 把聚合平台价格恢复为官方价：破坏已确立的厂家来源语义，不采用。

## Verification

- `go test ./...`、服务端构建、主站/图片应用/独立文档构建通过；构建中的默认 Linux Chromium 路径在 macOS 不存在，补用本机 Chrome 运行预渲染。
- Haiku 集成回归覆盖 HTTP 文档 → 自动同步 → SQLite 持久化 → 公开目录四档，以及坏价格保留旧值、人工零价保护。复用 GORM TEXT 序列化，无 schema 或数据库方言改动；本轮未重跑 MySQL/PostgreSQL 容器。
- 厂家格式回归覆盖错型号、单位歧义、区间缺失、重复冲突、HTML 边界、缓存时长、AWS 占位符和网页数据解码；真实下载的厂家文档执行全目录只读审计及有界失败重试。
- 官方价/折扣前端单测通过。复用真实 Chrome 验收脚本，在桌面/手机视口展示六个实际解析结果（Haiku、Qwen 多模态/图像、GPT 图像、Nova、MiniMax），核对来源、行数、单位与无整页溢出；既有管理编辑/保存/清空流程通过。页面 API 为隔离数据，未修改生产。

## Consequences

覆盖率以本次公开目录和实际抓取日期为准；无独立厂家定价的模型应保持未知，并提供可追查清单。发布不等于云上同步完成。
