# Agent Note: 官方参考价缺口修复与可解释空态

Status: implemented

## Problem

公开目录40项缺价混合了可修复解析问题、型号身份、历史服务和非厂家价格来源。单一“暂无官方参考价”不能解释这些差异。Google Omni 的官方模型链接采用系列路径且按输出模态分别报价；DeepSeek 当前价格表明确给出版本名但现有同步只匹配API ID。公开文档10秒超时导致已支持模型取价失败。

## Decision

复用现有官方同步、可空价格、公开投影和详情/分组比较。Google 仅允许经精确官方ID、标题锚点与体验链接验证的 Omni 系列链接，按模态拆分价格与单位，保留视频Token换算说明。DeepSeek 仅接受当前官方表同列 MODEL VERSION 的精确完整版本名，不将旧日期或不带日期名称猜作别名。公共文档超时20秒，带凭据API保持10秒，外部取消继续生效。

Glimpse 读取 Elorian 固定厂家发布页的明确输入/输出单价，注明2026-10-16发布参考价，未披露缓存价格不填充。40项审计形成不含价格的核实状态快照。仅在公开层最终无价格时返回统一状态（来源可核实、历史条目待核实、型号映射待核实、免费变体、一般待核实），附核实日期；未知新模型默认待核实，不宣称官方未定价。实际有效价优先，自动清除空态提示；不新增数据库字段、不改管理员资料或本站计费。详情与各分组消费同一状态和翻译。

[后续参考范围与展示](../feature/2026-11-17-official-price-reference-scope.md)部分替代重复外显空态：缺口原因改按需展开，区分来源访问失败；历史价使用FAQ隔离，当前参考表与计费不变。

## Existing notes audit

[Google迁移](../../implemented/bug-fix/2026-11-15-gemini-pricing-migration.md)部分扩展；[官方覆盖](../../implemented/bug-fix/2026-11-01-official-pricing-coverage.md)继续负责条件完整性；[公开来源](../../implemented/bug-fix/2026-11-06-public-model-provenance.md)继续排除平台价。不改变这些决定。其他渠道Claude缓存改动与本任务无关。

## Alternatives considered

统一手填或套用最新模型价能减少空值，但会把旧型号、平台免费或不同模态误标成官方价。只改变提示无法修复可核实的解析缺口。为每种失败写入数据库会扩大跨库和同步所有权契约，本次使用只读审计快照并在价格有效时隐藏。

## Verification

真实文档验证 Omni 输入及文本/视频输出、DeepSeek精确版本峰谷价；拒绝错型号、未知模态、旧版本及含歧义条件。状态覆盖40项、有效零价隐藏空态、公开过滤后状态与详情/分组一致、17种站点语言完整。真实网络审计40项取得5项价格、35项保留核实状态。controller/model完整测试、真实文档定向测试、22项前端单测、前端生产/预渲染及服务端构建通过。针对缺价与模态价格的20个桌面/手机浏览器场景通过。原大型浏览器脚本通过本轮相关详情/分组断言后在既有模型体验页旧选择器超时，未将全脚本算作通过；另建聚焦脚本覆盖本轮用户流程。两个旧单测预期按已有首地域和同币种比较规则更新，无折扣运行时逻辑改动。发布与生产生效分别核验。

## Consequences

历史审计是某日核实结果，不能作为永久退役或永久无报价结论；页面显示核实日期，未知原因采用保守文字。上游格式变化仍保留旧有效价。模态价不跨单位比较。
