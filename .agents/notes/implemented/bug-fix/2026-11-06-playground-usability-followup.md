# Agent Note: 模型体验操作与价格口径补齐

Status: implemented

## Problem

聚焦布局顶部误用分组说明作名称，可能出现重复福利；价格沿用USD、流式双入口、桌面遮罩阻止切换工具，参数术语和备份范围不清。用户要求分组只显示名称，其余反馈补齐并发布。

## Decision

复用原权限和计价数据，不改后端：顶栏/设置选择仅显示真实组名；有效已存选择保留，无有效选择优先精确福利。价格摘要与详情使用同一格式器，按站点自定义货币换算闪电、按status.price显示标准充值人民币参考，不凭固定5倍换算；缺率不显示人民币，不把微小非零四舍五入为零。

桌面历史/设置/代码为推开聊天的侧板，工具栏始终可操作；手机保留抽屉。流式设置单模型只留输入框，多模型在其输入区提供一个；思考仍按能力控制但名称/默认/关闭差异明确，参数中文名附API字段并解释开关。会话备份与单会话配置导入导出区别命名。代码示例只将元衡精确域名改为meta-api.com，localhost与其他自部署不变。

## Alternatives considered

- 全部会话强制福利会改变用户选择和计费，不采用。
- 固定乘0.2简单但不适用于不同站点配置，复用公开充值基准。
- 桌面继续遮罩最省代码但不能直接切换面板，使用同一组件按断点停靠。

## Verification

46项分组、价格格式、代码转换、会话、比较、请求工具与语言资源测试通过；账号存储、SSE和既有价格币种测试通过。主站Vite构建、修改文件ESLint和Prettier通过。隔离浏览器验证桌面直接切板、组名与报价、移动端抽屉、有效保存分组保留、新账号福利默认、会话切换与导入导出、账号/标签隔离、五模型和非流式停止。测试浏览器与服务均在finally关闭，未发付费模型请求。

## Consequences

名称与金额口径统一，参数和备份作用范围明确。桌面展开侧板仍会占用聊天宽度，可随时关闭；移动端保留抽屉以避免挤压。人民币是标准充值参考而非套餐成交价；部署后需真实站点配置核验。测试使用隔离API，不代表生产渠道验收。仅本轮变更发布，不混入主目录其他改动。
