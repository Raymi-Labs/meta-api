# Agent Note: 公开模型资料只展示本站与原厂信息

Status: implemented

## Problem

公开pricing的67个官方价格备注仍提及接入平台，9个免费变体档位和来源链接直接暴露第三方平台。仅清理描述或前端隐藏无法覆盖JSON与后续同步。

## Decision

在GetPricing角色过滤后做不修改源数据的公开投影，覆盖描述/多语言、FAQ、档位、备注、图标链接、属性来源及返回厂商文案。公开官方参考价仅保留已有原厂域名校验通过的价格；平台免费变体保留模型及本站售价，但不把平台零价冒充原厂价。保留后台原始来源和同步，不改模型ID、倍率、路由、计费及署名。

原厂价格备注移除第三方/接入运维句，保留可识别的价格条件；丢失档位含义时不猜条件，隐藏参考价。公开来源必须是可信原厂HTTPS域名，无用户信息、查询或片段；描述中的未知站外链接句不公开。已知聚合平台名称明确移除，原厂品牌及项目保护署名保留。

## Existing notes audit

[厂商可见性](../../implemented/bug-fix/2026-11-06-pricing-vendor-visibility.md)仍负责权限与引用交集；本篇处理公开内容并保留后台厂商。公开描述规范化仍保留原始审计，本篇不改变其数据库迁移或人工编辑。原厂定价校验复用manufacturer_pricing，不给未知平台改名伪装。

## Alternatives considered

- 批量SQL改备注最快，但下次同步会重新出现且损失审计来源，不采用。
- 前端替换可修截图但公开JSON仍泄漏且多入口遗漏，不采用。
- 在公开返回层按字段投影可覆盖所有消费者和未来同步，代价是未知来源参考价可能不显示，明确保留本站真实售价。

## Verification

对当次公开222模型快照离线投影并序列化审计，67条OpenRouter备注、9个来源链接及档位不再对外输出；所有模型ID、本站倍率/表达式/售价及分组保持。定向race验证大小写、零宽/HTML/百分号编码、伪造官方域、带凭据URL、条件句保留、原厂query规范化、跨角色重复请求、源缓存/数据库不变。真实controller使用SQLite隔离证明公开过滤、后台原始资料保留。隔离Chrome桌面GPT-4o和390px Flint详情实测点击官方参考价帮助，检查完整DOM/链接及档位；全部API由本地快照模拟，无付费请求。

## Consequences

不靠字符串替换修改模型ID或功能键。未知原厂域名未列入信任表时来源/价格保持未知；未来新增原厂需要审查名单。已知平台词表不能证明任意未知品牌已识别，应使用全字段审计持续检查。不删许可和项目署名，不改后台资料、生产数据库或渠道。

[Flint例外](../../implemented/bug-fix/2026-11-06-flint-free-reference-price.md)与[已核实免费变体](../../implemented/feature/2026-11-06-openrouter-native-names-free-variants.md)保留后台来源核验及实际免费售价，本公开投影按用户最新要求不再把第三方变体价公开为官方价。Fireworks等实际原厂名保留；不会仅因它同时提供托管服务而删除真正厂商。对外模型ID、分组键和计费表达式是功能契约，不作为展示文案重命名。公开定价端点对所有角色应用同一内容规则，后台管理接口不受影响。
