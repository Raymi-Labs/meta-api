# Agent Note: 模型与兑换码编辑会话隔离

Status: implemented

## Problem

模型与兑换码抽屉复用同一表单，详情旧请求返回后直接覆盖当前记录。列表 hook 关闭后 500ms 无条件清空编辑 ID，快速关闭 A 再打开 B 时可把 B 切成新建态。加载失败后没有成功加载门槛，旧值或默认值仍可能被保存到当前 ID。

## Decision

沿用令牌表单的请求序号隔离：每次打开、切换记录与关闭形成独立会话，详情请求禁用按 URL 合并，完整默认值先重置，当前会话详情加载成功后才允许编辑保存。保存请求也绑定会话，迟到响应不能关闭或重置新抽屉；提交防重入，失败保留当前输入。表单按可见性、记录身份及加载完成代次重新挂载，使用完整快照作为 initValues，而不是只对已注册字段 setValues。这样套餐 ID、份数、续期模式等条件挂载或隐藏字段也有准确初值。

保存成功通过最新 refresh 引用刷新当前列表，不能调用保存开始时捕获的旧厂商/分页闭包。详情与保存请求关闭全局重复错误处理，当前会话独立提示；旧 HTTP 失败静默，当前 Axios 401 仍沿用清除登录状态和登录过期跳转。未取消服务端已执行的保存，不声称具有回滚能力。

关闭仅改变可见性，不再定时清除 ID；创建/编辑入口本来就显式设置目标记录。保留退出动画的原记录身份，下一次打开以明确目标和全新默认值初始化。只改前端状态流转，不新增接口，不改变模型厂商/标签/端点或套餐码/有效期语义。

## Existing capability review

管理员 models/redemption 路由、详情和写接口已存在，列表按钮明确设置 editing 对象。复用现有组件、hooks、API 与鉴权，不新建服务端能力。

活跃笔记检索：[令牌选择器](../feature/2026-10-20-token-create-selector.md)、[令牌收藏](../feature/2026-10-04-token-group-favorites.md)与请求隔离部分重叠，保留并借鉴其独立请求快照；模型广场筛选/厂商排序、视频价格与此管理抽屉会话无关，不改其决定。无现有模型/兑换码编辑会话归属。

## Alternatives considered

- 仅像上游补齐 reset 默认值，改动最少，但挡不住已发出的旧详情/保存请求，也不能消除旧关闭定时器。
- AbortController 可减少无效请求，但已完成响应与客户端 URL 合并仍需身份门槛；本次复用 Token 的代次校验并关闭单入口去重，避免新增取消契约。
- 保留 500ms 定时器并逐次取消能维持清理习惯，但所有打开路径都要协调计时器；关闭无需清空记录，删掉定时清理更直接且保留退出动画身份。

## Testing

`PLAYWRIGHT_MODULE=<已有 Playwright 的 index.mjs 路径> node web/scripts/admin-edit-session.browser.mjs` 使用真实组件和列表 hooks、本地 Chrome 与合成 API，20 组场景通过并以退出码 0 完成。覆盖 A 关 B 开、超过旧 500ms 截止点、同 ID 重开独立请求、旧详情迟到、新建/编辑切换、HTTP/业务加载失败按钮与 Enter 不可保存、保存失败保留输入与重复提交、旧保存迟到不关闭 B、旧 HTTP 失败不弹错、当前错误单次提示、最新分页/厂商刷新、401 登录过期和 390px 暗色提交。断言模型厂商 ID/标签/端点、套餐 ID/份数/续期模式/有效期保持不变；新建后保留下载确认提示。浏览器、Vite、esbuild 在 finally 关闭，临时入口删除。

相关四个源码文件 ESLint、Prettier、diff 空白检查和 make verify-notes 通过。精确暂存快照的完整 Bun 生产构建通过，并显式使用本地 Chrome 完成 login/register/pricing/download/about 五页预渲染，无跳过；合成浏览器验收与构建不代表发布成功或生产管理员账号已验收。

## Consequences

当前加载失败不能把旧值或默认值保存到另一条记录，快速重开没有旧定时器清空身份。完整快照额外触发一次表单挂载，换取条件字段与隐藏字段一致；已开始加载期间用户输入不保留，只有当前加载成功后进入可提交会话。当前新建兑换码成功保留原下载提示，已关闭旧会话不会弹下载确认干扰新操作；已落库结果仍通过当前列表刷新可见。代次、快照和最新刷新引用是额外维护成本，后续改动必须保留这些真实浏览器边界，不扩展为全站表单框架。
