# Agent Note: 渠道模型发现使用当前表单地址

Status: implemented

## Problem

编辑渠道时手动取模型仍读取数据库URL，忽略未保存地址；Gemini中转的原生目录可能只是旧官方镜像，实际账号模型在兼容目录。内置Gemini参考表停留在旧型号，取列表失败没有可选参考。

## Decision

新建、编辑、映射选模共用POST预览接口，提交当前URL/类型/代理/请求头；编辑密钥留空且目标同源时由服务端使用该渠道启用密钥；跨域必须显式填写目标密钥，避免借查询接口转发受保护凭据，不回传凭据或保存表单。复用既有渠道发现函数，自定义Gemini地址先查兼容models，再查原生分页目录；官方地址只走原生协议。分页错误不当作完整成功。

仅手动预览请求允许回退。Gemini匿名读取固定Google官方价格文档中的精确模型ID，失败时使用内置参考；其他类型沿用适配器参考表。返回来源并在选择弹窗持续提示参考不是该渠道可调用证据。自动检测不使用官方回退。表单配置变化清除缓存并丢弃旧响应。

## Existing notes audit

[模型发现体验](../../implemented/feature/2026-10-26-model-discovery-experience.md)属于公开目录，相关但不承担管理员上游查询；[模型能力同步](../../implemented/feature/2026-10-27-model-capability-sync.md)为元数据同步，不接管路由发现；[采购限价](../../implemented/feature/2026-11-01-openrouter-price-routing.md)部分相关，参考名单不绕过已有参数覆盖和价格审核。

## Alternatives considered

只更新内置模型能补当下新型号，但不能反映填写的供应商URL；先保存再读取会迫使用户持久化尚未验证的配置。把第三方密钥发送给官方API会跨账号复用凭据，因此官方参考采用匿名公开来源。自动同步也回退会把未证实能力写入路由，因此仅手动预览允许回退。

## Verification

Go controller、Gemini适配器、参数覆盖包回归通过，新增回归覆盖未保存地址、已有密钥不回传/不落库、跨域密钥保护、代理和请求头覆盖、兼容目录优先、原生分页与游标编码、重复游标/分页失败、空目录与错误数据、重定向凭据隔离、匿名官方回退和自动同步不回退；针对发现链路race检查通过。真实浏览器加载编辑/新建组件，验证草稿URL、保存密钥留空、来源提示、回退和过期响应丢弃。完整前端含生图子应用构建和17语言检查通过；主程序构建通过（本机构建目录的iCloud重复生成文件导致复验阻塞，保留重复文件并用Go overlay排除残余重复条目；正式CI使用干净源码产物），五页Chromium预渲染、29项发布脚本回归及发布策略检查通过。生产尚未升级，真实上游接口的差异仍需部署后验收。

## Consequences

公开文档变化时回退到明确标注的内置参考，参考不保证账号权限或实际可用；不自动保存模型。手动获取既有渠道接口仍返回真实上游数据，自动检查同源，不使用参考回退。模型查询有时限、响应体上限、分页完整性检查且不跟随重定向；故障不返回带密钥的上游正文。没有数据库迁移或生产配置修改，发布与生产部署分别验收。
