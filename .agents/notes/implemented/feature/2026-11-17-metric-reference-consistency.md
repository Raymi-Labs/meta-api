# Agent Note: 模型指标参考在各入口一致显示

Status: implemented

## Problem

用户要求其他缺失指标也按本站数据优先、官方参考补齐的方式显示。现有首字/速度P50已进入卡片及分组，但图表仅支持两个外部指标且没有统一摘要回退；对比页仍标Uptime却使用请求成功率，不能消费新可用率参考。空曲线会掩盖已存在的本站汇总或七天历史摘要。

## Decision

复用已有modelPerformance、modelUptime、ModelMetricChart与鉴权健康接口，不新增抓取或计费。将当前实测、已有历史摘要、匹配端点P50/24h参考统一为图表汇总选择：有历史点则继续绘制真实曲线，当前值只显示汇总；没有历史点但有摘要时直接显示数值快照，不把摘要复制为各小时。保留本地0优先、模型/分组身份和过期保护。缓存命中率/完成耗时只有本站实测或已有历史参考，没有官方字段则明确暂无统计数据，不能借用TTFT或推断缓存。

对比页将Uptime对齐同一可用率字段与探测规则，参考窗口独立标明。目录、详情和对比共享严格五分钟参考时效；来源不明、时间无效、字段未知不补零。图例、快照缺失项使用明确状态，不保留裸破折号；历史表格缺测仍保持缺口。图表标题根据参考类型区分首字时间及参考可用率。

## Existing notes audit

扩展[24h参考](../../implemented/feature/2026-11-17-external-uptime-reference.md)到图表与对比；沿用[空图参考](../../implemented/feature/2026-11-01-model-chart-reference.md)的快照/历史边界、[性能质量](../../implemented/bug-fix/2026-11-16-model-performance-quality.md)的不填历史缺口和[补值简化](../../implemented/simplification/2026-11-03-model-performance-source-display.md)的简洁展示。现有用量参考是模型全网用量，不可冒充本站分组消耗，本轮不改变该机制或增加当前UI未展示的用量板块。

## Alternatives considered

对每条空历史记录灌入当前参考会制造稳定性；多模型或多服务商取最快/最高值会偏离路由。继续只补分组行会让详情与对比结论冲突。为缺字段猜数值无法核实，因此保持明确状态与已验证来源。

## Verification

外部首字/速度/可用率覆盖卡片、分组、空图和对比的适用入口；零值优先、部分组有历史/部分无历史、无数字来源、过期、外部0与历史不填充回归。现有汇总和历史参考能显示为快照但不改变原始数据。缓存/完成无官方字段不虚构。桌面/手机及图表放大验收，测试与临时进程全部清理。

## Consequences

外部接口可能对冷门模型返回null，没有可靠证据无法保证全部指标有数字。数字参考需登录且符合授权路由，匿名权限不扩展。本轮本地实现不代表上线。

验收：20项前端回归通过（图表隔离套件另覆盖8个场景）；精确快照周期、真实零值、本地历史摘要、引用时效及不支持指标不推断均通过。浏览器核实6种数据状态：外部快照、本站0、混合实测/参考、过期、无字段、历史摘要；真实历史只有3张实测图，无历史只显示快照；放大窗口、对比页、手机312px有效视口无横向溢出。前端主站与图片应用构建、17语言、ESLint、五路由预渲染及机械UI检查通过。临时测试数据仅用于本地验收，不代表线上模型性能。

收尾：研究代理和浏览器临时页已关闭，临时验收入口文件已删除，开发服务器与构建/预渲染执行结束；任务遗留进程为0。
