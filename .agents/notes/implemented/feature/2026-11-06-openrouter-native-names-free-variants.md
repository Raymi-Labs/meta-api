# Agent Note: OpenRouter 原生名称映射与免费变体恢复

Status: implemented

## Problem

初次按厂商接入采用完整 OpenRouter ID，并在后续原厂价审核中暂停没有原厂托管 API 报价的免费变体。用户已手动整理 Recursive、Elorian、Kimi，要求其余型号使用去厂商前缀的名称，通过渠道映射调用完整上游 ID；实际免费的模型保持输入输出为零。当前公开参考价仅允许 Flint 零价，其他免费型号填写零仍不可见。

## Decision

复用渠道管理 API、模型元数据、价格 options 和既有参数覆盖；对现有 OpenRouter 精确型号去掉首段厂商命名空间并显式映射，保留 :free 等变体后缀。先检查短名碰撞和已有计费配置，再补齐价格和资料，最后修改渠道。用户已整理的 Recursive、Elorian、Kimi 保持原样。付费模型保留原采购限价、停售状态和销售价格；不因开源而置零。

免费准入使用当日 OpenRouter 官方目录及精确端点报价，输入输出必须显式为零，其他公布的费目同样不能为正。只恢复本仓库已有接入资料的已验证免费型号；未知或受账户限制的端点记录原因。免费路由保留零采购上限、明确上游模型及额外收费拒绝，不能直接删除整条渠道的保护。参考价将已有 Flint 的精确来源例外扩展到本轮已核实的型号清单，不按任意 :free 后缀自动推断。

- [Flint 免费参考价](../../implemented/bug-fix/2026-11-06-flint-free-reference-price.md)：扩展已核价精确型号，不改变零与未知、来源匹配和单档约束。

## Alternatives considered

- 只改渠道模型列表：价格键、展示元数据和映射不一致，会导致计费缺失或请求无法调用；必须联动迁移。
- 删除所有采购保护后启用：可以快速恢复，但会放开付费回退和额外收费；免费使用零限价和收费入口拒绝。
- 将所有开源模型价格设为零：权重许可与推理费用不同；仅使用当日明确零报价。
- 给任意 :free 名称显示零官方价：缺乏精确来源证明；采用已核价清单及来源路径校验。

## Verification

生产通过既有管理员 API 完成 41 渠道、88 个短名映射及对应模型资料，价格映射先补齐后切换渠道能力；保留原资料和历史价格键供审计及回退。两个未被任何现有渠道使用的 Cohere 裸名默认倍率被当前实际售价替代；其他来源价格原样复制，Sakana 两项阶梯表达式和模式通过原子 bundle 同步。受影响旧名未被现有令牌模型限制引用。Recursive、Elorian、Kimi 的配置读回保持不变。

当前 53 个启用短名全部出现在公开 pricing 和受限令牌目录。Go 实际模型映射与参数覆盖引擎 120 项检查通过，付费模型映射后覆盖结果与原请求逐字节相同；免费零采购上限、未知型号和收费入口拒绝通过。独立导出的源代码完成 model、relay/helper、relay/common 全包测试与服务端构建；首次构建因干净导出缺少前端 embed 产物失败，补入既有前端产物后通过，无应用逻辑变更。

8 个恢复的免费型号中 7 个普通请求取得有效正文和 usage，上游 cost 与本站消费 quota 均为零；NVIDIA 免费流式含正文、usage、[DONE] 且日志零扣费，收费搜索返回 400。付费 Ministral 短名请求及正值扣费通过。XingChen 首次实际请求收到上游 429，随后受路由保护返回 503，不能计为成功推理；另一个 NVIDIA content-safety 免费端点状态 -5，未恢复。首轮验证令牌误包含停用渠道被权限校验拒绝，修正限定启用渠道后继续，失败记录保留；所有临时令牌清理。

审计见[逐项清单](../../../../docs/channel/openrouter-normalization-audit-2026-11-06.json)。私有快照、计划、逐项进度、失败与验证结果保存在生产 `/opt/meta-api/operations/openrouter-normalize-20261106`，目录 0700、文件 0600，不含密钥的公开清单入库。配置写入期间服务保持在线，数据库只读。

生产通过 `newapi-update sha-95632b7` 完成在线备份、两次稳定 schema 预检、健康切换及恢复包封存，当前运行 v1.20.6，保留 v1.20.5 回退镜像。15 项上线后检查通过：9 个启用免费变体（含保留的 Flint）公开参考价输入输出均为零、Jev 两个短名仍有厂家价、旧完整名不在公开目录、全部 OpenRouter 渠道无厂商前缀名称、临时令牌为零。XingChen 冷却后单次补测仍为上游 429，未产生消费日志；不将其记为成功推理。此前镜像尚未发布时的 dry-run 拉取失败未修改生产，正式发布后更新成功。

## Consequences

对外名称变更需要客户端使用短名，历史消费记录保留原模型名。裸名与既有价格冲突必须逐项检查，不能覆盖正在使用的其他渠道配置。免费端点仍可能限流或要求账户隐私设置；不更改用户隐私偏好。快照不是自动追价。并行任务正在改用户分层计费，不能把其文件混入本次提交或部署。
