# Agent Note: 官方参考价的历史范围与缺口展示

Status: implemented

## Problem

缺失官价混合了历史型号、无法访问的一方文档、渠道别名与平台免费变体。历史官方发布价有查阅价值，但作为现行优惠基准会误导。当前详情和各分组重复展示缺口说明，掩盖仍可使用的本站售价。`:free`是本站提供的免费服务，不证明厂商免费，也不应因此改变本站收费。

## Decision

历史报价复用现有模型FAQ，标题明确“历史官方参考价”与日期，正文包含精确版本、币种、单位、价格、出处和非现行报价说明。不写入official_pricing，因此所有现有分组对比入口及旧版本均不会将历史价作为现行优惠基准。只有获得完整官方证据才追加，保留已有FAQ；未核实候选只在审计文件保存。继续按既有厂商国内/国际来源补缺，不改变已填价和计费。

复用核实状态和ModelSectionHelp。无参考表时压缩为标题及信息按钮，原因与核实日期放入弹层；分组中的重复缺口说明收进信息按钮。新增source_unavailable区分官方页面访问受限与identity_review身份不明，审查日期只更新实际核实项。平台免费状态明确本站与厂商是两种价格；未知不填0，本站是否免费仍由真实计费字段决定。North已有后台平台零价的金额与USD显示币种保留，只把来源换成Cohere一方页面、备注明确免费条件。旧生产版本仍过滤此参考表，资料已存储但公开表须发布本次来源例外后生效；当前FAQ已有免费说明。

[本站售价优先](2026-11-17-marketplace-site-price-first.md)按用户最新指示替代缺价表空态：详情先显示本站价格，无有效官价不展示该区块或导航。本文的历史FAQ、来源边界和手机面板规则仍保留。

## Existing notes audit

部分更新[缺口与空态](../../implemented/bug-fix/2026-11-15-official-price-gaps.md)的外显说明方式和状态分类；沿用[官方参考价](../../implemented/feature/2026-10-30-model-official-pricing.md)的可空价、[公共来源](../../implemented/bug-fix/2026-11-06-public-model-provenance.md)的厂家证据要求及[分组优惠](../../implemented/feature/2026-10-30-model-group-official-discount.md)的同单位条件。只有 North Mini Code 获得Cohere官方型号映射及速率限制内免费证据，允许两个精确名称使用 docs.cohere.com/docs/north-mini-code-1.0；其他免费变体仍不从后缀推定官价。

## Alternatives considered

继续要求旧型号有现行价目会丢失有价值的官方历史证据。只在official_pricing.notes写历史无法阻止优惠计算。新增historical_as_of字段会让旧版本忽略标记仍计算优惠；另建历史价格结构扩大数据库、同步与回滚契约。已有FAQ可明确日期和来源，优先复用。历史价直接套用现行型号会混淆不同服务。删除缺口原因会降低可解释性，因此保留可键盘和触屏访问的信息入口。根据free后缀设官价0或本站0会混淆语义，本轮不改计费。

## Verification

历史价格不进入official_pricing，不产生任何折扣或官方价比较；当前有效零价仍正常比较。未知价格字段保持未知。桌面和窄屏可查看本站价、通过点击及键盘展开原因；更新17语种。复用既有手机断点，窄屏说明固定在视口内，限制高度并内部滚动，避免锚点附近放不下的长提示越界；桌面保留锚定弹层。只填有官方证据的空缺，历史候选通过既有FAQ保存，不依赖新代码上线；没有证据的保留为空。相关后端和前端测试、构建、文档校验通过，遗留进程0。

## Consequences

FAQ不会作为价格排序或折扣计算依据，但历史价没有结构化筛选，这是复用已有能力的明确取舍。本轮没有应用发布授权，线上资料补缺与本地显示优化分开报告。没有新增数据库字段。官方文档不可访问的项可能仍需外部资料，不能将无法核实描述成官方不存在。

实测：24项价格/分组前端回归通过，model定向来源/公开投影/规范化测试通过；17语种检查、ESLint、构建与5条公开路由预渲染通过。CUA实测缺口、官方0、本站free、访问失败、模态单位、阶梯价格与键盘聚焦/Esc；桌面和有效312px窄屏及512px短视口无整页横向溢出，说明面板左右16px。机械UI检查无命中。未进行真实移动设备或收费推理测试。
