# Agent Note: 模型目录与独立详情页

Status: implemented

## Problem

模型目录左侧的可用令牌分组占据浏览空间，600px 侧栏详情难以容纳模型介绍、接口、价格及调用表现。用户明确选择移除目录中的分组展示，并希望点击模型进入可分享的完整详情页。

## Decision

[模型发现与接入路径](2026-10-26-model-discovery-experience.md)更新搜索与筛选布局、缺失状态、快速开始入口和首页手动公告规则；本文其余数据及权限契约继续有效。

本篇的 cURL 单语言、仅复用旧健康数据与不新增展示元数据决定，由[模型展示元数据与分组指标](2026-10-25-model-catalog-metrics.md)部分扩展；独立路由、价格和权限边界继续保留。以下说明原详情页设计的边界。

目录保留厂商、类型、标签、端点与价格显示设置，移除分组侧栏及抽屉中的分组选择。新增 `/model/:modelName`，使用编码后的模型名称作为地址，从当前身份的 `/api/pricing` 响应精确查找；沿用模型广场登录守卫及角色可见性，不从 URL 或历史状态注入模型信息。

详情采用介绍、价格与分组表现、接口、快速开始、同厂商模型的布局。复用现有计价和健康组件；快速开始仅为后端声明且已有生成器支持的协议生成 cURL，沿用运行时地址，绝不发起模型调用。价格在目录和详情使用相同的 K/M、当前账户和时间倍率。历史状态仅保存列表筛选、排序、页码和显示偏好，返回重新读取数据；身份切换不保留前一身份数据。章节目录使用滚动按钮而非原生 hash 导航，避免新 history entry 丢失返回列表的状态。

[当前位置导航](2026-10-31-model-detail-active-section.md)扩展滚动位置反馈：目录当前项加粗并设置 aria-current，保留上述按钮与历史状态边界。

## Alternatives considered

- 扩大原侧栏能复用全部交互，但无法直接分享和刷新定位模型，也不符合用户明确选择的详情页路径。
- 复制参考页的上下文、模态和性能数字能填满页面，但本地没有对应可信来源；只采用信息层次，展示站内已配置描述、价格、协议及实际健康数据。
- 用独立接口或额外模型库取详情便于扩展元数据，但会引入第二套权限和价格来源；当前目录响应已经足够，复用同一数据边界。

## Verification

- 路由测试使用实际 App 验证模型广场和详情共用登录守卫；模型名编码测试覆盖斜杠、百分号、空值和格式错误。状态白名单测试排除模型与账户数据。
- cURL 测试覆盖声明协议、运行时地址、URL 凭据去除及 shell 引号。既有普通/阶梯/小时计价、K/M、充值换算和筛选测试通过。
- 表格采用受控分页后由调用方切片，避免 Semi Table 的受控 currentPage 跳过内部分页；实际 Semi SSR 测试覆盖第二页、末页和空结果。路由与表格的模块模拟在独立 Bun 子进程执行，防止污染同进程导航测试；并跑与随机顺序均通过。
- Chrome 使用公开模型数据快照在本地项目壳验收：Kimi 详情、动态价格、协议示例复制、匿名健康入口、筛选返回、表格第二页返回、未知模型及失败重试；320/390px 德语暗色无整页横向溢出，桌面深浅色正常。
- 17 语言新增词条与变量检查、相关回归、主站/独立文档完整构建及预渲染通过；与已发布的独立文档和顶栏改动合并后复验。账号切换隔离经代码检查，未以真实生产账号完成浏览器切换测试。

## Consequences

模型可通过独立 URL 分享和刷新，目录获得完整宽度；筛选状态通过 history 保存，返回时重新获取当前身份数据。详情重新获取目录会多一次读取，但避免历史缓存泄漏及过期价格。第三方描述属于运营内容，前端不机器改写或补造能力；接口未声明时只能引导文档。2026-10-31 按用户要求移除详情重复的动态基础阶梯表；分组价格仍按当前适用倍率计算，顶部官方参考价保留官方币种及档位。列表状态只作 UI 偏好，不作为权限依据。

发布不部署生产，不新增后端接口、数据库迁移或依赖。

相关扩展：[固定模型栏与跨模型对比](2026-10-31-model-detail-sticky-compare.md)复用本能力，并通过权限校验后的模型体验深链接连接详情、对比和测试。

模型介绍的动态17语言缓存与人工覆盖见[模型介绍全站语言](../bug-fix/2026-10-31-model-description-locales.md)，不改变本笔记的原文同步或页面权限约定。
