# Agent Note: 多模型回答分栏与选答续聊

Status: implemented

## Problem

双列网格不方便横向比较三至五模型，手机长页难以切换，选答后还需手工切模型。用户要求本地优化，并明确不要耗时、首响应、速度和最快标签。

## Decision

系统提示词位于对话设置侧栏，单/多模型顶部均不再显示提示词卡。多模型内容铺满可用宽度，单模型消息仍保持阅读宽度；[设置收敛](2026-11-07-playground-settings-simplification.md)负责侧栏精简和清空确认。

复用现有独立请求和每轮共同上下文：并排模式每回答一栏，按实际可用宽度保留最小列宽并横向滚动，正文独立滚动、头尾固定；上下排列自然展开，手机每轮标签切换。放大只改变展示，不卸载请求；空选择与待发送提供操作引导和预览卡。

保留“用这条继续”供下一轮多模型比较，另加“用这个模型继续”选择本轮完整回答并切单模型；所有旧回答保留用于查看，只有各轮已选回答进入请求。仅最新轮、无任何进行中请求、当前分组与发送时一致且模型仍有权限时可续聊。重新生成复用最新轮原请求快照，完成/失败/停止均可显式重试；刷新后快照不在则禁用，不猜原请求、不自动发送。

## Existing notes audit

[比较布局](../../implemented/feature/2026-10-31-playground-comparison-layout.md)的双列/手机纵向由本篇替代，资料选择与共用参数仍成立；[并发文本](../../implemented/feature/2026-10-31-playground-parallel-text.md)的请求隔离、计费和选答契约保留；[聚焦补齐](../../implemented/bug-fix/2026-11-06-playground-usability-followup.md)的名称/价格/侧板不变。其他检索命中的渠道、模型定价和令牌笔记不相关。

## Alternatives considered

- 五列强行平分能一次看全，但设置展开或窄屏导致文字不可读，改为最小列宽和横向滚动。
- 切单模型时删除其他回答实现简单，但会丢失比较记录，保留原消息并复用选答过滤。
- 按模型重写之前每轮上下文更像独立分支，但改变用户已选共同历史，不采用。

## Verification

40项并发、工作区、会话和语言资源测试通过；Vite生产构建、局部ESLint/Prettier通过。隔离浏览器验证五模型真实渲染、横向分栏、单栏放大/Esc恢复、单模型续聊、手机及既有停止/重试流程；未采集耗时、输出速度或最快标签。测试浏览器与本地服务已关闭，遗留测试进程为零。

## Consequences

回答内容更容易横向比较，手机不再依赖长页面；并排模式使用回答区横向滚动，长文可切上下排列或放大。切回单模型后只将选中回答送入后续请求，但比较答案仍保留在本地供查看。跨组、撤权、未完成和失败回答不能续聊；重试是新调用，界面不估算费用。没有新增后端或计费逻辑。
