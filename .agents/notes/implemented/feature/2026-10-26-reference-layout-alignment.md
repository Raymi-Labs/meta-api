# Agent Note: 以实测参考站校准模型浏览布局

Status: implemented

## Problem

前一轮模型目录与详情虽然改善了状态提示，但大价格卡片、宽松介绍区和胶囊控件偏离用户指定的 AIHubMix 风格。实际查看参考目录、Kimi详情及登录框后，确认其采用紧凑横栏、内联价格、分行筛选和普通圆角控件。

## Decision

模型卡片恢复名称→价格/性能摘要→简介，复用原计价和身份状态；目录主页面显示已有厂商、计费、标签行，端点及价格设置继续使用已有抽屉，已选条件仍可独立清除。未配置模态不伪装成可用筛选。详情收紧介绍、价格、分组与代码区比例；保持当前快速开始、声明协议提示、分组权限和实际价格。登录注册与顶栏仅调整外观，保留整页路由与现有认证方式，不复制参考站弹窗认证架构。

## Related decisions

- 部分取代[发现路径](../../implemented/feature/2026-10-26-model-discovery-experience.md)的低频筛选全部收入抽屉、简介在价格前及大圆角展示比例；保留缺失状态、价格条件、返回状态和公告手动规则。
- [模型目录](../../implemented/feature/2026-10-25-model-catalog.md)、[模型指标](../../implemented/feature/2026-10-25-model-catalog-metrics.md)及[详情](../../implemented/feature/2026-10-25-model-detail-page.md)继续持有底层数据与权限；不建立第二套模型库。
- [认证布局](../../implemented/feature/2026-10-25-auth-form-layout.md)保持账号/OAuth、协议和回跳契约。
- 伙伴视频计费工作不在此决定范围，保留表达式/秒/次/小时展示。

## Alternatives considered

- 继续放大圆角和留白容易保持上一版，但已被用户指出与目标不符；采用实际参考页面的信息密度。
- 完全复制参考站字段、性能或认证方式能更像截图，但会伪造本站能力并改变权限、认证契约；仅映射本站真实功能与数据。

## Verification

在1100px参考站实际查看模型目录、Kimi详情和登录框，按截图与可见DOM校准：参考详情标题32px，介绍横栏紧凑、价格为内联列表；本站样例介绍区约131px、目录卡片约229px。使用隔离API样例在真实项目壳验证目录按次/零值按量筛选与逐项清除、复制不跳转、320/390px深浅色、详情协议与代码语言联动及未声明提示。认证与模型路由/回跳、协议示例、计价、筛选与语言回归通过；格式、ESLint、主站/独立文档构建与笔记校验通过，保留既有大包提示。详情返回保留搜索、空结果重置和注册next参数均实测通过。

2026-10-27 密度调整：目录在 ≥1280px 使用四列，1024–1279px 三列，680–1023px 两列，更窄单列；卡片缩小内边距、圆角、标题与图标，价格采用两列标签和值，性能采用三列，匿名/失败状态跨两列。八张紧凑骨架沿用相同网格；保留全部原有字段、整卡跳转与控件隔离，不改计费或数据来源。实测 Semi Checkbox 的可见外层为 span，补充 `.semi-checkbox` 交互隔离，防止点击勾选时整卡误跳转。

本轮验收：Chrome 1512/1280px 四列、1100px 三列、800px 两列、390/320px 单列，德语暗色无页面/卡片横向溢出；复制成功仍留目录、勾选/取消不跳转、点击信息区进入详情。相关模型展示、身份状态、路由和价格回归、ESLint/Prettier、主站及独立文档生产构建通过。
[控制台概览与复制反馈](2026-10-27-dashboard-overview.md)接管本篇记录的长代码复制toast遮挡问题，目录和详情复制成功不再回显正文。

## Consequences

筛选展开后目录高度随标签数量变化；保留折叠能力和抽屉。中文和本站认证字段与参考站存在必要差异，不宣称像素级复刻。保持元衡品牌、项目署名、账户权限、公告手动规则及伙伴视频计费；不复制参考站模型资料或指标。没有修改生产配置，没有发起模型调用或OAuth登录。验收发现既有长代码复制toast会短暂遮挡窄屏上部，提示消退后导航正常；本轮未更改共享复制通知行为。
