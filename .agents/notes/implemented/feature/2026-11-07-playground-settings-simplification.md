# Agent Note: 对话设置侧栏收敛

Status: implemented

## Problem

系统提示词移入侧栏后，资料、分组、参数和说明仍重复常驻，常用项需要长距离滚动；清空没有明确确认。用户确认本地收尾模型体验，不操作生产配置及钱包等页面。

## Decision

系统提示词与常用能力在前；移除侧栏分组，生成参数、高级设置与末尾模型资料默认折叠。价格摘要复用当前模型/分组目录报价，明确输入输出顺序和单位，不硬编码；默认配置仍显式发送部分参数，摘要如实显示“已启用N项”，全部关闭才显示模型默认。

恢复默认只重置提示词、生成参数、思考和工具，保留会话、消息、模型、分组。确认框说明清除范围；生成或工具续接期间禁用。清空单/多模型均需确认。提示词圆点来自当前会话保存状态，无第二份状态。思考分段按钮保留既有能力约束，未知档位能力不做承诺。

导入/导出为轻量文字操作，保留可访问名称及导入覆盖确认；资料折叠、说明改为可聚焦info tooltip。侧板展开时隐藏顶部长价格，底部资料仍可查价；不猜费用。比较区基于实际溢出显示左右箭头，手机保留标签，布局不触发请求。

## Related decisions

[回答分栏](../../implemented/feature/2026-11-07-playground-answer-columns.md)保留请求隔离与选答契约；[操作补齐](../../implemented/bug-fix/2026-11-06-playground-usability-followup.md)的价格口径保留，替代侧栏重复分组与参数常驻展示。其他钱包/渠道笔记不相关。

## Alternatives considered

- 常驻所有资料便于发现，但把低频信息放在主要操作之前，改为折叠并保留摘要。
- 所有参数关闭以展示“默认”更简单，但改变已有请求语义；保留既有值并按实际发送字段计数。
- 复用旧全配置重置最省代码，但会涉及模型、分组和消息，使用限定字段与确认。

## Verification

43项分组价格、工作区请求、并发和会话及语言资源测试通过，原Node账户存储与SSE脚本通过；局部ESLint、Prettier、Vite生产构建通过。隔离浏览器检查提示词编辑/标记/重置、消息与模型分组保留、清空取消与确认、折叠与桌面/手机布局；五模型一条失败其他四条完成，独立重试/停止仅发送相应模型；两轮比较后单模型请求只含两条选答，原未选记录仍保留。标签/箭头不发送请求。测试服务与浏览器自动回收；用户本地预览是单独显式保留服务。

## Consequences

折叠增加一次点击，摘要与明确标题保留可发现性。真实渠道质量需另行生产验收，本地合成请求不能证明上游能力。未推送或部署。
