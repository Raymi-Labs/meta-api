# Agent Note: 模型体验三栏工作区

Status: implemented

## Problem

现有模型体验将参数和聊天放在两栏，模型切换藏在参数选择框，缺少独立系统提示词入口和可直接使用的请求代码。用户参考 AIHubMix Playground，明确本轮只迁入模型标签、参数、系统提示词和代码面板的主要布局及聊天体验。

## Decision

在已迁移的 `/playground` 页面复用现有聊天渲染、请求、分组模型加载和按账户隔离的存储。桌面使用参数／聊天／代码三栏，窄屏将参数与代码变为可关闭面板。保留主站顶栏与主题。模型标签是同一对话的模型快捷切换，每次只请求当前模型；标签随账户配置保存，按当前分组可用模型裁剪，加载失败可以重试，生成期间锁定模型和分组变更。

系统提示词随 inputs 保存，复用 buildApiPayload，普通发送、编辑重试、预览和代码使用同一来源。新账户从空对话开始，不发送示例聊天。编辑草稿进入代码预览但不会自动请求。代码提供 cURL、Python、JavaScript 和 JSON，以本站公开 `/v1/chat/completions` 和环境变量令牌生成；不输出登录会话或实际密钥，公开调用用令牌确定分组，明确要求选择与当前分组匹配的令牌。自定义请求体继续独立拥有其负载，不与普通系统提示词叠加。

代码导出范围由 [SDK 代码面板](2026-10-31-playground-sdk-export.md) 扩展为三协议 SDK，保留当前负载和环境变量令牌契约。

模型信息与能力设置扩展见[信息卡与工具控制](2026-10-30-playground-model-controls.md)：复用目录价格/属性，工具回合可复制和失败重试，但禁止单条编辑/删除破坏协议。

## Related decisions

- 部分重叠：[企业导航与根路径迁移](../../implemented/feature/2026-10-25-enterprise-navigation.md)，保持 `/playground`、旧地址跳转及登录要求；本次只扩展页面内部。
- 复用：能力地图的 Playground 账户隔离与现有 configStorage；身份变化仍停止请求，不写入其他账户。
- 检索命中的模型详情、发现体验及静态安全笔记属于相邻入口，不被本决策替代。

## Alternatives considered

- 仅调整原两栏 CSS：风险较小，但不能提供模型标签和真实请求代码，不足以达到已确认范围。
- 完整迁入参考站三协议、并发模型对比及多媒体工作台：覆盖面更广，但用户明确选择先完成主要聊天工作区；现有生成图像另有入口，不在本次重建。
- 为每个模型创建独立会话：便于长期分别聊天，但会改变上下文共享语义、扩大存储和并发契约；本轮采用同一对话切换模型，生成时锁定。

## Testing

- 生产构建配本地模拟 API，在浏览器验证模型添加/切换、分组权限裁剪、加载失败重试、空模型禁用、刷新持久化、系统提示词及草稿代码复制。
- 请求日志验证流式/非流式、失败重试仅发一次、编辑重发仅发一次、停止后继续发送、自定义 JSON 不叠加系统提示词；单测验证图片、零值及停用参数，三种可执行代码在本地 HTTP 服务实际执行并核对负载。
- 浏览器验证配置导出后重新导入、自定义 JSON 校验和代码复制；账户隔离与 SSE 既有回归通过。导出改用账户存储，编辑/重试请求从 React 状态更新器移出，保留原消息图片；中止支持 AbortController 与 SSE，忽略迟到回调，未产生内容时移除空占位。
- 浏览器检查桌面三栏和 390px 手机参数/代码抽屉、亮暗主题及无页面横向溢出；未使用真实上游模型，未验证真实渠道费用或生产部署。
- `bun run test:playground-workspace`、语言资源、导航/鉴权回跳回归，目标 ESLint/Prettier、完整前端/文档构建与 `make verify-notes` 为本次提交检查。

## Consequences

标签不代表并发对比；公开代码的令牌分组与网页登录选择必须分别配置。切换语言不能清空对话，异步响应不能污染后续请求。参考站仅提供视觉与交互观察，不复制其品牌、私有源码或未实现的能力承诺。
