# Agent Note: 模型体验本地独立会话

Status: implemented

## Problem

模型体验现有单账号单段聊天保存不能保留独立话题；简单替换消息数组会让流式回调写错会话，刷新自动重发还会产生意外费用。

## Decision

入口布局由[聚焦聊天布局](./2026-11-06-playground-focused-layout.md)扩展为窄工具栏与可关闭会话面板，生命周期和本地保存规则保持。

复用既有消息、请求、模型参数与五模型比较能力。IndexedDB按账号保存独立会话，支持新建、标题搜索、重命名、删除、备份导入导出。旧账号localStorage聊天只在首次空库迁移，保留旧源副本；无归属共用历史不导入。每会话独立ID用于客户端session头，配置与草稿独立；新建仅继承模型/分组等参数，不带消息、工具结果、自定义请求体或系统提示。

仅当前与生成中的会话组件挂载；生成中可切换查看，发送使用同步互斥，不排队、不自动重试。账号切换及卸载中止请求，加载后未完成消息标记中断。IndexedDB写串行并显示失败，失败保留内存和导出入口；删除需确认且不允许删除生成中会话。Web Locks保护同账号多个标签页只能一个编辑，第二页不发送不写库。导入有大小/结构限制、生成新ID、永不自动发送。

## Existing capabilities and notes audit

复用[工作区](../../implemented/feature/2026-10-30-playground-workspace.md)、[五模型](../../implemented/feature/2026-10-31-playground-parallel-text.md)；两篇部分重叠，其消息渲染、权限与计费保持。模型目录、图片工作台及SDK导出范围不扩展。路由依旧登录后/playground → /pg/chat/completions → 原后端计费。

## Alternatives considered

- 切换时卸载所有旧会话最简单，但会中断生成，不符合用户体验；保留生成中的一个会话。
- 每个会话始终挂载保留状态容易，但重复目录请求和渲染随着历史增长，故只挂载当前和正在生成会话。
- 服务器存聊天能跨设备同步，但用户明确本地保存，本轮不增加聊天数据库和费用逻辑。

## Verification

本地单元验证新ID、空历史和无自定义请求继承、损坏备份、导入重建ID、停止状态和同步生成锁；已有账号隔离、SSE、比较模型、工具/请求/导出负载回归继续验证。隔离浏览器仅使用本地模拟请求，验证新旧对话无上下文混用、后台流继续与其他对话发送禁用、刷新中断无重发、账号/标签页隔离、重命名搜索、导入删除、存储写失败恢复及桌面/手机布局。五模型和非流式中止列入同一脚本，finally关闭浏览器与服务。

## Consequences

浏览器清理、无痕或存储回收可能丢数据，明确本地提示和备份；关闭页不保证生成继续。备份含对话正文但不包含会话鉴权，仅用户主动导出。代码提交会使用既有Git身份，不上传真实用户记录或本机私有配置。

每账号最多100个会话；导入限20MiB、每会话1万条消息，超限拒绝且不删除已有记录。不支持Web Locks的浏览器显示升级提示，不降级成不安全多写者。保存以250ms节流和串行事务记录快照，关闭时尽力刷新但不承诺强制关闭最后一刻的内容必定落盘；标签页锁在排队保存结束后释放。备份导入只接受已知配置与合法消息形状，不启用原自定义JSON请求，导入本身不发送。现有配置导出/重置在本地会话模式不再修改旧localStorage备份。
