# Agent Note: 公共页脚、政策说明与隐私选择

Status: implemented

本文的中文正文边界由[全站统一语言偏好](2026-10-25-site-language.md)扩展为随选择切换的静态译文；后台协议仍以最新配置为准，只有完整原文匹配才使用对应译文。本文的隐私选择和数据处理事实保持不变。

## Problem

首页页脚只有少量入口；用户要求参考 AIHubMix 的四栏目录和政策结构，补齐本站已有能力及政策说明。现有用户协议与隐私政策由后台配置，不能用参考站的主体、退款、保留期限或全站 ZDR 承诺替换。可选 GA / Umami 脚本当前在服务端直接注入，单独做一个隐私开关会造成设置与实际请求不一致。

## Decision

- 页脚采用产品、开发者、关于我们、条款与政策四栏；复用实际路由及导航权限。对不存在的博客、应用市场、企业定制、退役目录等不捏造功能，改用已有客户端、生图、Skills 文档等准确入口。
- 新增公共 `/legal/:slug` 说明页和 `/privacy-choices`。服务条款、隐私政策继续指向原配置页面；补充 Cookie、数据隐私、支付、ZDR、异步生成说明，使用原创中文正文。运营主体、所在地、邮箱按用户指示暂不填写。
- 共享公共页头、页脚、移动端与暗色样式，新增界面文案覆盖现有 17 种语言；中文政策正文明确标记语言，不冒充法律译本。
- 统计默认为关闭，只有浏览器明确允许才加载配置中的 GA / Umami。选择可撤回并保存，撤回后刷新停止已加载的脚本；必要登录、本地聊天和偏好存储不被一键清除。保存失败明确提示，不能声称已持久化。
- 不修改生产政策配置，不自动发布到生产，不将代码中的默认保留时间表述为已核实的生产承诺。

## Alternatives considered

- 完整复制参考站正文能快速补齐栏目，但会引入未实现的 ZDR、固定期限、退款、法域和企业身份承诺，因此只参考结构，依据当前实现重写。
- 全部链接都新增独立页面可凑齐目录，但没有业务能力支持的页面会误导用户，使用实际入口与准确名称。
- 仅写隐私说明或保存前端开关改动最少，但无法控制现有服务端统计脚本；统计注入与选择必须同时接通。
- 替换原协议页可统一外观，但会绕过后台配置与注册入口约定，保留既有协议页面和配置优先权。

## Testing

- 19 项公共语言测试覆盖 17 语言、173 个公开词条和原异步选择边界；8 项 ReactDOMServer 实际页脚渲染测试覆盖导航开关、登录 next、政策条件、自定义首页与说明页。
- 16 项统计控制测试覆盖默认/拒绝、允许、撤回、加载竞态、存储失败、跨标签与页面恢复；2 项政策路由/目录测试保持原协议入口。
- Go 根包、common、service、router 测试通过，含 SPA 与预渲染共同 HTML 配置出口、安全 JSON、失效配置与重复注入；ESLint、Prettier 与完整前端构建、五页预渲染通过。
- Chrome 在最终构建中验证五份政策页面、原后台协议正文、刷新与目录跳转；320px 下 17 语言无横向溢出，中文正文语言标记正确，明暗主题可读。自定义首页仍紧凑页脚且隐藏公共导航，进入政策页恢复完整公共壳；未知文档明确提示。隐私选择允许/拒绝及刷新后持久化经 UI 验证；已配置脚本的阻断、撤回网络边界由隔离回归覆盖，不向真实统计服务发送测试访问。
- 发布前执行 make verify-notes、diff 与发布策略检查。发布为源码/构建产物交付，不代表生产已部署。

## Consequences

统计从立即加载改为明确允许，访问统计数量会减少。新增说明仅覆盖已核实的处理类型，具体主体、联系方式、生产保留期和未消费充值退款细则仍需运营方后续补充。参考站未实现的产品不会出现在本站页脚。新增页面正文为中文，界面和目录覆盖 17 语言；后台已有协议保持配置优先，不建立新注册同意记录或替换旧文本。
