# Agent Note: 使用日志的查询一致性与紧凑布局

Status: implemented

## Problem

日志列表、导出、统计和管理员汇总各自读取表单草稿；未提交条件会影响翻页或导出，与当前可见结果不一致。列表失败被呈现为空表；宽筛选区与彩色统计标签影响扫读。

## Decision

复用现有日志列、费用解释、详情与角色接口；按 AIHubMix 实际 Request logs 页采用标题、轻量工具栏、可折叠且字段持续挂载的筛选、轻边框表格。统计保留真实消费/缓存/最近一分钟含义，不制造请求总量或缓存节省金额。

查询提交时生成独立快照；分页、刷新、重试、统计、导出、管理员榜单和分组汇总共用已应用条件。日期无效不发请求；重置显式应用默认范围。身份变化重挂载，卸载令旧响应无效；失败有明确重试。保持渠道用量跳转闭区间转换与所有权限字段。

## Existing capability review

- 页面/列/hook → router/api-router.go 的用户 self 与管理员日志接口 → controller/log.go、model/log.go；普通用户脱敏在服务端，金额仍由既有计费组件解释。
- [导出](../../implemented/feature/2026-10-17-usage-log-export.md)部分重叠：共用已应用筛选，不改变31天/10000行限制或脱敏。
- [渠道用量](../../implemented/feature/2026-09-29-channel-usage-in-management.md)部分重叠：保留渠道集合及 end-1 的闭区间语义。
- [厂商](../../implemented/feature/2026-10-21-inception-vendor.md)部分重叠：保留厂商/历史分组搜索及隐私模式。
- 日志模型复制与上游诊断仍由原组件提供；不改变错误分类和模型身份声明。
- [摘要与完整派生视图](2026-10-29-model-detail-log-view.md)：普通用户展示模式独立于原列偏好，不修改本篇的查询、导出、统计与管理员契约。

## Alternatives considered

- 仅改样式不能解决表格/导出范围不一致与失败伪装空结果。
- 照搬参考站的请求专用列会隐藏退款/系统记录和管理员排障，保留原列与列设置，优化承载布局。

## Verification

26 项条件快照、日期无效与渠道时间边界、普通用户排除管理员参数、厂商契约、错误费用解释与17语言资源测试通过；修改源码 ESLint、Prettier、主站 Vite 构建通过。

完整页面使用隔离合成 API 人工验收：提交模型后输入新草稿，分页/刷新/CSV导出仍沿用旧条件；第二页失败不显示旧表，重试保持目标页；快速挂起旧查询/统计再重置，释放旧响应不覆盖新模型及额度；统计失败有重试不显示旧金额，成功空结果单独显示。管理员渠道集合跳转保留 end-1 闭区间，汇总/榜单使用已应用模型，选人不误用草稿；榜单失败隐藏旧排名并可重试。保留管理员错误及尝试记录、消费/失败/退款/系统行、列设置与分页大小。390px 深色列表无页面横向溢出，普通用户无管理员入口。

日期无效由纯函数测试和代码分支核对覆盖；没有真实账号切换/生产数据库/真实模型调用验收。既有字段与模型复制渲染器复用，不声称重测所有历史计费场景。

## Consequences

导出改用当前已应用条件，用户必须先查询草稿；页面需明确展示已应用范围。刷新固定范围不自动扩展时间。后端/计费不改，合成数据不代表生产调用验收。

本地测试服务与临时浏览器标签在验收后清理，保留截图与日志供复核。没有后端、计费、权限或数据库变更，发布前在独立工作树从公司 main 2beec8674 提取日志相关文件与两条翻译，排除并行模型协议改动；26项定向测试、ESLint、笔记校验与主站构建再次通过。不执行生产部署。
