# Agent Note: 下游令牌音色复刻与归属路由

Status: implemented

## Problem

下游用户只能持有本站令牌，不能登录渠道所有者的百炼账号。已有阿里 TTS 支持复刻音色的合成，但缺少上传和音色管理；直接公开上游音色 ID 又无法保证租户隔离和正确账号路由。

## Decision

新增 POST/GET /v1/audio/voices、GET/DELETE /v1/audio/voices/:voice_id。POST multipart 上传 model/name/file，并要求 Idempotency-Key。同一用户的普通令牌共享音色，可售令牌单独按 token 隔离。复用 TokenAuth、运行时限流、模型权限、分组和渠道白名单。公开不透明 meta-voice- ID，记录创建时的渠道、凭据摘要和上游模型，服务端才翻译为上游 ID。

HTTP speech 按音色固定选渠；双向流增加可选 voice 查询参数用于握手前选渠，每次 run-task 再校验权限和音色状态。系统音色和既有外部音色保留，本站创建的上游 mv 加8位十六进制前缀保留为内部命名空间，不能直接绕过归属检查。已绑定渠道失效时失败，不跨账号重试；首版要求单 Key 阿里渠道，轮询 Key 池不能保证账号一致，明确拒绝。

录音限制 10 MiB、WAV/MP3/M4A、5–60秒，使用已有时长解析；不接受用户提供 URL，不引入任意地址下载。仅通过渠道配置地址提交 Base64，拒绝重定向，限时与限长响应；不持久保存录音或返回上游凭据/错误正文。创建前落库并限制每用户作用域最多20条未删除记录；幂等键绑定请求摘要。未知结果保留记录及唯一前缀，查询时尝试找回，绝不自动重放创建。使用乐观版本防止查询结果覆盖删除状态。

供应商明确的 `BadRequest.ResourceNotExist` / `BadRequest.VoiceNotFound` 视为删除幂等成功，其他错误保留失败状态，依据[官方错误码](https://help.aliyun.com/zh/model-studio/error-code)。HTTP 200 缺少 output 或携带错误码仍属失败。

## Existing capabilities and note audit

[阿里实时 TTS](../../implemented/feature/2026-10-31-aliyun-realtime-tts.md)部分重叠：复用合成和结算，此记录扩展其首版未涵盖的音色生命周期，不改变既有协议决定。文件上传相关备份、发票、桌面更新和视频提案均无音色归属/凭据路由能力，属于无关。功能地图、路由、TokenAuth/Distribute、AliTTSHelper、音频时长解析和主库迁移均已核对。用户明确本轮只做 API。

## Alternatives considered

- 直接透传百炼 customization 请求最短，但 list/delete 会暴露共享账号资源，创建后随机渠道也可能换账号；不采用。
- 复用永久文件存储可以给供应商 URL，但当前供应商支持 Base64，持久保存用户录音无必要且增加清理负担；采用有限上传后立即转交。
- 在所有渠道轮询密钥间共享音色需要可靠的账号/业务空间身份，目前没有此元数据；首版绑定单 Key 渠道，变更凭据后明确失败。

## Testing

真实TokenAuth和本地模拟百炼覆盖上传→查询就绪→HTTP/SSE/双向调用→删除；验证消费只来自合成、未知创建按前缀找回而不重放、重复删除与上游明确不存在、共享账号内用户/可售令牌隔离、模型/渠道/分组撤权、禁用渠道、凭据变更、录音大小/时长/格式、分页及响应脱敏。服务测试验证重定向、超大/缺失输出和伪成功响应拒绝。

SQLite、隔离MySQL8.0（utf8mb4_unicode_ci）、PostgreSQL16执行真实迁移（重复两次）、8路同幂等键创建、32路配额竞争及删除释放。MySQL5.7/PostgreSQL9.6最低版本未实际运行；新表使用通用GORM字段、索引与事务，无数据库专属SQL。相关Go包全量回归和TTS专项race通过。尚未对真实百炼创建音色或验证用户录音效果。

同步主分支后再次完成相关Go包回归、前端和独立文档构建、服务端构建/版本检查、发布策略与笔记门禁。固定音色路由在启用并发控制且存在更高优先级其他账号渠道时仍保持原渠道。本机前端预渲染因无 `/usr/bin/chromium` 按既有脚本跳过，未宣称浏览器页面验收；本轮无页面功能改动。

## Consequences

新增主库表需随受保护部署迁移。供应商创建成功而本地未收到响应时只能查询恢复；长期未知记录占用配额，保留可诊断状态。共享账号总配额仍由阿里限制。凭据轮换需要管理员确认音色可访问后迁移绑定，不能凭模型相同自动推断。GitHub发布不代表生产部署。
