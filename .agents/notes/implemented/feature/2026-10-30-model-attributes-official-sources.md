# Agent Note: 模型属性与厂商优先同步

Status: implemented

## Problem

详情的模态夹在定价内部，缺少最大输出及逐项能力。既有能力同步只读取社区模型库，无法把厂商官方证据与补全数据区分。

## Decision

[自动资料默认值](2026-10-31-model-official-defaults.md)扩展公开厂商来源、介绍/标签/供应商和自动更新入口；其新规则取代下文旧的字段范围与失败等待周期，人工保护及来源语义继续有效。

详情属性按用户当前要求精简展示：不显示各列来源文字/链接和底部参考提示，能力悬停及无障碍标签只包含能力名称和状态。来源继续随元数据保存并由接口返回；官方价格区域的来源展示不受影响。

[官方参考价同步](2026-10-31-official-pricing-sync.md)复用本任务的 OpenAI 文档请求与候选/并发保护，补齐独立文本参考价；模型属性的来源优先级和能力语义不变。

复用模型管理、pricing、管理员同步和主节点定时任务，在官方参考价之后、分组价格之前独立展示输入/输出模态、上下文、最大输出和能力。增加安全整数最大输出及 TEXT 布尔能力映射；缺键表示未知，false 表示明确不支持。管理界面逐项支持未知/支持/不支持，旧客户端省略新字段保留已有值。

资料同步继续采用厂商官方优先、模型库补全、按字段记录来源。OpenAI 公开模型文档不需要凭据；Claude 与 Gemini 官方 Models API 使用专用可选环境凭据，不读取或转发渠道密钥。官方适配器只使用其明确公布的字段，不从名字或接口存在推断能力。社区字段逐项补空，每字段保留来源，不能用社区值降级覆盖已拥有的官方值。官方适配器失败保留旧值；未支持的厂商由社区补全并记录对应来源。

人工配置优先、精确 ID、关闭同步、软删除和已有规则保护继续有效。能力按键跟踪自动所有权；显式 false 也是人工值。乐观更新包含新字段，防止后台覆盖并发保存。公开来源仅暴露与当前值一致的自动快照；没有自动来源的已配置字段为人工配置。属性是模型参考信息，不宣称本站任意渠道均实现相应工具。

## Alternatives considered

- 继续只用社区源最简单，但不能满足用户明确要求的官方优先及可追溯来源。
- 全部直接请求官方接口有统一权威性，但厂商字段及认证方式不同；按已验证的适配器接入，缺失保持未知或社区补全。
- 仅存支持能力列表很紧凑，但无法区分未知和明确不支持，也无法保护人工 false，因此使用布尔映射。

## Verification

管理 CRUD 与 pricing 回归覆盖保存、旧客户端省略、显式清空；SQLite、MySQL 8、PostgreSQL 16 验证迁移和新字段乐观更新、官方优先、人工 false、字段来源、失败不降级。Go 全量测试通过；一次无关支付测试出现异步日志表清理冲突，单测重跑和后续全量均通过。

浏览器回归验证1440桌面五栏、390暗色和320宽度不溢出、属性位于官方参考价之后、分组定价之前，导航与正文顺序一致；管理页改变最大输出、能力 false 和恢复未知均保存成功。OpenAI 页面解析验证1,050,000上下文、128,000最大输出、实际模态及工具支持；Claude/Gemini 的分页、认证、字段映射和拒绝重定向使用隔离模拟响应验证。17语言检查、前端和文档构建、Go 构建通过。

## Consequences

官方文档结构变化会导致适配器失效，应有界失败并保持已有数据；需要认证的 API 未配置专用凭据时只用社区补全。OpenAI 真实 Go 请求首次遇到10秒超时，独立重新验收3.31秒完成，确认自动解析链路可用；运行任务本身仍不紧密重试。Claude/Gemini 未使用真实凭据联机验收。发布与生产部署分别处理。

阿里旧别名的定向数据修复和同步入口边界见[阿里厂商归一化](../bug-fix/2026-10-31-alibaba-vendor-normalization.md)；普通人工归属保护继续适用。
