# Agent Note: OpenRouter 按原厂价限价并优先低价服务商

Status: implemented

## Problem

现有 OpenRouter 厂商渠道沿用账号默认均衡路由，不能保证按价格排序。用户要求优先最低价格、便宜服务不可用时允许回退，但上游采购价不能超过模型开发商公开 API 价；用户明确选择暂停无法核实原厂价的模型，核实后再恢复。

## Decision

复用渠道参数覆盖与管理 API，不修改账号全局设置或业务结算倍率。逐模型核对开发商公开报价和计价单位，用 `provider.sort=price`、`allow_fallbacks=true` 与按模型的 `max_price` 限制可选服务商。公开目录价不等于原厂价，开源许可免费不等于推理服务免费。不能用现有协议可靠约束额外收费的模型同样暂停。

渠道内移除待核实模型；整厂商无合格模型时停用渠道。保留恢复清单，并在参数覆盖中拒绝未知模型，避免后续自动同步直接绕过审核。变更前读取最新配置，检测并发改动，写入后核对渠道、能力表和公共可用模型集合。原厂账号隐私设置不变，不更改直连渠道、销售价、分组或密钥。普通 Chat DTO 不保留任意 provider 字段，不能把覆盖引擎对较低限价的保留行为宣传为客户端自定义限价支持。

## Existing notes audit

- [OpenRouter 厂商接入](../../implemented/feature/2026-10-31-openrouter-vendor-onboarding.md)：部分重叠；保留厂商拆分及销售价决定，本篇收紧采购路由与准入范围。
- [渠道推理档位](../../implemented/feature/2026-10-25-channel-reasoning-profiles.md)：部分重叠；复用最后执行的参数覆盖，不新增请求改写体系。
- [模型展示元数据](../../implemented/feature/2026-10-25-model-catalog-metrics.md)：相关但职责不同；显示用官方价格字段不作为路由限价的可信来源。

## Alternatives considered

- 设置 OpenRouter 账号全局价格排序操作最少，但会影响项目之外的请求，且不能落实逐模型原厂限价；使用本项目渠道覆盖。
- 用 OpenRouter 目录价作上限能保留更多入口，但用户选择以开发商公开 API 价为准，不能混用。
- 未知原厂价时继续调用可保持可用性，但无法验证成本约束；依用户确认暂停并保留恢复资料。

## Validation

逐模型审核覆盖 45 个启用渠道的 133 个型号。50 个通过、83 个暂停，剩余 21 个启用渠道。生产通过管理 API 更新并读回，50 条启用 abilities 与计划一致，销售配置及范围外渠道哈希不变。小米并发更新在写入前被预检阻止，重新读取后保留新的 V2.6 别名和映射；新增 Gemini 渠道 1638 属用户排除范围，不纳入本次修改。

真实参数覆盖引擎完成 733 项请求检查；`go test ./relay/common` 通过。公网和计量共 10 项核验通过，4 次实际推理及消费日志吻合，三次非流式返回的采购单价在上限内，暂停模型与搜索拒绝生效，临时令牌已清理。验收细节和维护步骤见[限价运维记录](../../../../docs/channel/openrouter-price-routing.md)，具体来源和单位见[逐模型清单](../../../../docs/channel/openrouter-price-audit-2026-11-01.json)。配置和凭据分离，恢复必须重新核价，不能盲目重放旧快照。

## Consequences

[Claude 企业级接入](../process/2026-11-01-openrouter-claude-enterprise.md)在用户后续授权下将本篇采购规则扩展到新渠道 1639；本篇原 45 渠道/133 型号仍为初次限价范围快照。

价格上限收窄了可调用目录；没有合格服务商就失败，允许回退不等于允许超价。服务端固定标准服务等级，屏蔽未审核收费插件及托管工具；保留客户端 function tools。

原厂价格、促销、阶梯与 OpenRouter 服务商报价会变化；静态审核有时效，不能承诺永久跟随降价。`max_price` 不提供独立缓存价字段，缓存价通过审核时逐服务商比价和允许列表收窄，不能把基础 token 上限解释成所有附加费用均受动态约束。分时与长上下文采用较低标准档固定上限，可能减少可用路由；不做昂贵长上下文验收。全局或渠道透传会绕过覆盖，必须保持关闭。此次不修改应用运行代码、版本或触发应用发布。

## Gemini 和售价口径的后续范围

[Gemini 语音、映射与汇率校正](2026-11-01-openrouter-gemini-audio-pricing.md)接管渠道 1638 和本批已核价型号的销售汇率修正；其他渠道命名及上游限价策略保持原决定。语音采用用户接受的调用前核价，不能宣传为上游硬限价。
