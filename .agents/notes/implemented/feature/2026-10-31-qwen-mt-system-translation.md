# Agent Note: 系统翻译复用 Qwen MT 与专用令牌

Status: implemented

## Problem

模型介绍后台依赖 Google 免费接口，限流会让多语言介绍长期等待。管理员已经配置 qwen-mt-flash，要求以超级管理员专用令牌复用现有渠道、额度与日志。最新主分支已补齐 translation_options 透传，复用现有 DTO 与适配测试；后台仍只调用 Google，因此只添加模型不能切换自动翻译。

## Decision

唯一运行时免费翻译入口改为共享系统翻译服务，固定调用本实例 loopback /v1/chat/completions，单条 user 消息及 translation_options，不绕过令牌鉴权、渠道选择与计费。不接受任意翻译地址、不携带浏览器 Cookie、不跟随重定向、不使用环境 HTTP 代理发送令牌。

新增根管理员设置 ModelDescriptionTranslationTokenId；0/缺省暂停付费翻译。根管理员从自身已创建且仅允许 qwen-mt-flash 的普通令牌中选择；配置只保存 ID，运行时从数据库取得密钥并复核所有者角色、状态与令牌限制。新增根管理员只读配置状态接口与模型设置卡片，令牌创建和额度管理复用现有令牌页。禁用、删除、过期或修改权限的令牌不会退回免费接口。

保留已完成缓存、内置译文及人工优先策略；新翻译使用 qwen-mt-flash 缓存前缀与独立持久租约，旧免费服务的半成品不拼接、旧限流不带入新提供商。读取时同源同语言的 Qwen 完成缓存优先于旧缓存，内置审校与人工优先级保持。新任务仍单实例串行、分块续传、持久退避；浏览请求只读缓存。

## Alternatives considered

- 直接用阿里密钥调用百炼可少一次内部 HTTP，但另建密钥管理并绕过用户要求的现有网关、额度和日志。
- 复用浏览器或管理员管理令牌可以省配置，但混淆系统管理权限与模型访问权限，且后台依赖会话；使用限制模型的普通 API 令牌。
- 在每次页面请求生成译文能即时返回，但会重复付费且拖慢浏览；保留后台缓存队列。
- 自动创建无限额令牌并默认启用减少配置，但升级其他实例时会隐式启用付费服务；改为显式绑定，并为本次已授权实例创建和配置专用令牌。

## Testing

- `GOMAXPROCS=4 go test -p 2 ./...` 通过；后端构建通过。实际 loopback HTTP → TokenAuth → Distribute → 阿里适配 → 结算测试验证用户和令牌同额扣减及消费日志，未绕过鉴权。
- 17语言、无配置零请求、旧半成品/冷却隔离、续传、人工覆盖、401/429退避与Retry-After、重定向拒绝、截断/超大响应、绑定所有权及状态不泄密回归通过。
- 隔离 SQLite、MySQL 8、PostgreSQL 16 验证令牌条件、同源新旧缓存优先级、租约及持久冷却，通过且不跳过数据库用例。
- 前端43项语言资源/模型介绍检查通过；本机负载下默认5秒时限曾超时，使用 `bun test --timeout 300000` 重跑无断言失败。图片子应用、Vite生产包和后端构建通过；预渲染按项目既有行为因 `/usr/bin/chromium` 缺失跳过。
- Chrome隔离页面验证选择令牌、保存启用、暂停、失效与冷却提示；不连接生产。实际生产已有渠道上简/繁中文调用均返回完整译文、占位符与usage，并写入消费日志；密集连续调用曾遇到本地限流，5秒间隔后成功。
- 全仓运行时扫描不再包含 Google 免费翻译调用。生产后台队列的发版后启用与持续运行另行验收，不由上述单次模型调用代替。

## Consequences

付费按实际模型渠道结算，失败重试也可能产生上游成本。模型输出仍可能改变占位符，恢复失败时不发布。未配置渠道、额度不足、令牌失效或环境关闭会暂停生成，已有译文继续显示。loopback 必须与应用监听端口一致；不支持把本机请求改投其他站点。
