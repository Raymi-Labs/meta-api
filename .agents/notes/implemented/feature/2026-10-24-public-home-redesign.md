# Agent Note: 公开首页的开发者接入设计

Status: implemented

## Problem

现有首页以密集企业网关介绍、动态端点和模拟运行指标为主，阅读负担较高，客户端、模型与文档入口分散。用户希望参考 AIHubMix 的留白、点阵背景与接入示意，让元衡首页更直观。

## Decision

复用 PublicHomeShell → Home → EnterpriseHome 的公开首页结构、/api/status 的品牌和地址、既有模型广场/下载/控制台/文档路由。首页采用居中首屏、三张接入示意、客户端入口、模型生态、可复制代码和常见问题；以原创 SVG/CSS 构建插图，不引入参考站素材或新依赖。

自定义 HTML/远程首页仍由 /api/home_page_content 优先决定。配置读取失败时保留现有回退；不改变登录和模型广场权限。端点由用户选择且不定时轮换，复制内容提供成功/失败反馈；Python/cURL 是 Chat Completions 示例，明确提示其他接口查阅文档。手机导航使用折叠菜单，随链接导航关闭，Escape 关闭后焦点返回按钮。首页/下载页切换遵循 PageLayout 从顶部开始的约定，显式 hash 保留浏览器锚点行为。公开首页继续使用轻量 zh/en 字典，不引入控制台全量国际化资源。界面示意明确标注，不展示无数据来源的可用率、余额、模型数量或实时状态。

v1.0.0-compat.62 的鼠标地图交互决定（“仅悬停运行、触控静态”及强度已由[持续轻波动](2026-10-24-world-map-ambient-motion.md)取代）：复用原 SVG 轮廓与静态底图，首次鼠标移动时采样点阵并以 Canvas 呈现局部形变、涟漪与亮度变化。坐标按 SVG 的视口矩阵转换，保留桌面和窄屏的等比留白；装饰层不接管点击。细鼠标悬停时最多 30 帧/秒、像素比上限 2，移开后回弹并停帧；滚动、失焦、后台、离屏或卸载立即停止。触控和减少动态效果设置保留静态 SVG，不新增依赖或持续空闲动画。

## Alternatives considered

- 只改原样式：范围小，但保留密集内容和模拟指标，不能达到参考站清晰的阅读层次。
- 自定义 HTML 首页：能独立上线，但重复导航、主题和语言逻辑，且绕开已有组件与构建验证；选择扩展默认 React 首页。
- 引入模型榜单：参考站的榜单信息丰富，但当前没有等价的公开榜单数据来源；复用模型广场入口，不编造排行和统计。

- 直接逐点更新 SVG DOM：点阵规模较大，持续修改大量节点增加布局和样式开销；Canvas 只在交互期间绘制，原 SVG 承担静态与降级显示。
- 全图倾斜或平移：不能体现参考站鼠标附近的局部点阵起伏，选择按距离衰减的局部形变。

## Testing

- v1.0.0-compat.62 地图动态补充验收：Chrome 明暗主题跨区域鼠标跟随、移开复位、首页按钮跳转、返回/刷新、390px 布局与滚动正常。`bun run test:world-map-motion` 22 项通过，覆盖单一 RAF、回弹停帧、触控/减少动态效果、可见性中断、运行时偏好切换、letterbox 坐标、缩放和卸载清理；完整构建与五个公开路由预渲染通过。

- 本地真实 React 应用壳、隔离只读 API fixture：Chrome 宽屏/390px、中英文/亮暗主题正常，无横向溢出，正常首页无浏览器错误。
- 实际复制 Python/cURL 和 /v1/responses，确认地址/换行及成功提示；端点经过多次交互仍保持选择。FAQ 展开和手机菜单键盘关闭正常；从页面下部进入下载页时回到顶部。
- 公开模型入口进入 /pricing，需要登录的模型入口与创建令牌入口进入 /login；自用模式不显示注册。
- 自定义内容仍优先且没有默认导航；配置 503 时保留已缓存自定义内容，无缓存时显示默认首页。
- 相关 ESLint、Prettier、前端生产构建及五个公开路由预渲染、相关既有前端回归、make verify-notes 和发布策略检查用于发布前验证。

## Consequences

首页复用已有能力，视觉内容与实际入口一致，保留 New API / QuantumNous 版权与归属。复制示例不包含真实密钥，不自动执行模型请求。没有新增后端接口、依赖或数据库变更。

原创插图属于界面示意，不表示真实账号数据、模型实时可用性或官方合作关系。静态模型生态可能随平台配置变化，因此明确以模型广场为准。页面不引入公开榜单数据源，榜单功能留在本次范围之外。

本地验收不能代表生产部署；自定义首页启用时不会应用默认首页设计。GitHub Release 与 Linux 附件/双架构镜像需另行确认完成，不自动上线生产。
