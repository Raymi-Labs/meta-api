# Agent Note: 按厂商补充 OpenRouter 模型渠道

Status: implemented

## Problem

生产的模型能力来自渠道与 abilities，不是源码预设或 models 展示资料。用户要求补充 OpenRouter 上尚未接入的模型，每个模型厂商一个 OpenRouter 渠道，复用已有模型的入口而不重复加入。

## Decision

以 2026-10-31 OpenRouter `/api/v1/models` 文本目录快照与生产启用渠道、模型映射交叉核对。排除腾讯、字节、阶跃、Qwen、GLM、OpenAI、Google、xAI、Anthropic；用户进一步确认跳过 batch、自动路由及 latest 特殊入口，保留具体模型和免费版本。Meta 与 meta-llama 合为一个厂商。

新增渠道复用类型 20 和现有 OpenRouter 凭据，通过应用管理 API 创建，所有渠道使用独立 OpenRouter 分组且倍率为 1。模型名采用 OpenRouter 完整 ID，避免厂商命名冲突。先补价格与展示资料，再启用路由；不停止应用、不直接写生产业务表、不更改已有渠道和价格。

153 个候选创建为 46 个厂商渠道，实际启用 145 个模型。4 个受账号训练隐私设置限制、2 个要求认可的代理应用、2 个上游已失效的条目不进入启用渠道能力，元数据保留为关闭状态。受限模型的恢复依赖真实上游条件变化，不能通过关闭隐私保护或伪装应用身份获得通过。所有新渠道禁止单个模型失败自动停用整个厂商渠道；分组加入现有 AutoGroups 末尾。

用户指定模型价格栏为上游美元价格 × 6.8 × 5，即 ×34。生产额度使用自定义能量值，展示汇率为 1；沿用「接入阿里模型」的数字填入规则，不额外改变全站换汇或充值比例。输入、输出、缓存、音频 token 保留各自单位；长上下文与分时价格复用现有阶梯表达式。上游目录的创建时间不当作模型发布日期。

后台价格数字与前台人民币金额必须区分：现有充值折算为 ¥0.2/能量，后台 34 能量对应前台 ¥6.8。本次不把用户指定的后台数字再次乘以充值兑换的倒数。搜索单价虽然已配置，当前适配器没有完整的搜索次数归一化；独立推理附加价同样不能由普通输出倍率精确表达。这些计费边界明确记录，不将价格配置成功解释为全部费用均已正确结算。

保存不含凭据的导入清单、变更前快照、执行结果与测试结果。密钥与管理凭据仅在服务器内存中使用，不进入 Git、命令参数、日志或本地清单。全局映射配置每次写入前重新读取并合并，验证未覆盖其他模型。

## Alternatives considered

- 单一渠道容纳全部模型最省操作，但不符合用户明确的按厂商管理要求；按厂商拆分并共享一个倍率为 1 的分组。
- 直接导入全部 452 个 ID 容易实现，但会重复已有模型、纳入用户排除厂商及当前普通聊天接口不适用的 batch/自动路由；使用明确排除及去重规则。
- 直接修改数据库可一次写入，但会绕过应用校验及缓存刷新；使用现有管理 API，数据库仅作只读核验。

## Validation

153 项渠道短请求测试与必要复测后，140 个启用模型获得成功响应；另 4 个持续上游限流/暂不可用，1 个深度研究模型超过 100 秒，保留入口但不标记实测成功。公网目录、令牌选择器及受限令牌 `/v1/models` 的集合均为 145 项。

7 次公网实际请求覆盖普通文本、免费模型、分时与阶梯价格、结构化提取、代码修改和流式终态；正文、usage、分组及消费日志均核对，扣费按目录 ×34 逐条重算一致，免费模型扣费为 0。长上下文、峰时、真实音频及全部工具能力未做真实验收。既有各项价格映射逐项比较未改变。详情、未启用原因与逐模型清单见 [运维记录](../../../../docs/channel/openrouter-vendors.md)。

## Consequences

免费模型限流、供应商路由和账号权限可能变化；本次静态快照不自动追价或自动增加模型。联网搜索、独立推理等附加费用仍有结算限制，不能宣称所有工具及模态均已验收。回退使用明确的新渠道 ID 与新配置键，不以整份旧 option 覆盖当前配置。这里仅记录已经落地的配置，不发布新的应用版本。
