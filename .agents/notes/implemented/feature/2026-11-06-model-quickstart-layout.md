# Agent Note: 快速开始协议按钮与语言选择布局

Status: implemented

## Problem

模型详情将协议放在外层下拉、语言放在代码标题栏，三种文本协议不可直接比较。用户要求参考横向协议按钮和相邻语言下拉的布局。

## Decision

复用 ModelQuickStart 的示例、选择状态和复制逻辑；工具栏左侧按 Chat Completions、Messages、Responses 顺序展示协议按钮，右邻七语言下拉，操作链接在右侧，复制按钮放在代码区右上角。其他已声明协议继续有入口，未知或媒体模型不强行补文本协议。未声明模板继续明确标注，默认已声明和 Responses 深链预选保持原规则。手机允许工具栏换行、协议条内部滚动，代码横向滚动不撑开页面。

## Existing notes audit

- [原协议选择](../../implemented/feature/2026-10-26-model-protocol-examples.md)：部分取代“协议使用下拉”的布局决定，保留模板资格、未声明提示、默认选择和按模型隔离状态的理由。
- [接入信息合并](../../implemented/simplification/2026-10-30-model-detail-quickstart-only.md)：保留快速开始作为接入入口及 Responses 深链和旧锚点。

## Alternatives considered

- 保留两个下拉改动较少、能容纳很多协议，但隐藏了三种文本协议，不符合本次明确要求。
- 固定只显示三种文本协议更接近参考图，但会删除 Gemini、Images、Decisions 已有示例入口；按钮使用现有生成结果，只调整文本协议展示顺序。

- 本次源码快照执行主站构建、五条路由预渲染、文档构建；格式、静态检查与笔记校验通过。

## Consequences

用户可直接比较协议，并在同一工具栏选择语言。按钮支持 Tab 聚焦和 Enter/空格选择；窄屏在协议条内滚动、工具栏换行。代码只做布局调整，保留请求内容、配置地址和模板资格；不发起真实模型调用、不更改后台权限或计费。其他任务工作区差异不进入本次提交。
