# Agent Note: 简洁令牌创建与分组选择

Status: implemented

## Problem

创建令牌的窄侧栏把供应商、分组和说明藏在下拉菜单，额度和访问限制占据主流程。用户需要直接比较分组说明与本人适用倍率，并保留编辑原值。

## Decision

创建弹窗的名称区使用淡蓝底与清晰边界。名称为空或仅空格时沿用表单校验拒绝提交，显示“请输入令牌名称”与红色区域并聚焦名称；有效输入恢复正常。名称错误不展开无关的额度/高级设置，也不发送写请求。该局部校验与首选分组/故障切组功能共存，编辑原值和限制保留规则不变。

分组按当前适用数值倍率稳定降序，同倍率保持目录顺序，动态/未知置后；整行名称、说明、倍率及空白可选择，收藏、展开说明和文本拖选不触发选择。保留原生 radio 的键盘/label 行为，父行不重复触发选择。详情模型名使用独立复制按钮，浏览器 Clipboard API 成功后才提示成功，拒绝或缺失时提示手动复制；不使用忽略失败返回值的旧 execCommand helper，不写入模型限制。

令牌列表顶部常用操作与搜索筛选分两行，批量操作只有选中令牌后才出现，并显示选择数量；原启用、禁用、复制和删除确认流程保持不变。窄屏筛选分两列或单列，不挤压操作按钮。复用 TokensActions、TokensFilters 和原 hook，没有新增写接口。

创建使用宽弹窗，编辑保留侧栏，两者复用分组选择组件。供应商/收藏/搜索只筛选，点击分组才写入 group。后台说明直接显示在名称下，两行截断可主动展开；倍率与星标固定右侧，详情按需展开。额度/有效期、访问限制折叠但字段持续挂载，套餐和可售限制保持原有语义。沿用 /api/user/self/groups、/api/token/models、/api/token/channels 和原 token 写接口；权限加载失败不提供旧候选。

模型异步响应按请求序号隔离；编辑加载不裁剪原限制，只有主动换组才同步有效选项。创建未选组、编辑未加载、联动未完成时不能提交；失败保留输入。

分组厂商命名扩展见 [Inception / Mercury 分类](2026-10-21-inception-vendor.md)，继续遵循供应商筛选不写 group、不扩大权限的约束。

## Existing capability review

- EditTokenModal → token 与 user/self/groups 路由 → controller/group.go 的 GetUserGroups → service.GetUserGroupRatio 已返回可用组和专属倍率。
- [个人收藏](2026-10-04-token-group-favorites.md)部分重叠，保留浏览器/账号隔离和权限交集，入口改为列表星标与收藏筛选。
- [列表倍率](2026-10-07-token-list-group-ratio.md)部分重叠，复用零倍率/auto/未知边界，不改列表。
- 命中的 Claude 计费提案、Kimi 真实验收与该 UI 无关，不改其决定。

## Alternatives considered

- 保留双下拉占空间小，但分组说明和倍率不易并排比较。
- 三栏固定详情能同时查看全部信息，但降低小屏可用空间，用户确认优先简洁，改为按需详情。
- 新增后端目录与云收藏可统一元数据，但现有接口足够本轮目标，不引入数据库或权限新契约。
- 仅加大圆圈可减小修改范围，但说明/倍率/留白仍不响应，采用行点击并显式排除子按钮；整个行改成一个 button 会嵌套收藏按钮，保留原生 radio。
- 批量操作全部放“更多”可再省空间，但增加已选择用户的操作步骤，选择在有选中项时直接展示。复制复用旧 helper 代码更少，但它忽略 execCommand=false，会出现假成功，因此此处使用有明确返回结果的 Clipboard API，失败保留可选择文字。

## Consequences

弹窗与折叠改变布局，隐藏字段必须持续注册，不能重置额度/限制。后端说明按纯文本展示，不推断性能承诺。已有编辑数据可能包含不可选值，必须保留展示而不能成为创建候选。用户授权提交并合入主线；服务器部署与线上验收另行进行。

主界面可直接比较说明及倍率，健康统计只在详情展开时挂载；移动端厂商横向滚动。说明是否超出两行按实际尺寸测量，展开按钮独立于选组，避免误选。额外维护一个选择组件和响应失效机制；收藏仍只在本浏览器保存，不新增后台元数据。未来需要跨设备收藏或后端厂商分类时再评估接口扩展。

对抗性审查重点是筛选不能写 group、零倍率不能视为缺失、旧模型响应不能裁剪新选择、编辑加载不能清空已有模型/渠道限制、折叠不卸载字段、失败不清空输入。保护账号切换和重开时的独立权限快照；现有后端权限仍是最终边界。
