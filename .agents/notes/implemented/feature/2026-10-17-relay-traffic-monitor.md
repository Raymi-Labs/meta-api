# Agent Note: 跳板整机流量监控与测速口径

Status: implemented

## Problem

Flawless 仅有 LibreSpeed，不能持续记录整机日/月流量，也不能将当前业务速率与主动测速结果混为一谈。

当前权限与展示已由 [公开轻量监控](2026-10-17-public-relay-monitor.md) 部分替代。以下独立认证及完整页面描述为初版决定；采集权限隔离、持久化统计和测速口径继续适用。

## Decision

复用 vnStat 持久化 ens3 统计，systemd timer 每分钟生成只读快照及有界延迟历史；由既有 HTTPS Nginx 在独立 Basic Auth 路径展示。凭据仅保存于服务器及用户本机私密文件，不进入 Git。网卡流量从监控安装开始，内核启动后累计另列，不假装有历史数据。采集失败显式显示过期/错误；保留现有测速程序，不持续运行吞吐压测。

迁移笔记与本决策部分重叠：复用其主域名 HTTPS，但新监控的计量口径与权限属于新增能力；既有渠道用量笔记是应用计费口径，与网卡统计无关。

## Alternatives considered

- 只查内核网卡计数：开销更低，但重启归零且缺乏日/月历史。
- 完整 Prometheus/Grafana：可扩展指标更多，但当前单机流量需求无需增加数据库及常驻 Web 服务。
- 公开监控：省去登录，但会暴露业务流量变化，因此仅管理员密码访问。

## Testing

线上 HTML/JSON 未认证返回 401、正确认证返回 200；vnStat/采集 timer 为 active，采集进程退出码为 0；日/月累计已产生非零数据。部署后主站状态接口复验。线上认证由 HTTP 客户端验证，浏览器自动化不能处理 Basic Auth，布局用经认证取回的同版本 HTML/真实快照核对；390px iframe 无整页横向溢出，刷新及过期提示可见。LibreSpeed 直连与中转上传下载均已实际完成。

## Consequences

网卡收发相加并非供应商计费口径；中转流量可能在网卡进出各计一次。ICMP 与 HTTP 延迟不是同一指标；当前电脑 VPN 会影响主动测速。监控故障不应阻断业务反代。

## Deployment details

实现位于 `scripts/relay-monitor/`；新机为 155.103.118.155，独立监控路径 `/relay-monitor/`，无新公开监听端口。systemd 采集账号无 shell，仅写状态目录。页面刷新 30 秒，采集 60 秒；历史最多 1440 个样本。时区初始化时保留了初装数据库备份并重新开始正式统计，正式累计起点为北京时间 2026-10-17 01:08:51，不保留错误时区的试运行日统计。后续更新不得重建数据库。日期标签由服务端固定北京时间生成，避免浏览器时区扩展改写。

未修改旧跳板、应用鉴权、计费、数据库或供应商套餐；不发布应用版本。密码只写入用户本机权限 600 的凭据文件和服务器的 htpasswd，仓库不保存凭据。相关入口迁移边界见 [迁移笔记](../architecture/2026-10-11-qiyun-reverse-proxy-migration.md)。
