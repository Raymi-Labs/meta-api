# Agent Note: 令牌分组个人常用入口

Status: implemented

## Problem

同一供应商下分组过多，创建与编辑令牌时重复翻找。现有 EditTokenModal 的供应商筛选、健康显示和 /api/user/self/groups 可选范围可复用；收藏不能成为权限来源。

## Decision

在既有创建/编辑表单加入跨厂商的“我的收藏”可搜索入口和当前分组收藏按钮。收藏按登录用户 ID 隔离存于本浏览器，声明不跨设备同步。仅与本次成功加载的可选分组取交集；编辑时为保留旧值补入的失效组不可成为收藏捷径。点击收藏项仍使用原 group 字段与模型加载流程。全部分组继续可用，不自动改变默认选择。

## Alternatives considered

- 用户自建文件夹能多层分类，但增加命名、搬移和维护负担，与快速选择目标不符。
- 后端收藏可跨设备同步，但需新增账号配置契约；本次优先不改变服务端，跨设备需要时单独扩展。
- 只优化搜索改动小，但重复选择仍需每次输入；保留搜索并补常用快捷入口。

## Consequences

[简洁创建窗口](2026-10-20-token-create-selector.md)将创建/编辑的收藏入口迁移到分组列表星标和收藏筛选，沿用本篇存储与权限边界；旧浏览器回归入口转发到覆盖新交互的统一套件。

同入口的 [令牌列表分组倍率](2026-10-07-token-list-group-ratio.md) 复用服务端只读计算，不改变本篇的收藏/权限刷新决策。

常用组跨厂商直接可选；全部分组和现有健康/模型/渠道联动仍保留，默认选择不变。代价是增加一份本地偏好，不支持跨设备或与 YuanHeng 客户端同步，后续如要求同步需要设计服务端偏好契约。浏览器阻止持久化时明确提示且保留内存状态。不保存账号姓名、令牌或密钥。收藏候选始终由本次可用组接口决定，独立复制后再给旧令牌补展示值，避免旧值混入收藏权限候选。

活跃笔记检索未发现同一能力归属；生图自动选组记录与此入口无关。未修改服务端鉴权/计费/路由，不依赖真实模型请求或生产部署验证。浏览器模拟不能替代部署后真实账号验收。

## First-principles and adversarial review

目标是减少重复选组时的查找成本，不是增加新的业务分组或路由层。保留原供应商/全部分组入口，收藏只做用户主动建立的捷径；相比自定义文件夹减少命名和整理负担，相比自动最近使用不引入行为跟踪。无需改变服务端数据库和权限契约，明确接受本浏览器而非跨设备同步的边界。

对抗假设包括：伪造收藏中的无权分组、编辑旧令牌带入失效组、收藏按钮误触提交或模型刷新、存储拒绝写入、账号切换期间旧请求晚到、权限接口失败、键盘与窄屏无法选择。除了既有回归，本轮增加请求计数断言、权限接口失败、故意扣住旧请求并在新账号请求之后释放的真实浏览器回归。

复测暴露 API.get 默认按 URL 合并未完成请求：组件请求序号无法阻止新刷新共享旧网络响应。此入口复用已有 `disableDuplicate: true` 能力，让每次打开/账号切换独立获取当前可用组；旧响应仍按请求序号作废。不修改全局 API 合并策略，避免扩大到其他页面。

新增对抗回归在修复后通过：权限接口返回失败时无收藏候选；旧账号请求晚于新账号返回也不能恢复撤销的收藏；星标增删不产生模型权限查询或令牌提交。提交前在隔离的 main 基线上复跑相关测试与主网页构建，不夹带其他本地功能。
