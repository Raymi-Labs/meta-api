# Agent Note: 企业服务统一公开入口

Status: implemented

## Problem

企业工作空间已经有钱包、成员预算、审批和用量页面，公开企业定制页仍主要介绍通用API和模型生态，与首页重复。用户希望按已讨论方案继续优化并在本地验收。所有者与管理员权限混淆，入口应指向真实角色可用功能。

## Decision

保留/enterprise路由、公开壳、原联系方式和17语言，顶栏/页脚名称改为企业服务。公开页以真实企业功能与角色权限为主，移除重复模型Logo、营销口号与线路演示；技术接入链接到已有文档，示例生成器及其测试保留。

基于useEnterpriseSelf已有身份选择入口：访客联系开通并可登录回跳；已登录非成员联系开通；Owner/Admin进入企业工作台；Member查看我的额度并进入令牌管理；平台管理作为平台账号的单独入口，不把平台权限视为企业身份。加载/失败不展示旧账号信息或误判为未加入；冻结企业显示状态并保留管理入口，不承诺可调用。功能关闭仍保留公开介绍和Root管理入口。

角色说明明确Owner由平台开通时指定、可管理本人预算及审批本人申请；Admin处理普通成员申请，本人申请交Owner；Member使用与申请本人额度。现有待办按上一修复直接处理。未实现的体验区、视频音乐、MJ与Realtime企业付款不宣传为可用，不承诺SSO或部门管理。

## Alternatives considered

删除导航会让新客户失去开通入口；将所有人直接送工作台会让访客和非成员撞权限错误；继续增加宣传区块会加重重复。复用现有身份接口和实际角色，不增加后台表单、CRM或自助开通API。

## Verification

入口/审批/身份/示例/导航/页脚/公开语言共46项通过；36项语言资源检查通过，Vite构建通过。浏览器使用真实公开壳和组件、合成身份API：访客、Owner、Admin、Member、非成员、冻结、功能关闭、平台角色与错误重试通过；17语言390px暗色页面无整页横向溢出，中文桌面/手机与德语长标题明暗截图核对。身份退出切号保护复用已有状态测试，本次未执行真实登录、收费调用或邮件发送。最终进度写入docs/reviews，本轮只本地修改与提交，不推送或部署。

## Consequences

角色说明不能替代后端鉴权。公开文案区分代码已支持与实际企业开通；联系方式使用原有业务邮箱，不上传用户截图或个人信息。此次页面内容取代旧介绍，但保留原导航/路由及上游署名。
