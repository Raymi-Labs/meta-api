# Agent Note: 模型详情头卡与官方参考价

Status: implemented

## Problem

详情顶部名称、介绍与操作分散，现有价格来自本站分组计费，不能作为厂商官方价。用户要求参考附件的头卡，并确认独立维护官方参考价、下方保留本站分组价。

## Decision

[厂家来源约束](../bug-fix/2026-11-01-manufacturer-official-pricing.md)收紧公开价格来源并允许旧 OpenRouter 资料被厂家取价替换；保留人工厂家价及同步失败保护。

“仅手工维护、来源不抓取”的边界由[官方参考价自动同步](2026-10-31-official-pricing-sync.md)部分取代：固定 OpenAI 官方模型文档可补齐标准文本价格，人工填写的来源 URL 仍不抓取，人工价优先。其余展示、币种与计费隔离规则继续适用。

[分组价与官方价对比](2026-10-30-model-group-official-discount.md)将分组列表前移到官方参考价之后，逐项展示所选官方档位与分组价的差额；完整动态规则仍在快速开始之后，顶层官方表和实际计费不变。

复用模型管理的 display_name、description、icon、vendor，扩大头卡并将介绍完整展示在名称下。模型使用 official_pricing 展示元数据，通过管理员现有模型 CRUD 保存到可空 TEXT，按精确模型返回既有 /api/pricing。配置包含币种、来源链接、说明、有序档位及可选输入/输出/缓存/按单位价格；缺失与零价明确区分。管理员使用表单配置，不要求输入 JSON。

官方参考价标题后以信息图标承载说明：悬停或键盘聚焦时展示参考用途提醒、实际自动更新时间和完整价格规则，支持 Esc 或点击外侧关闭；长内容限定高度并滚动，窄屏限制宽度。正文仅保留价格表和来源链接，原说明/时间/规则字段及展示条件不变。

官方价独立于分组、套餐、币种换算和扣费；详情先显示官方参考价，再显示原本站价格。旧客户端省略字段保留，空对象清除；同步不得覆盖人工官方价。宽泛名称规则不承载价格，防止给不同模型错误赋价。人工填写的来源仅链接，不由服务端访问。

## Existing notes audit

- [展示元数据](../../implemented/feature/2026-10-25-model-catalog-metrics.md)：部分重叠，复用介绍和管理入口，扩展独立参考价。
- [接入顺序](../../implemented/feature/2026-10-29-model-detail-log-view.md)：部分重叠，保留同名 ID 不重复、复制、快速开始先于完整分组明细，新增官方区块置顶。
- [详情页](../../implemented/feature/2026-10-25-model-detail-page.md)及[参考布局](../../implemented/feature/2026-10-26-reference-layout-alignment.md)：保留权限、路由与健康，只替换头卡布局。
- 健康、协议、日志、钱包、目录缓存价格笔记均无决策变化。

## Alternatives considered

- 直接展示未乘分组倍率的基础价无需新存储，但不是独立厂商价格，用户明确选择独立配置。
- 在前端写死参考站金额可迅速复刻截图，但不能维护、不能证明官方来源，改用可配置表单且不自动填入附件价格。

## Verification

- 2026-10-31 提示布局调整：价格与分组对比 8 项回归、ESLint、Prettier、主站及图片应用构建通过；Chrome 验证指针进入图标展开、键盘聚焦、Esc/外侧关闭、完整说明/动态时间/规则，390px 宽度无整页横向溢出。复用现有组件与字段，未新增定价逻辑测试。

- Go 全量测试与服务端构建通过；官方配置验证、模型 CRUD → pricing、旧载荷保留、同步保护、缺失与零价、非法数值与链接覆盖。
- SQLite、MySQL 8.0、PostgreSQL 16 隔离实库验证旧表新增字段、保存、清空、重复迁移。清空显式存储 `{}`，避免 SQL NULL 读回复用对象时残留旧值；旧记录 NULL 作为未配置读取。
- 10 项相关前端测试、ESLint、17 语言资源检查、主站及图片应用构建通过，五页 Chrome 预渲染通过。
- 真实 React 页面 + 合成 API 验证编辑介绍/价格、增加档位、清空并回读、独立币种/单位、官方来源、空态、桌面/390px 暗色/320px 无整页溢出。原详情/复制/快速开始顺序与日志浏览器回归通过；截图保留在本地验收产物中。

## Consequences

官方价不依赖用户分组或价格显示设置，未知字段不会伪装免费。仅精确模型支持最多20档，币种 USD/CNY/EUR，单位覆盖百万Token、次、张、秒、分钟、小时；其他费目可用独立档位的价格列或说明维护。人工配置的来源链接不自动抓取或验证时效，维护责任仍在管理员。

复用既有模型管理权限与目录可见性，无生产数据改写。未填写且未成功自动同步官方价的模型显示暂无数据；附件金额不预置为已核验官方价。发布不等于生产升级，真实账号及实际扣费未执行。
