# Agent Note: 模型广场隐藏供应商下不可用筛选项

Status: implemented

## Problem

选择供应商后，零匹配分组仍占据侧栏空间。桌面侧栏与移动筛选弹窗共用筛选组件；当前模型计数会排除本维度条件，不能根据最终结果列表或分组名称猜测可用性。

## Decision

复用 usePricingFilterCounts 的模型集合和各筛选组件的 disabled/零计数判定。选择具体供应商（含未知）时，分组、标签、计费类型、端点隐藏未选中的不可用项；供应商列表不变。共享按钮组新增默认关闭的选项及显式 resetValue，仅模型广场启用。

已选项与“全部”保留且可点击，以避免搜索无结果时出现隐藏条件；不自动更改筛选状态、价格分组或权限。折叠高度按可见项数量计算。加载阶段继续显示骨架。

## Alternatives considered

- 在公共按钮组全局隐藏禁用项：改动小，但会影响其他管理页面，故采用显式开关。
- 隐藏所有零匹配项并自动清空已选条件：列表最短，但搜索与刷新会静默改变用户意图和价格分组，故保留已选项及解除入口。
- 仅隐藏名称不属于供应商的分组：无需动态计数，但跨供应商共享分组会被误删，故使用模型 enable_groups 与后端 usable_group 的交集。

## Verification

`node web/scripts/pricing-filter-items.test.mjs` 检查默认兼容、选中零值、重置、倍率字符串和数字选项。`node web/scripts/pricing-filter-browser.test.mjs` 使用本地 Vite、无真实客户数据的 API fixtures，覆盖桌面及移动筛选、已选项恢复、共享零倍率分组、无权限分组排除、未知供应商、搜索空结果和重置。浏览器脚本在 finally 中关闭浏览器；可通过 PRICING_SCREENSHOT_DIR 保存检查截图。

主站 Vite 生产构建通过；不重建未修改的生图子应用，不声明完整 Docker 构建或线上部署已完成。依赖复用本机已有 node_modules，未修改锁文件；构建仍有第三方 eval、旧 Browserslist 与大分包提示。

## Consequences

侧栏减少无效项与无用折叠区域。保留的已选项可能显示零计数，这是可解除的当前条件，不代表有模型。默认关闭的共享组件开关避免影响其他页面；启用者须显式提供重置值。没有数据库或后端变动；未来新增筛选入口需同步传入开关。不能据此改变后端权限或计费。
