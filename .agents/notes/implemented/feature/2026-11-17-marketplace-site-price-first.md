# Agent Note: 模型广场优先展示本站收费

Status: implemented

## Problem

用户要看到本站实际标价，详情顶部却优先展示缺失的官方参考表。缺官价并不等于缺本站价。继续追查官价或保留空表不能解决用户的价格阅读需求。

## Decision

复用getModelCatalogPricing和ModelGroupRows，把本站价格放到详情首个内容区。已有有效官方表继续保留在后面，无有效表则连同导航隐藏，不将本站售价冒充官价。卡片、列表、详情共同按原始实际金额识别零价，明确显示免费，非零仍使用既有价格计算与单位。名称含free但实际非零时必须显示非零，微小正价不因舍入视为免费；倍率视图保持倍率语义。图片按张计价在列表主价列展示完整分项。

[数字零价与明确健康状态](../bug-fix/2026-11-17-numeric-zero-health-states.md)根据用户最新要求替代本文的免费文字方案：所有价格恢复原数字和货币格式，仍保留本站价格优先及隐藏空官价表。

## Existing notes audit

[参考价范围](../../implemented/feature/2026-11-17-official-price-reference-scope.md)仍保留历史FAQ、一方来源与窄屏说明；本决定替代其无官价仍留标题及未知标记的展示。复用原账户可见分组、特殊倍率、时段、充值换算及阶梯，不更改计费配置。

## Alternatives considered

把本站价格写到官方参考价字段会伪造对比依据；重复新增顶部价格卡会造成多份状态与筛选不一致。直接前移已有本站分组价格区既完整又沿用现有计价。根据free后缀填零与用户现有价格可能冲突，因此以原始有效金额为准。

## Verification

无官价模型的卡片、列表、详情可读出本站主价；详情首区是本站价格，无空官价表或失效导航。实际零价显示免费，非零与极小正价不受影响，倍率视图不改；图像张价、视频秒价、文本阶梯与K/M语义保留。覆盖公开目录提取和关键UI流程，测试结束遗留进程0。

## Consequences

本站价格按可见分组变化，不能给出独立于账号权限和分组的假定统一售价。无配置的费项不虚构0；不适用的列表输出/缓存列可保持破折号，主价格必须有正确单位和金额。没有提交、合并或生产发布动作。

验收：226项公开目录快照全部保留本站主价格，零价/付费/微小正价/无配置/倍率模式、分组/时段/汇率/阶梯及视频单价回归通过。浏览器核实卡片与表格的免费、文本和按次价格，详情首区、缺官价隐藏、已知官价保留、千问阶梯、视频秒价及手机无溢出。前端构建、17语言、ESLint与五页预渲染通过；这是本地修改，未发布。
