# Agent Note: 模型广场协议声明与示例分层展示

Status: implemented

## Problem

模型广场的端点标签暴露 openai 等内部枚举，普通 OpenAI 渠道默认声明 Chat，用户容易把目录标注理解为本站只支持 Chat。详情已提供未声明的 Responses 示例，但卡片、列表、筛选和端点区未形成一致可见的解释。

## Decision

复用 `/api/pricing` 的 supported_endpoint_types，抽出共享协议描述与文本示例资格规则。卡片/列表展示声明的友好名称；对已有文本声明且无图像、视频、音频/嵌入专用标记的模型，额外展示明确标记未声明的 Responses 示例入口。详情与快速开始共用同一规则，未声明示例不出现在声明能力或筛选计数中；无协议时保持未知，自定义端点保留原名称/路径。路径只是文本，不执行外部链接或模型请求。

## Existing notes audit

[协议示例](../../implemented/feature/2026-10-26-model-protocol-examples.md)部分重叠，保留默认选已声明与示例生成不改原数据的约定，本篇扩展广场可见入口与端点解释；[模型详情](../../implemented/feature/2026-10-25-model-detail-page.md)继续管理身份/导航边界。使用日志由其独立笔记管理，不属于本篇。

## Alternatives considered

- 对 GPT 全部追加后端 Responses 声明，现有页面即可显示，但模型名不能证明每个分组/上游支持，会污染筛选与文档能力。
- 仅修改 openai 标签为 Chat，不改变数据，但用户仍看不到 Responses 接入入口。
- 新增逐分组在线协议探测能提供强证据，但涉及收费、凭据和后端任务，超出本轮本地展示范围；保留未来按实测更新声明的入口。

## Testing

- 新增协议展示、既有快速开始和运行时文档共23项通过，覆盖只声明 Chat、Responses、多协议、重复/非法声明、自定义路径、恶意模型名、无声明及媒体模型；生成示例不变更输入数据，声明计数不被扩展。
- 当前页面的独立 Chromium 合成流程覆盖卡片/表格、详情锚点、协议与语言切换、复制及真实声明筛选，桌面浅色/390px手机深色通过；不调用外部服务、不执行写接口，浏览器关闭由 finally 保证。
- 筛选可见性、厂商选择、价格单位回归与详情鉴权、真实 Semi 表格分页通过；17语言18项资源校验、修改源码 ESLint、完整前端构建和五个页面预渲染通过。
- 旧 pricing-filter-browser 在已移除的 pricing-group-list 侧栏选择器超时；旧 pricing-wallet-layout 在历史表头背景色断言超时。这两项未标为通过，不扩大本次范围重写旧布局验收；以当前页面独立流程覆盖本次交互。
- 与2026-10-29的公司main合并后，68项相关回归、桌面/手机深色协议浏览器流程、36项语言/文档校验再次通过；主站Vite构建及五路公开页面预渲染完成。构建保留既有大包、Browserslist和第三方eval警告。测试浏览器与本轮预览服务已关闭。

## Consequences

示例可见仍不等于可调用，必须持续显示未声明和分组确认提示；不改变运行时转发与价格，不把此前 Responses 审查缺陷算作修复。合入最新main保留已提交的钱包、日志、发布日期排序和缓存价格改动；提交合并不等于生产部署。

[接入信息合并](../simplification/2026-10-30-model-detail-quickstart-only.md)移除独立详情的重复端点区；广场 Responses 示例改到快速开始并预选模板，旧 #endpoints 兼容跳转；声明元数据与筛选语义不变。
