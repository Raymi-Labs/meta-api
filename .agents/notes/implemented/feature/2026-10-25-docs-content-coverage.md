# Agent Note: 文档主题覆盖与多语言内容门禁

Status: implemented

## Problem

独立文档站已有阅读框架和十七语言，但十三篇文章偏重客户端安装，API 参数、协议边界、控制台操作和运行排查不足。用户要求参考完整目录并结合本站能力扩充，语言入口也需要直接可见。

## Decision

把参考站当前 181 个中文条目逐项映射到本站原创手册：相同协议和流程合并成可维护的专题；未提供的专有能力明确边界与替代入口，参考站新闻和商业承诺不作为本站事实。每个专题依据本仓库路由、校验、用户界面和公开协议编写，代码支持不等同于生产模型已上架。

沿用独立静态构建、匿名公开目录和正文词典，在 docs/handbook 保存分领域文章与元数据。元数据与正文一并收集翻译，保证目录、搜索和文章语言一致。语言选择在桌面和手机顶部显示当前语言。用户在免费服务持续限流后明确改为由 GPT 直接翻译。停止原监督进程，由独立语言任务直接撰写分批译文，根任务在完整性与占位符检查通过后单独合并，避免并发改写正式词典；不调用付费或其他翻译端点，浏览时不向第三方发送内容。

目录为 64 篇：保留原十三篇，补充十八篇指南、十七篇 API 参考、八篇控制台手册与八篇集成指南。新增 API 文档使用 `/docs/reference/*`，控制台手册使用 `/docs/account/*`；独立域名去掉 `/docs` 后仍不会与 Nginx 拒绝的 `/api`、`/console` 前缀冲突。生成显式 Markdown 导入供 Vite 与 Bun 共用，构建前校验生成索引，避免通配导入仅在一套工具链中有效。

英文新增 1,225 项先逐条离线校对，再作为其他语言的翻译底稿；原词典中已审阅的内容继续复用。除变量集合一致性之外，将真实译文还原为 Markdown，核对代码块、链接目标和非空链接标签，防止翻译保留全部占位符却错误重排链接。目录独立滚动，搜索词变化时回到结果顶部，防止长目录的原滚动位置遮住首个结果。

## Related decisions

- 扩展[独立文档站](../../implemented/feature/2026-10-25-docs-subdomain.md)的内容范围与入口，不改变匿名边界。
- 复用[正文语言](../../implemented/feature/2026-10-25-site-language.md)与[动态样例](../../implemented/feature/2026-10-12-runtime-documentation.md)，不改变账户/令牌权限口径。
- 企业导航、支付与第三方客户端笔记用于核对事实，本次不实现这些业务的新功能。

## Alternatives considered

- 全文镜像参考站可以快速获得大量页面，但会将其专有接口、企业工作区、银行卡托管、智能路由和数据承诺误写为本站能力；采用完整主题清单与本站原创说明。
- 每种工具和每个同协议模型都复制一篇文章会重复公共配置并迅速漂移；专用协议单独说明，共用配置按工具类型归并，保留各主题映射。
- 增加第二套多语言文档框架会分裂偏好和正文词典；扩展已有采集与门禁。
- 将 API 和控制台手册直接命名为 `/api/*`、`/console/*` 会命中独立文档域名的拒绝规则。改用不冲突的文章路径，不放宽业务接口与登录路由的隔离。
- 仅按翻译占位符数量验收无法识别空链接或代码结构损坏；增加真实 Markdown 结构比对，不放宽发布前的完整翻译门禁。

## Validation

参考清单共 181 个唯一主题，分别为 50 个实际改写、89 个合并主题、34 个尚不支持主题和 8 个仅作参考条目。目录与全部文章内链检查通过，文档域名不能误用为模型 API 地址。浏览器确认 390px 下无横向溢出，语言菜单有十七种选择；英文切换和刷新持久化、目录独立滚动、搜索回顶、主站链接携带语言已通过。公开配置返回 503 时正文保留，API 地址回退到主站，恢复后可刷新动态示例；请求不带 Authorization、New-Api-User 或 Cookie。

原免费服务监督进程已按用户新指示停止。英文及另外十五种目标语言各补充 1,225 项，保留原有 940 项；每份词典均为 2,165 项。全部译文由 GPT 直接撰写，复核了否定、计费、重试、权限和隐私边界；完整性、占位符顺序、真实 Markdown 代码块与链接校验通过。搜索目录按语言缓存，避免每次输入重新翻译全部 64 篇文章。

真实浏览器逐一切换十七语言，确认标题、简介、正文和目录切换；英文搜索及刷新保留、390px 德语暗色目录与搜索、主站 /docs/reference/overview 法语深链、公开配置 503 回退及刷新恢复均通过。

验证通过：站点语言 97 项、文档与手册 14 项、运行时文档 7 项、模型快速开始 9 项、发布工具 Python 13 项；资源语言检查、格式、ESLint、主站完整构建与预渲染、独立文档构建。笔记门禁共 99 份记录通过。发布产物由标签 CI 重新构建，部署只使用核验版本与 revision 的 Release 静态包；本地构建不作为线上发布证据。

## Consequences

所有参考条目有适配结论与目标章节；文档内链与元数据唯一，接口样例与实际路由/鉴权一致；十七语言的正文与元数据无缺失、代码/变量保留；桌面/手机直接切语言，搜索、深链、刷新、错误回退和旧 /docs 通过。构建、中文提交、Release 附件与镜像完成；仅更新静态文档站，不重启业务应用。

## Risks

直接翻译仍可能发生术语或结构错误，必须检查完整性、关键含义与实际 Markdown，不得发布半译文。文档只说明已核实协议入口，生产可用模型以令牌与公开目录为准；不运行付费模型请求来伪造验收。第三方客户端字段会随版本变化，核实官方来源并说明适配边界。
