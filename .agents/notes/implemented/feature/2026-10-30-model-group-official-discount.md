# Agent Note: 分组价与官方参考价逐项对比

Status: implemented

## Problem

官方参考价已经独立维护，分组卡片仍仅显示本站金额且位于快速开始之后。用户要求官方价下方直接列出分组价，以划线官方价和降幅呈现对比。

## Decision

将既有 ModelGroupRows 移到官方参考价后，保留筛选、分页和健康。每张分组卡片将价格/缓存置于上方，首字均值/输出速度/Uptime以独立横行放在价格下方，手机按可用宽度换行。复用计价函数的未舍入美元金额、分组和时间倍率，逐项对比所选官方档位；输入/输出/缓存不合成单一折扣。多档官方价允许显式选择并展示档位名；动态分组仍显示已标注的本站首档，不将单价对比当作完整请求报价或宣称两个档位条件相同。

分组价沿用当前 USD/充值/套餐显示模式。官方价按站点真实 USD/CNY 汇率转换到相同币种，不能套用充值/套餐折算率。顶部官方价不变；未配置汇率、EUR/自定义币种不能换算、不同单位、倍率视图及无明确 TTL 的缓存创建不比较。缺失仍未知；官方零价不可作分母。只有实际更低才划线并显示降幅，持平/更高如实显示。K/M 同步换算而不改变折扣。

## Existing notes audit

- [接入顺序](../../implemented/feature/2026-10-29-model-detail-log-view.md)：部分取代分组明细在快速开始之后的顺序，动态完整规则保留在快速开始之后，日志决定不变。
- [展示元数据](../../implemented/feature/2026-10-25-model-catalog-metrics.md)：复用分组健康、搜索分页和可见性。

## Alternatives considered

- 直接把分组倍率当优惠率很简单，但基础价未必等于官方价，且遗漏时间倍率与充值/套餐成本，改用实际单价比较。
- 将首个官方档位静默作为统一折扣基准省去选择，却掩盖多档差别；提供显式官方档位选择并标明本站首档。

## Verification

- 真实 React 合成 API 浏览器验证官方档位切换、CNY → USD、K/M、不同分组降价/持平/高价/免费、搜索和分组筛选、编辑保存/清空、桌面/390px暗色/320px无整页溢出。原详情/日志流程保持。
- 17语言资源、ESLint、Prettier、完整前端构建（含图片应用）、五页Chrome预渲染、Go构建及笔记门禁通过。

## Consequences

输入、输出、可比缓存及按次/小时价格分别展示对比；未配置官方价、缺失汇率、不兼容币种/单位或TTL仅保留原分组价。官方零价不计算百分比；同价显示持平，更高显示增加比例；仅更低使用删除线及绿色降幅。显示精度不参与百分比计算，非免费价格不会四舍五入成降低100%。

管理员仍需维护官方价。对比是选定档位的单位价格，不代表完整请求优惠，也不推断两个档位的条件等价。顶部官方表保留原币种；分组中的官方金额可按明确USD/CNY汇率换算，缺失汇率不借用充值汇率。分组列表前移后快速开始在其后，保留分组搜索/分页；完整动态规则仍位于快速开始后。无后端、数据库、权限或扣费逻辑变更，未升级生产或执行真实模型调用。
