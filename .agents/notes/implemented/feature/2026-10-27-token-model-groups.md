# Agent Note: 单 Key 多模型分组范围与测试目录

Status: implemented

## Problem

令牌已支持多个模型白名单，但只能选择一个首选组；故障回退展开全局自动分组后，测试目录也合并所有备用组，无法表达模型 A 仅用甲组、模型 B 用乙丙组。

## Decision

令牌使用可选 TEXT 字段 routing_config，以 JSON 字符串保存有序 groups 与 model_groups。空值保持旧路由，新配置只在显式分组范围内按顺序选渠道，模型映射进一步收窄范围；模型白名单仍由 model_limits 控制。服务端保存和请求时核对用户权限，配置解析失败拒绝，不回退全局范围。复用已有故障重试预算、容量、亲和、实际分组倍率和余额扣减。

旧客户端更新缺少 routing_config 时保留原配置，显式空字符串退出新模式。可售令牌保持既有约束。测试目录支持组筛选，固定首选组旧令牌默认目录限该组；选定组的测试也固定在该组执行。新配置的普通模型目录、渠道列表和测试均按模型-组交集计算。

全局分组与逐模型分组下拉共用 `/api/user/self/groups` 的名称、本人适用倍率及 `desc`（表单中的 `label`）。说明在选项第二行按纯文本完整换行，空说明不占位；搜索匹配名称、倍率和说明，已选标签只保留名称与倍率。旧编辑值缺少元数据时保留原名，不推断倍率或说明；路由载荷仍只保存原始分组名称。

全局候选应用[通用分组置顶](../bug-fix/2026-11-01-token-group-priority.md)：企业级、优选、福利优先，其余沿用目录顺序；已选择的全局和逐模型路由顺序保持原值。

## Existing capability review

- 创建/编辑、列表及测试 → token controller → Token；TokenAuth → Distribute → channel_select → ability；实际 group 进入既有计费和日志。
- [首选组回退](../../implemented/feature/2026-10-24-preferred-group-fallback.md)部分重叠：旧路由不变，目录默认范围调整由本篇接管，显式新范围优先。
- [创建选择器](../../implemented/feature/2026-10-20-token-create-selector.md)、[列表倍率](../../implemented/feature/2026-10-07-token-list-group-ratio.md)部分重叠：复用选组和倍率，新增多组选项与实际分组计费说明。
- 视频预检、模型详情、文档、配额通知及健康笔记属于关联消费者，不改变其协议、价格或错误分类。

- [令牌列表与操作隔离](../../implemented/feature/2026-10-27-token-management-experience.md)部分重叠：摘要列表复用本篇多组与实际倍率渲染；保存会话隔离保留 routing_config 载荷，旧保存不能关闭新分组编辑器。

## Alternatives considered

- 仅扩大旧 group 为逗号串省字段，但破坏既有精确分组语义及旧 Key。
- 每个模型独立 Key 可复用现有能力，但用户需重复维护凭据和额度，不能满足同 Key 调用。
- 自动加入所有后台分组最省配置，但扩大权限范围与费用选择，不符合用户指定范围。

- 将说明直接拼入已选标签实现更少，但长说明会撑高多选框；采用带说明的选项与简洁标签，保留原生 Select 键盘和选择行为。

## Testing

- 全量 `go test ./...` 与前端构建通过；亲和计费、精确模型别名边界由新增定向回归覆盖，整合主线后再次通过全量 Go 测试、前端及后端版本构建。
- 真实 Distribute/Relay + 本地 HTTP 上游证明同 Key 的两个模型分别使用 1x/3x 分组，共享余额按实际日志扣减；仅成功扣一次、全失败退款、不扩展后台全局组、原重试预算不重置。
- API 创建、编辑、状态、旧客户端省略/显式清除、真实 Bearer 鉴权模型目录、渠道目录、越权组、撤销权限、畸形配置、精确别名测试范围均有回归。服务选渠覆盖内存缓存开/关；亲和与指定渠道均校验模型范围，亲和命中同步实际倍率。
- 独立 SQLite、MySQL 8.0.46（utf8mb4_unicode_ci，与生产一致）、PostgreSQL 16 测试旧表加列、两次迁移、余额与限制保留、新配置读写和清除。生产更新入口还会对当前完整 schema 连续预检。
- Playwright 使用真实创建/编辑/测试组件与合成 API，覆盖多组选取、逐模型映射、保存载荷、编辑回填、失败保留输入、组筛选与测试载荷、旧固定/auto 开关回填保存；390px 深色侧栏截图检查及边界通过。测试不请求付费上游。
- 构建检查全部 17 种界面语言。独立 Redis 回归验证新字段缓存往返和旧缓存缺少字段的兼容。生产构建预渲染由 CI 的 Chromium 完成，本机按既有逻辑跳过。

分组说明修复复用 `web/scripts/token-routing.browser.mjs`：覆盖企业专属/企业级/优选说明、空说明、零/未知倍率、纯文本转义、说明搜索与键盘选择、逐模型候选范围、简洁标签、390px 长说明不溢出，以及既有创建/编辑/失败保留/延迟保存/旧固定与 auto 流程。18 项分组与收藏单测、`make verify-notes`、完整 `bun run build`（含本地 Chrome 预渲染）通过；合成接口不证明线上注释已保存，也不代表生产部署。

## Consequences

新配置增加一个 TEXT 字段和一份可选 JSON 契约，以兼容现有 Redis 字段缓存；目录通过实际模型/分组/渠道元组求交，避免笛卡尔积扩大范围。回滚旧程序会忽略新配置，因此创建新范围 Key 后不能直接降级到不理解该字段的版本。新字段不回写历史 Key、不拆分余额。
