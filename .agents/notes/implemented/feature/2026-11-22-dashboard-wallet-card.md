# Agent Note: 看板余额预估进入指标网格

Status: implemented

## Problem

用户要在打开看板时直接看到本人资金预计可用多久，且日期与查询操作在桌面同一行。

## Decision

复用已有钱包摘要的请求、身份隔离和详情，桌面在五个日期指标之后显示第六张卡，窄屏优先展示。当前余额次于天数，充值放入详情。仅替代[原决策](2026-11-07-dashboard-wallet-summary.md)的位置，不改变预估口径。

## Alternatives considered

保留筛选旁的横条会挤开日期，也暗示预估随筛选变化；仅放进钱包则需要点击才能看到天数。

## Verification

钱包单元测试与真实浏览器验证布局、日期独立、身份切换、异常、键盘关闭和钱包跳转。

## Consequences

充值比原横条多一次点击；桌面右下卡与其他指标同组，但预估仍固定参考本人近24小时净消耗。
