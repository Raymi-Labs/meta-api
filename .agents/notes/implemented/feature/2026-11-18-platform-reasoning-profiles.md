# Agent Note: 逐型号推理能力声明

Status: implemented

## Problem

账号目录只返回名称，桌面端只能猜测可选推理档位。

## Decision

复用管理员模型编辑和账号模型可见性判断，声明仅属于精确型号；客户端显式请求才返回补充字段。与[自动能力同步](../../implemented/feature/2026-10-27-model-capability-sync.md)并存，不从布尔能力或价格推导档位。

## Alternatives considered

修改原数组会破坏旧客户端；通过公开定价接口返回所有型号并不能保证账号可见性。

## Verification

SQLite 真实读写与账号 HTTP handler 回归覆盖旧响应、允许/禁止分组、未列出型号、缺省/置空/错误声明及旧管理端切换匹配规则；无真实用户、数据库或推理。隔离无头浏览器使用实际打包页面和合成接口，修改默认档位后检查提交的请求体。表单基线与 Semi 嵌套控件独立，其他字段不变不会把旧值写回。

## Consequences

可空 TEXT 随现有 GORM 模型迁移，旧版写入省略字段保留声明；改为非精确规则的同一次写入清除档位。客户端显式请求才分批查询，空表表示无声明，查询失败保留原目录但不冒充空表。声明不更改用户权限、原生工具协议或计费，不能证明真实渠道执行。没有在生产 MySQL/PostgreSQL 执行迁移。
