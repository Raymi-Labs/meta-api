# Agent Note: 文档跟随站点地址和当前模型分组

Status: implemented

## Problem

平台文档把域名、分组和模型快照写在 Markdown 中。服务器地址及运营分组调整后，教程、客户端配置和请求样例仍展示旧值；当前没有启用的订阅套餐，购买说明也已失效。

## Decision

复用公开 `/api/status` 的服务器地址和经 TryUserAuth 处理的 `/api/pricing`。文档渲染时生成分组表、模型清单和按协议选择的请求样例；只展示模型启用分组与当前身份 usable_group 的交集。保持 Markdown 为教程来源，域名与动态区块在渲染时替换，不增加数据库字段、后台接口或定时任务。

进入文档、切换身份、返回标签页和可见页面每分钟刷新配置。失败时保留教程，明确标记动态信息不可用并提供重试；身份变更不能保留上一身份的数据。请求样例仅用已声明的端点，不按厂商名称推断协议、上下文长度或工具能力。客户端模型占位符在协议信息不足时保留并解释，不能伪造可用模型。

删除教程中的套餐购买、订阅管理和订阅额度排查说明；不删除后台订阅实现或历史订单。专用生图和语音教程的参数语义不随任意文本模型自动替换。

## Alternatives considered

- 全部更新为现网文字快照：改动最少，但下次运营调整再次过时，不满足自动同步目标。
- 定时抓取配置并改写仓库：能保留纯静态页面，但需要发布才能生效，且单一账号快照不能表达当前用户分组权限。
- 新增文档配置接口：便于聚合，但现有公开接口已经提供所需数据，另建会增加权限与缓存口径。

## Testing

`bun run test:runtime-docs` 的 7 项回归、定向 ESLint/Prettier、`make verify-notes` 和前端生产构建通过。构建使用本机 Chrome 完成 login/register/pricing/download/about 五个公开页预渲染。

Playwright 在真实项目壳中接入现网只读 status/pricing，并用相同现网响应完成文档导航与动态 API 样例展示；代码复制、1440px、390px 暗色和刷新通过。隔离模拟覆盖域名/分组改名后的聚焦刷新、每分钟刷新、加载失败保留教程、重试、无可用组、未授权组过滤，以及缓存管理员身份切到普通身份后立即清除旧数据再接收新目录。普通身份边界使用模拟响应，不声称生产普通账号验收或付费模型调用成功。

## Consequences

收益是服务器地址、模型和分组变化无需修改教程或重新发布；代价是在线动态区块依赖两次只读请求，源 Markdown 使用说明性回退文本。旧截图含固定分组推荐，文档以字段操作说明替代，避免截图再次过时；MiMo 原有文档补齐站内路由。

pricing 有约一分钟后端缓存，文档展示不代表真实调用成功；令牌还有独立模型限制。端点元数据缺失时不猜测支持，可能需要运营人员补齐元数据。现有笔记检索命中 Kimi 验收范围修正（无关）和通用流程约定（遵循），没有同属文档动态数据的已有决定。

独立文档域名复用本决定的内容或入口，跨域与发布边界见[独立文档站](2026-10-25-docs-subdomain.md)。
