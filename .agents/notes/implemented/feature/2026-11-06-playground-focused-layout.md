# Agent Note: 模型体验聚焦聊天布局

Status: implemented

## Problem

本地多会话加入后，常驻历史、参数、聊天和代码四区挤压输入与阅读空间。用户提供窄工具栏、顶部模型/分组、中央聊天的预览，要求参照优化。

## Decision

复用现有本地会话与请求状态：左侧窄栏放新建/对话/设置/代码，历史为可关闭面板，参数与代码在所有宽度按需抽屉。顶部保留模型切换与最多5模型模式，新增现有授权组选择及目录价格摘要。中央提示词、消息、输入框统一最大宽度，手机水平工具栏和可关闭历史面板，键盘Escape与焦点恢复可用。

不复制预览演示浮层，不猜请求费用；价格复用目录原费目和单位、未知不补零。原session归属、生成锁、导出、工具续接、权限和计费保持。设置与代码同一时刻最多开一个，隐藏生成会话不弹出浮层。

## Existing notes audit

[本地会话](../../implemented/feature/2026-11-06-playground-local-conversations.md)继续管理生命周期；[三栏工作区](../../implemented/feature/2026-10-30-playground-workspace.md)的常驻参数/代码由本篇替代，功能与SDK导出保留。

## Alternatives considered

- 缩小四栏字体改动少，但不能解决聊天可用宽度不足。
- 删除参数与代码栏可增加空间，但丢失已上线能力；改为按需面板。
- 复制预览预计费用会需要请求估算与真实路由价格支持，本轮只呈现已存在的目录价格。

## Verification

39项会话、比较、工具/请求与语言资源回归通过，主站Vite构建与局部ESLint/Prettier检查通过。隔离浏览器验证桌面/手机入口、参数与代码按需展开及Esc关闭、历史搜索焦点与关闭、模型切换、授权组变更后的模型裁剪和倍率更新；这些操作的模型请求数为零。完整会话后台生成/发送锁/账号及多标签/刷新中断/损坏导入/存储失败/5模型/非流式停止回归通过。截图目视检查桌面空态、手机消息列表及深色，检查无页面横向溢出。全部网络限定本地fixture，无真实付费请求；finally关闭浏览器和本地HTTP服务。

## Consequences

按需入口改变查找位置，使用带文字的工具按钮；旧showDebugPanel偏好不再自动打开代码。布局范围限定模型体验，不改顶栏/控制台菜单或其他页面。用户随后明确授权将本布局与GIF帧参数一起提交并合并main，发布版本v1.23.0；生产部署不在本次范围。

顶部价格沿用现有模型资料面板的USD报价口径并保留单位；不是本次请求预计费用，动态表达式仅显示动态计费及详情提示，完整条件与缓存价格在设置面板内。原厂/本站资料未新造。标题按钮打开已有模型选择器，标签和加号保留原选择能力。历史面板覆盖聊天区，关闭回到对话按钮；手机工具栏横排以保留输入空间。
