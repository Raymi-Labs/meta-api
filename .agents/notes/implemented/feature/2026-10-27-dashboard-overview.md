# Agent Note: 控制台概览的信息层级与统计状态

Status: implemented

## Problem

概览以问候语、四色分组卡片及八个数字开头，账户累计值和选定范围统计没有明显区分。筛选弹窗直接修改输入，取消也可能改变平均RPM/TPM；失败时缺少持久状态。模型详情复制完整代码到toast会遮挡手机界面。

## Decision

首屏布局与指标由[五项指标整合](./2026-10-30-dashboard-five-metrics.md)接管；以下保留原设计理由，查询草稿、角色隔离、失败保护和剪贴板契约继续适用。

复用 /api/user/self、/api/data/self 和管理员 /api/data 原有聚合，不新增统计接口或成功率算法。首屏四卡突出账户余额、范围额度、范围次数、范围Token；累计账户消耗/次数与范围RPM/TPM以副指标明确区分。时间范围、时区与用户范围常驻可见；普通用户不访问管理员数据，管理员筛选不改变“当前账户”的余额语义。快捷入口遵循现有侧栏模块配置。

标题右侧增加今天/近24小时/近7天/近30天/自定义。今天按显示的浏览器时区从午夜开始；最近N天按准确秒数回溯，避免夏令时导致超过普通用户30天上限。快捷范围默认选择相应小时/天粒度；自定义保持用户粒度，取消不改变已应用标签。刷新快捷范围重新取当前时间，刷新自定义保持固定范围；用户过滤在日期切换中保留。午夜瞬间零时长拒绝提交，不构造未来结束时间。管理员常用入口额外提供渠道/用户管理，普通用户不显示，均遵守侧栏模块开关。

弹窗使用独立草稿，确认时校验有效正时间范围和普通用户30天限制；取消不更改统计。提交后才刷新关联图表，加载与失败不可伪装为0或旧结果，保留重试。身份切换重新挂载概览，旧请求不覆盖新身份。余额刷新使用已有self接口并明确失败状态。

模型目录/详情复制成功只提示“复制成功”，不回显内容；失败提供有界滚动的可选文本。剪贴板兼容回退需检查execCommand返回值并始终移除临时节点。

## Related decisions

- [参考布局](../../implemented/feature/2026-10-26-reference-layout-alignment.md)继续持有目录/详情布局，本篇接管已记录的长代码复制提示问题。
- [发现路径](../../implemented/feature/2026-10-26-model-discovery-experience.md)保留价格和身份边界；复用相同缺失与失败不补零原则。
- [渠道用量](../../implemented/feature/2026-09-29-channel-usage-in-management.md)持有管理员监控和精确日志口径，本篇不更改这些接口或统计。
- 用户登录后已实际查看参考站Activity、日期与筛选菜单：标题右侧日期/筛选、主要用量指标与分区图表作为视觉参考；管理员视图按本站能力保留，不宣称看过参考站管理员后台。

## Alternatives considered

- 仅换颜色最小，但不会修复草稿泄漏与失败误读；先厘清状态再统一布局。
- 新增“今日成功率”卡片更像运维看板，但现有quota_data是聚合用量，不能当请求健康分母；使用现有日志/可用性入口。
- 复制成功回显部分原文可识别内容，但仍可能暴露代码或密钥；使用固定成功提示，实际剪贴板内容保持完整。

## Verification

本地实际页面配合隔离API验证普通用户仅请求self统计、role 10管理员保留专用图表及用户名筛选、隐藏模块不显示快捷入口。确认用户名查询编码、取消草稿后重开恢复、确认后才切换粒度、错误日期不应用。统计503时范围卡片隐藏旧值且图表不显示旧结果，重试为空成功显示0；账户余额独立保持。人工挂起旧请求，在新用户查询成功后释放，迟到响应未覆盖新范围。

桌面、390px及320px无整页横向溢出，暗色卡片正常。实际复制411字符示例后剪贴板与页面完全一致，通知只显示“复制成功”；兼容回退测试覆盖false/异常、完整内容、焦点和节点清理。新增查询回归覆盖时间边界、普通用户30天、空响应不修改输入、有限平均值及管理员10/超级管理员100。

同步主线四列卡片更新后，28项查询/剪贴板/语言回归与26项共享导航/认证/模型回归通过；作用域ESLint、修改文件格式、主站Vite构建与笔记校验通过。构建保留既有大包提示；账户接口失败隐藏旧余额、重试恢复也已实测。后续已只读查看用户登录后的参考概览和筛选，未修改参考账号配置。新增快捷范围与角色/模块可见性测试；本地实测管理员用户筛选在日期切换中保留、取消自定义回原范围、范围说明和图表口径同步。普通用户30天精确2592000秒且只访问self接口；America/New_York时区覆盖夏令时前后30天边界。标题右侧日期与图标筛选在320/390px及暗色无横向溢出。

## Consequences

保留原服务端聚合与缓存时效，不将范围次数称为所有HTTP请求。管理员专项图表有各自时间选择，保留原标注与入口；本轮只修主范围卡片/图表状态，不重写管理员专项报表。默认结束时间改为打开页面的当前时间，避免向未来多算一小时；非法保存粒度回退hour。真实账号切换通过组件按身份重新挂载和请求失效保护，未以生产账号实测。无数据库、接口或线上配置变化。用户已授权本批通过审查后提交并合并main，生产部署不在范围内。验收结束关闭本轮预览服务与测试页面，遗留测试进程为零。
