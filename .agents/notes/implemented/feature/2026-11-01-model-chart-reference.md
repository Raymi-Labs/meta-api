# Agent Note: 模型空图的性能与用量参考

Status: implemented

## Problem

已有 OpenRouter P50 只用于卡片和分组价格摘要，模型详情性能图仍为空。用户要求空性能图与空用量图同步 OpenRouter，确认无本站用量时切换为模型用量参考，有本站记录则恢复分组用量，不显示来源徽标。

## Decision

复用现有参考权限、精确模型映射和独立字段。性能图缺失时展示当前 P50；不把当前30分钟快照铺成24/72小时曲线，也不修改原始聚合。当前接口只有性能快照，因此不画历史性能折线。用量参考属于整个模型，不复制为本站各分组用量；本地真实数据优先，失败、过期与缺字段保持未知，零值保留。

用量从公开 catalog/models 的精确 slug 解析 permaslug，再读取 stats/model-activity 的对应 variant，逐行校验模型、变体、UTC日界与整数计数。只展示最近30天原始每日记录，默认7天，可切30天；不根据24/72小时性能筛选伪造小时用量。输入加输出作为 Tokens，推理/缓存字段不重复相加。缺项仍未知，真实零保留。独立 model_usage_reference 含可用分组白名单，当前选中分组均无本站观测/用量才切换；有任何本站记录就恢复分组用量，侧栏同步名称。

读取复用已启用授权渠道的精确模型映射与代理，公共接口不传渠道密钥，固定主机且拒绝重定向；6秒请求预算、4并发、成功15分钟缓存、失败1分钟退避、最多256缓存项，缓存不存用户权限结果，每次重新投影可见分组。性能与用量读取并发执行，均不回写 DB、账单、Uptime 或原始小时统计。公共页面接口不属于稳定版 API，字段变动时拒绝无效数据并保留空态。

## Alternatives considered

- 把当前P50重复写入每个小时最容易填图，但会虚构历史稳定性；显示当前快照或真实上游历史。
- 把全网用量重复到每个分组可以沿用现有布局，但会被误解为本站消费；无本站用量时切换为模型用量参考。
- 仅接标准排行榜API契约稳定，但每日只覆盖前50模型，不能保证冷门模型有数据；改为使用模型页面的公开目录和 model-activity 接口，匿名 GET 已核对 Mercury 2 全量每日记录。

## Verification

生产服务器匿名读取 Mercury 2 公开目录和31天每日记录已成功。Go 定向测试、前端单测与 Chrome 验收覆盖本站优先、部分缺失、真实零值、无授权/禁用渠道、过期/请求失败、24/72小时、切换指标、放大及手机深色布局。检查不修改Uptime、计费、日志和渠道。前端完整构建与五页 Chrome 预渲染、ESLint/Prettier、Go全量测试、笔记与发布策略门禁通过。浏览器验收覆盖7/30天、Tokens/请求、图表放大以及390px深色无横向溢出；截图为合成数据。

service、group_health 与 controller 健康权限定向竞态检查通过。扩展到全量 controller 竞态检查时，既有后台 collector 与测试切换全局 model.DB 发生竞争；用 v1.13.0 原控制器 overlay 再跑亦在相同 collector/DB 路径触发空指针。该测试隔离问题未改动，不能将全量竞态检查记为通过。

## Consequences

公开元数据可能改变格式或缺模型；外部快照不等于本站实测，全网用量也不是本站分组消费。不能将未知补零。
