# Agent Note: 官方参考价自动同步

Status: implemented

## Problem

线上 GPT-6 Astra 已有官方属性但官方参考价为空。现有 official_pricing 只通过管理员手工维护；后台模型属性同步已读取 OpenAI 模型文档，却没有解析或应用价格。官方页面提供标准输入/输出/缓存价格以及长上下文倍率，展示层缺失源于同步链路缺口。

## Decision

[厂家来源约束](../bug-fix/2026-11-01-manufacturer-official-pricing.md)收紧公开价格来源并允许旧 OpenRouter 资料被厂家取价替换；保留人工厂家价及同步失败保护。

[自动资料默认值](2026-10-31-model-official-defaults.md)扩展公开厂商来源、介绍/标签/供应商和自动更新入口；其新规则取代下文旧的字段范围与失败等待周期，人工保护及来源语义继续有效。

扩展现有模型元数据同步，无新增定时任务或公开写接口。复用启动立即执行、默认每天以及编辑过期资料触发的同步任务和管理员 POST /api/models/sync_capabilities；从同一次 OpenAI 官方模型文档请求解析文本 token 的 USD / 1M 价格。校验精确模型身份、价格区块、单位及数值；明确的长上下文门槛和倍率生成独立档位，保留官方条件说明，不使用 Batch/Flex/Fast 价格替代 Standard。不从本站倍率反算，不把社区价格冒充官方数据；其他厂商/无法识别的费目暂保留人工配置；xAI 的区域及多模态解析扩展如下。

复用 official_pricing TEXT 和私有 model_capability_sync_state 跟踪自动所有权，无 schema 新增。仅空白或仍等于上次自动快照的价格可更新；人工价优先、关闭同步/删除/名称规则保护和并发比较继续生效。网络失败或解析失败保留上次完整价格，不清空；公开模型目录读缓存，不在用户打开详情时抓取来源。记录价格专属的最后自动更新时间（无变化检查和其他属性更新不刷新）；详情显示来源及时间，管理入口显示本次价格更新数量，人工内容不伪装自动价格。

管理入口改为“同步模型资料”，说明属性与官方价格的范围；同步结果显示价格更新数量。错误源计数继续复用原有提醒。官方价格始终为展示元数据，不能写入本站 ModelRatio、动态计费或分组倍率。

OpenAI 价格说明中的明确缓存写入保留时长按独立档位解析：校验卡片金额与默认时长费率一致、各时长不重复，再与长上下文倍率组合；默认时长优先展示。GPT-6.1 Terra 的 30 分钟/12 小时说明包含金额，原通用异常布局保护会拒绝整组价格。当前针对可识别的官方条件扩展解析，未知金额说明、矛盾费率和重复条件继续保留旧价，不简单忽略含美元符号的说明。时长复用现有档位标签，未新增数据库字段，也不将标签当作计费参数。

## xAI 区域、上下文与多模态价格

Grok 缺价的直接原因是 `parseXAIModelDocument` 只提取属性，没有填充 official_pricing；官方页面已提供价格。复用该固定官方请求，从 `globalThis.__XAI_PUBLIC_MODELS__` 的独立 JSON 赋值读取精确模型的价格，不执行脚本、不跟随页面提供的取价地址。官方原始整数单位经换算后与可见价格卡片的金额及单位交叉校验；页面身份、未知单位、缺失长上下文档或条件冲突均失败保留原价。

标准文本按 region 与明确的 input token 门槛保留完整输入/输出/缓存档位；图片按 region、resolution、quality 保存每张输入/输出；视频按 region、resolution 保存每秒输入/输出，额外图片输入费单独保留 image 单位。沿用20档上限，超过上限不截断。Batch与工具费不作为标准费率，未声明的缓存写入不补零；无官方精确型号的私有后缀不套用其他型号。所有费目仍为参考元数据，不写入渠道或计费倍率。人工保护、关闭同步、厂家来源过滤与现有 namespace→native ID 流程复用。

该扩展归属本笔记；厂家来源限制由[厂家来源修复](../../implemented/bug-fix/2026-11-01-manufacturer-official-pricing.md)持有，视频销售价/分辨率展示和模型卡片笔记仅相邻，无规则替换。相比只抓可见首屏金额，结构化数据能保留隐藏的地区/长上下文/分辨率档；可见金额交叉验证防止单位变化而误报价格。维护成本是官方数据结构变化时需要重新适配；不以本站或聚合商价格填补。

## Related decisions

- 部分取代：[官方参考价](../../implemented/feature/2026-10-30-model-official-pricing.md) 的仅手工维护与来源不抓取；保留独立币种、零值、管理员 CRUD、精确匹配和不参与计费。
- 复用：[官方属性同步](../../implemented/feature/2026-10-30-model-attributes-official-sources.md) 的固定来源、超时、有界并发、互斥、人工保护与乐观并发。
- 相邻：[分组价格对比](../../implemented/feature/2026-10-30-model-group-official-discount.md) 继续消费同一官方价，不改对比规则。
- 其余模型目录/详情布局笔记与视频定价提案无决策变化。

## Alternatives considered

- 手工填入当前 GPT-6 Astra 金额：可以立即补单模型，但后续模型和价格调整仍靠人工，不能满足自动获取。
- 从模型库或本站基础倍率填充：来源接入简单，但供应商/代理定价和币种语义可能不同，不能标作已核验官方价格。
- 每次详情请求实时抓官方页面：无需后台存储，但外部超时会拖慢公开目录并扩大请求量；采用已有同步与缓存。
- 新建独立价格任务和接口：可分开刷新，但会重复候选权限、请求及人工保护；同源资料沿用现有同步接口。

## Verification

- 2026-11-01 xAI 扩展：7 个下载的厂家页面通过解析，Grok 4.5/4.6/4.7 和 Imagine 图像/视频系列分别保留地区、长上下文、分辨率与质量档。回归覆盖原始单位错误、页面币种/可见金额冲突、身份/地区不匹配、缺长上下文档、重复数据和可执行脚本尾部；零价有效，未知价格不补造。
- xAI 同步集成覆盖 namespaced ID → 固定官方获取 → SQLite 写入 → 公开价格与来源；坏价格保留旧价且允许独立验证的上下文属性更新，人工价格不被覆盖。Go 全量测试、服务端构建、make verify-notes 与发布策略检查通过；不涉及 schema 或新 SQL。
- 真实 React 页面使用 Go 解析出的 Grok 4.6、Imagine Image 2.0、Video 1.5 价格验收，1440px/390px 深浅色检查档位数量、金额、来源和整页无横向溢出；既有官方价格浏览器回归通过。浏览器 API 使用本地夹具，不代表生产已升级。

- Terra 回归先复现 `unrecognized official price layout`，再验证四档完整价格、默认时长优先、跨时长等价重复、卡片矛盾和未知说明拒绝；同步集成验证 HTTP 获取→自动存储→公开 pricing 输出四档。公开 OpenAI 页面实测 Terra 为 1/5 USD 标准输入/输出，缓存读取0.05、写入1.25/2.50，>272K 档为2/7.5、读取0.1、写入2.5/5；同时 Astra、Sol、4o mini 原有解析通过。

- 三个实际官方页面通过 opt-in 验收：GPT-6 Astra 10/50 USD 的标准档及 20/75 的 >272K 档，缓存读写同步；GPT-6.1 Sol 两档、GPT-4o mini 一档均解析成功，不读取 Quick comparison 中其他模型价格。
- Go 全量测试与服务端构建通过。解析器覆盖缺输入/输出、错单位、重复费率、非法价格、未知长上下文条件、零值、缺缓存、页面身份/区块隔离。同步集成覆盖来源网络/解析失败保留旧价，结果写入公开 pricing 与只读来源。
- SQLite、MySQL 8.0、PostgreSQL 16 的隔离实库通过所有权、零价人工保护、清空恢复、禁用/删除、并发人工保存及新建模型测试；原属性同步与迁移回归通过。
- 11 项前端同步结果、官方价和分组对比测试通过；ESLint、17 语言资源、主站/图片应用/文档站及五页预渲染通过。
- CUA 验证真实 React 构建配合本地合成 API：模型管理按钮返回价格更新数量、详情出现来源和时间、两档四项价格与分组档位选择；390px 整页宽度保持390。后台实际同步→存储→公开目录由上述 Go 集成测试验证，浏览器夹具不代表生产数据库。

## Consequences

OpenAI 文档并非稳定的价格 API，结构或条件变化需保守失败并保留旧值；其他供应商的自动价格源需要单独适配。未部署新版的线上服务仍不能自动填价，本轮发布与生产部署分开，不直接改写生产数据库或计费设置。
