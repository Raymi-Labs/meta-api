# Agent Note: 模型发现与接入路径的信息层级

Status: implemented

## Problem

目录的多行筛选先于搜索和模型，卡片将未配置和无权读取的性能都显示为横线；详情主要操作指向文档且厂商介绍可能替代模型描述。首页普通公告延迟弹窗打断首次阅读。新顶栏下载入口增加窄屏空间压力。

## Decision

[实测参考布局](2026-10-26-reference-layout-alignment.md)部分取代本篇的抽屉优先筛选、简介前置和大价格卡片展示；本篇的价格条件、缺失状态、权限隔离和公告手动规则保持。

复用模型目录的筛选、价格、分页、身份和历史状态。搜索前移，厂商保留主页面，其余筛选使用现有抽屉；主页面显示可独立清除的已选条件。价格条件继续说明最低适用倍率，混合目录不再统一暗示所有价格按 Token 计费。卡片保留按次、小时、表达式与本地视频计费改动。

性能状态区分未登录、加载、失败和无样本；身份切换立即隐藏旧结果。未配置上下文明确提示，不补造模型能力；详情不借用厂商描述，快速开始在首屏可直接到达并前移到分析图表之前。首页公告仅由铃铛手动打开，仍读取公开内容并显示真实未读状态，不修改公告邮件或后台管理。窄屏顶栏保留所有入口。

## Related decisions

- 部分取代[模型目录](../../implemented/feature/2026-10-25-model-catalog.md)的常用筛选全部展开布局。
- 扩展[模型详情](../../implemented/feature/2026-10-25-model-detail-page.md)和[模型指标](../../implemented/feature/2026-10-25-model-catalog-metrics.md)的展示次序与缺失状态；价格和权限口径保留。
- 部分取代[公开铃铛](../../implemented/feature/2026-10-25-public-notification-bell.md)的首页自动弹出行为；已读同步与邮件链路保留。
- 视频定价工作区由伙伴持有，本次只衔接其展示逻辑，不改变计价表达式与后端契约。

## Alternatives considered

- 只压缩字体可以减少高度，但降低可读性且保留信息顺序问题；改为搜索优先和渐进筛选。
- 立即增加模态/用途筛选更接近参考站，但真实元数据尚不完整；暂不建立推断或第二套模型库。
- 隐藏所有未知指标更干净，但用户无法区分权限和缺失；显式状态并保留已有权限边界。

## Verification

本地隔离 API 与实际页面验收：桌面、390px 与320px暗色，德语长文案；数值0计费筛选可清除、复制不导航、搜索→详情→返回保留搜索、快速开始滚动并转移焦点；匿名提示与登录失败重试、真实0ms及无样本分离；按次/小时/伙伴视频表达式保留不同价格语义。首页后台检查后不自动弹窗，铃铛可手动读取真实内容；移除不再适用的“今日关闭”。窄屏厂商栏约束收缩并独立滚动。

模型权限/历史、展示、快速开始协议、过滤/分页、货币与阶梯计价、视频模板、公告已读、导航与17语言检查通过。新增性能视图回归覆盖身份切换、旧分页/重试响应、未登录、加载、失败、空响应与显式零值。主站完整构建（含生图子应用）与五页预渲染、最终主站及独立文档构建、作用域ESLint/Prettier及笔记校验通过；仅有既有大包提示。目录503→原页重试恢复、空结果重置与第二页详情返回也通过。

视觉整理沿用上述行为：目录移除筛选外框与价格/性能灰底，统一工具栏尺寸；桌面通过共享网格行对齐卡片，手机回到自然单列。长标题、描述有无、320/390px、900px双列及暗色验收通过；320px保留较宽的排序控件，避免压成单字。此项为样式整理，无新数据或权限决策。

详情视觉延伸保留原数据与交互：介绍区采用响应式网格避免中等宽度操作区挤压；价格摘要、分组行和代码区统一圆角与弱边线，分组价格增加独立标题。桌面分组切换后的摘要/分组列表一致，协议与语言联动、复制、快速开始焦点、390/320px长模型名、暗色及代码框独立横向滚动验收通过。

## Consequences

减少常驻筛选会增加一次打开抽屉的操作，已选条件常驻且可独立清除。缺失模型资料仍需运营配置，不由UI推断。性能接口保留原24小时和当前页查询；失败重试也遵守身份隔离。首页不再自动强调任何公告，紧急通知仍通过已有公告入口及独立邮件能力传达；不新增公告优先级配置。旧今日静音存储兼容保留在共享工具供其他入口使用。本轮仅本地修改，不部署生产。验收后关闭临时浏览页与预览服务，本轮遗留测试进程为零。
