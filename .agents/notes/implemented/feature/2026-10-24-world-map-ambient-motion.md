# Agent Note: 首页地图的持续轻波动与弱鼠标响应

Status: implemented

## Problem

用户复核 AIHubMix 后指出：地图在没有鼠标时仍有动态，鼠标附近的变化应当轻微。现有地图仅悬停时运行，较强的点放大、高亮及径向位移不符合这一视觉目标。

## Decision

复用 WorldMap 的 SVG 轮廓和 Canvas 点阵；页面聚焦、地图可见且没有开启减少动态效果时，自动播放缓慢、低幅度的基础波动。基础波纹同步驱动局部明暗色阶，深浅区域缓慢流动，保留中心与边缘淡出和原有平均明度。鼠标只叠加小幅扰动，离开后回归基础动画。触控设备允许基础波动，不接管触摸或滚动；减少动态效果保留静态 SVG。

地图离屏、页面隐藏或窗口失焦时暂停，重新可见/聚焦时自动恢复；滚动只清除悬停状态；保持单一 RAF、绘制上限 30 FPS 与 DPR 上限 2。卸载后不允许迟到的 observer 回调重启动画。

随[首页流式布局](2026-10-24-public-home-redesign.md)加宽地图后，画布 backing 总像素限制为 600 万；超过预算时降低栅格分辨率，按实际整数宽高分别补偿到 CSS 坐标。常规桌面保留原 DPR 清晰度，超宽高密度屏不会分配随面积无限增长的画布；SVG 比例、动画逻辑坐标和鼠标命中位置保持一致。

## Related notes

检索 WorldMap、点阵和空闲动画：仅[公开首页设计](../../implemented/feature/2026-10-24-public-home-redesign.md)拥有相关决定。本篇部分取代其中“只在鼠标悬停运行、触控保持静态”的规则；首页布局、SVG 原创轮廓、Canvas 叠层、路由权限与自定义首页优先级仍由原笔记负责。其他“功能地图”命中属于无关部署与安全功能，不改写。

## Alternatives considered

- 只减小悬停强度：改动最小，但仍缺少无鼠标时的动态，不满足用户纠正后的要求。
- 仅以 CSS 整张地图平移：绘制成本低，但点阵不能呈现局部连续波动，因此复用现有 Canvas。
- 无条件持续绘制：生命周期简单，但后台或离屏仍消耗资源；采用可见性与聚焦控制。
- 宽屏直接沿用 DPR 2 的完整画布：最清晰，但 4K 等比地图约需 2100 万像素；采用总像素上限，在超宽高密度屏适度降低栅格清晰度。

## Testing

- 宽屏布局补充：39 项地图回归通过，覆盖 1920px、4K/5120px 高 DPR 像素预算和超宽→手机→4K resize；绘制点经 CSS 缩放后与 SVG 位置一致，相同相位的鼠标位移、半径和亮度不变。
- Chrome 鼠标移出地图连续观察基础波动，悬停保持轻微变化；明暗主题正常，390px 无横向溢出，滚出地图暂停、滚回自动恢复。
- `bun run test:world-map-motion` 34 项通过：无鼠标持续、触控/coarse/pen 不叠加悬停、移出/滚动/cancel 回归基础、focus/hidden/offscreen/reduced 的暂停恢复、单 RAF、letterbox 坐标和 resize。
- 相同动画相位逐帧对比验证鼠标增加的点半径不超过 0.2、位移不超过 3、透明度不超过 0.065；批量 IntersectionObserver 采用最后状态，卸载后迟到回调不清除画布或排帧。
- 明暗回归直接检查绘制结果：无鼠标也持续加深/变浅，较深区域 30 秒内 alpha 跨度大于 0.4，相邻帧变化小于 0.025；多位置 alpha 保持 0～1，中心/边缘淡出，hover 增量仍不超过 0.065。Chrome 宽屏与 390px 亮暗模式、静置与悬停已验收。
- 完整前端生产构建与五页预渲染、ESLint/Prettier、发布策略和决策笔记校验通过；构建后的预览从下载页返回首页时，无需移动鼠标即可运行基础动画。

## Consequences

基础动画增加首屏可见期间的绘制成本；依靠帧率、DPR、可见性和减少动态效果控制。浏览器本地验收不代表生产部署。
