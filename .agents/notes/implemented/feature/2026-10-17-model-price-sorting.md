# Agent Note: 模型广场价格排序

Status: implemented

## Problem

模型广场主要按名称展示，不能快速比较输入、输出和按次价格。本地还存在分组、时段倍率、动态阶梯与不同显示单位。

## Decision

扩展现有筛选结果的排序并共享给卡片与表格；桌面和移动端均能切换输入、输出、按次价格升降序及默认顺序。复用现有价格计算得到未格式化数值，在筛选后、分页前排序。未知或不适用价格始终靠后，零价有效，保持默认顺序稳定。

## Existing notes

[厂商切换与版本顺序](../bug-fix/2026-10-21-pricing-vendor-transition.md)新增默认的自然版本降序，原默认名称顺序仍作为可选项；本文价格排序和零价/未知价规则不变。

[筛选可见性](2026-10-11-pricing-filter-visibility.md)及 [分组健康筛选](../bug-fix/2026-10-17-group-health-filters.md)管理结果范围，本次只扩展模型结果顺序，保留其权限和解除筛选入口。价格来源沿用 `calculateModelPrice`，不改变计费。

## Alternatives considered

只按 model_ratio 排序最简单，但忽略分组与时段且不覆盖按次价格；解析展示字符串会受货币、舍入和动态提示影响。采用同源未舍入价格。

## Verification

单元测试覆盖输入/输出/按次升降序、零价、未知价、动态价排尾、不可变原列表，以及共享价格函数的分组与时段倍率。真实本地四模型 fixture 验证卡片/表格顺序、刷新、390px 暗色。同步主线分组健康修复后，其桌面与移动端完整浏览器回归通过。

## Consequences

复杂表达式没有可比较单价时放在末尾并说明；排序只用于比较展示，不估算最终账单。
