# Agent Note: 视频测试默认无生成请求

Status: implemented

## Problem

H3 名称及映射别名的免费预检识别由[H3 基础链路](2026-10-26-minimax-h3-video.md)补齐；配置预检仍不证明供应商可用性。

用户准备逐步接入多家视频模型，但每次测试都真实生成视频会反复产生上游费用。原渠道测试固定 1 秒/480p，提交受理后即返回成功，没有任务持久化和终态轮询；批量和自动健康逻辑还会将这一结果更新为渠道可用。

该问题属于[通用视频框架提案](../../proposed/feature/2026-10-21-video-pricing-and-testing.md)中的成本控制部分。两篇部分重叠，保留互链；本篇落实低成本检查，原提案继续跟踪价格表、完整资金闭环和逐版本接入。[Vidu 计价字段保真](../bug-fix/2026-10-17-vidu-billed-fields.md)仍独立有效，本次不修改正式任务载荷或计费。

## Decision

- 视频测试通过已知家族、专用视频渠道、模型映射、直接 model 参数覆盖、缓存中的视频元数据及显式 `openai-video` 端点识别。该识别用于防止付费测试，不是新增模型支持声明；未知私有名称可手动选择视频端点。测试执行器在映射后和最终请求参数阶段再次拒绝视频，并删除整个视频上游提交分支。
- 渠道 GET 测试和令牌 POST 测试固定返回顶层 `success: false`，保留旧客户端“没有完成真实测试”的契约，防止旧页面按 true 提示启用渠道；新客户端使用 `data.passed` 展示预检结果。响应包含 `test_kind: video_preflight`、`generation_verified: false`、`upstream_requests: 0`。检查模型声明、映射、凭据是否填写、URL 格式、适配器、明确任务定价和分组。字段存在不证明密钥有效或该模型版本/参数可用。
- 管理员 `POST /api/channel/:id/video/preflight` 受原有 AdminAuth 保护。提供配置明细、历史摘要和可选表达式估价，最多接收 16KB JSON；不用适配器发请求，不轮换密钥、不预扣、不写任务或消费日志。
- 估价复用 `helper.ModelPriceHelperTask` 的现有表达式、分组优惠、时段倍率及额度取整。调用者明确输入参数和渠道分组，以 USD 标注站内估算扣费。旧固定单价可能另有适配器倍率，因此不猜测该路径的完整价格；没有表达式时返回不可估价。估价是参考，不是供应商能力检查或后续请求的扣费授权。改参数立即清除旧估价。
- 历史以 GORM 查询该渠道最近 200 条可见任务，在 Go 中按原始模型精确匹配、最多输出 10 条状态和时间。普通用户在 SQL 层限定自己的 user_id；管理员摘要不输出用户 ID、提示词、素材、上游 ID、原始错误或结果 URL。旧任务没有配置指纹，一律显示历史参考，不授予当前配置已验收状态。
- 前端把预检、真实测试成功、失败分别统计。预检不更新渠道响应时间、不触发自动/手动启用提示、不清除或确认待禁用状态，也不进入“选择成功”。测试过时响应在关闭、换模型或改参数后丢弃。
- 本页没有付费生成按钮。需要真实生成时使用已有正式视频 API；原提案中的独立付费验收入口须与持久预算、幂等、未知提交状态和正式任务结算一起实现，不能把旧裸提交分支换个按钮继续使用。

## Alternatives considered

- 每次生成最短低分辨率视频：可获得当次真实结果，但仍收费，固定 1 秒不适用于所有模型，且提交成功不能替代生成完成。
- 保留旧提交作为“付费测试”：界面变化最小，但原路径缺少任务持久化、预算和异步终态处理，不能可靠约束成本，故移除。
- 为预检调用模型目录、错误任务 ID 或生成后取消：某些上游可能可用，但缺少逐家验证的权限、计费和结果语义，当前不调用。
- 给全部视频统一推算每秒价：展示简单，但会误解固定档位、真实 Token 和输入素材费用。本次只复用已配置表达式估价，结构化定价仍按原提案实现。

## Verification

- Go 回归覆盖已知厂商家族、显式视频端点、别名链、映射环、无定价、零价、时长/分辨率及分组倍率、执行器预扣前拦截、HTTP 预检无任务/流水写入、令牌归属和历史隔离。额外验证预检通过/未通过两种情况的顶层 success 均为 false，旧客户端不能据此判定真实测试成功。HTTP 桩计数为零，重复检查不改渠道、密钥索引、响应时间。
- `controller`、`common`、`relay/helper`、`service`、`model` 包回归通过；无数据库迁移，新增查询仅用三数据库均支持的 GORM Select/Where/Order/Limit，JSON 模型匹配在 Go 层执行。
- 前端语义测试覆盖预检不计真实成功、保留文本/图像模型、混合批次分类。浏览器在真实项目壳中使用模拟 API 覆盖估价更新、错误 JSON 不请求、缺价/历史错误、窄屏暗色和令牌流程；不替代生产普通账号验收或真实厂商生成。
- Go/Bun 构建、五个公开页预渲染、七语言键完整性、`make verify-notes` 与 diff 校验按发布流程执行。

## Consequences

日常视频检查不再产生生成费用，也不再误报健康状态；代价是它不能判断当前上游鉴权、额度或参数是否真正可用，历史记录也不能填补这个证明缺口。只改售价可以本地估价，不要求重新生成。正式视频请求、生产价格和渠道配置保持原逻辑；结构化视频价格表、配置指纹、预算控制下的付费验收及具体新模型验收仍在原提案中。
