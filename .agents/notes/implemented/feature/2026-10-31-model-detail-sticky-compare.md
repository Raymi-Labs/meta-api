# Agent Note: 模型固定栏、跨模型对比与体验跳转

Status: implemented

## Problem

模型详情下滑后无法持续确认当前模型，也缺少直接对比和进入模型体验的入口。用户要求参考固定模型栏和 AIHubMix compare 页，提供复制模型 ID、跨模型对比与当前模型测试。

## Decision

模型标题离开可见区域后，在现有站点导航下方显示固定模型栏；向上滚动回标题时收起。复用当前名称、图标和复制逻辑，入口分别进入跨模型对比和携带模型 ID/分组的 `/playground`，不自动发送请求。固定栏与章节滚动偏移对齐，兼容窗口和工作区滚动、移动端、暗色及模型切换。

新增 `/compare`，复用 pricing 登录要求和当前账户目录，只从 URL 保存最多四个精确模型 ID；支持搜索添加、移除、复制链接、详情和体验入口。采用模型摘要卡、统一分组的价格/规格/能力表、24/72 小时性能与用量图表、费用估算和管理员配置的模型 FAQ。价格复用 getModelCatalogPricing，保持 USD/百万 token 与当前账户/时段倍率一致；非 token 单位明确显示，动态价格标注首档且不以首档计算完整月费用。统一选定分组缺少某模型时，该列显示不可用，不退回另一个分组。图表复用 useGroupHealth 和 ModelMetricChart，最多四个权限受控查询，缺失或失败不补零。不引入没有数据来源的外部榜单评分或虚构热门对比。

体验跳转的模型和分组仅是选择意图：以 `/api/user/self/groups` 和 `/api/user/models?group=` 确认后选择，非法/不可用值给出反馈；保留现有对话，生成中或待完成工具回合不自动切换，不绕过权限，不自动计费。URL 只含 ID，不传账户、消息或密钥。

## Alternatives considered

- 固定模型栏覆盖站点导航：更像局部参考截图，但会遮挡全站操作；采用导航下方固定栏并对齐锚点。
- 对比按钮只跳到本模型分组图表：完全复用已有功能，但用户已给出跨模型对比参考，不符合新意图。
- 将完整外部对比站的数据和 30 天统计直接迁入：缺乏本站可靠来源且改变统计保留窗口；采用现有 24/72 小时真实数据，外部评分不展示。
- 根据 URL 直接写入可调用模型或自动发测试请求：能少一步，但会混淆权限和产生未经明确发送的费用；验证后仅预选。

## Consequences

固定栏高度需避免遮挡标题或侧栏。对比中所有货币/单位/分组/时间范围必须明确，不能将目录可见性当调用授权，或以不同样本口径给出绝对模型排名。仅发布，不部署生产。

待选择目标模型时，普通新消息等待选定或主动取消跳转选择；用户仍可显式完成旧模型的工具回合，避免等待模型切换与工具完成互相阻塞。
