# Agent Note: 阿里图片分类与输入输出分项计费

Status: implemented

## Problem

Wan 图片模型被视频测试家族规则拦截；Qwen 3.0 图片模型的输入图和输出图按张、按输出分辨率分档计费，而定价表单仅提供固定单价或通用表达式。用户要求完善功能及参考价，本站售价由用户填写。

## Decision

复用现有 tiered_bundle、资金预留和图片数量结算，提供可往返编辑的 Qwen 图片输入/输出表单。官方人民币参考价独立展示且不写入售价。表达式的 `_image_billing` 是服务端根据转换及覆盖后的阿里出站请求生成的私有计费视图；调用者无法伪造。自动尺寸按两档最大费用预留，按上游返回的实际图片计量结算；缺失计量不报成功。仅支持已核实的阿里 Qwen 3.0 协议，其他渠道明确拒绝该模板。

前后端共用语义：已知 Wan 图片任务从保守视频家族匹配中排除，显式视频端点、专用视频渠道、映射为视频仍受保护。补齐图片端点发现、Qwen 3.0/Wan 2.7 同步端点及输入图保真。

## Related decisions

检索结果：[视频免费预检](../../implemented/feature/2026-10-21-video-free-preflight.md)部分重叠，继续保留无付费视频测试的边界；[视频定价提案](../../proposed/feature/2026-10-21-video-pricing-and-testing.md)仍为视频独立提案，不在本次实施。未发现现有输入/输出按张定价笔记。

## Alternatives considered

- 仅展示输入输出字段：改动小，但没有实际结算契约会造成错扣，因此前后端一并实现。
- 新建独立价格存储和扣费引擎：结构直接，但重复已有原子配置、分组及时段倍率、资金预留能力；采用现有表达式引擎并为图片提供专门表单。
- 按官方人民币价格自动换汇写售价：可以立即测试，但不符合用户明确保留售价决定权的要求。

## Verification

Wan image/t2i/i2i 与真实视频分类回归；输入输出单价空值不能当零、零价可显式填写、保存后能重开编辑；官方参考价注明地域/币种/来源，不修改线上配置；出站计数、分辨率、参数覆盖、重试、部分返回和伪造字段回归；Go 回归与模拟上游覆盖正式预留/结算及渠道真实测试路径；浏览器使用拦截 API 验证保存、重开、零价、缺价、目录分组价和桌面/窄屏。构建与发布独立检查，不部署生产或执行真实付费生图。

## Consequences

自动尺寸依赖成功响应的计量字段，缺失需报错，不能以预估价冒充实际用量。模板首期限定阿里 Qwen 3.0，Wan/Z 保持输出按张固定价及原有提示词改写倍率。发布不等于线上生效。
