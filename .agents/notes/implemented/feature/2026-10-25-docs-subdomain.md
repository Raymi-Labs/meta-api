# Agent Note: 独立文档域名与统一阅读入口

Status: implemented

## Problem

平台已有十三篇教程、十七种正文语言及动态模型样例，但文档仍嵌在控制台壳中。用户希望参考 AIHubMix 文档阅读结构，使用已确认的 docs.meta-api.vip 独立入口。

## Decision

复用自有 Markdown、翻译、运行时样例和渲染器，抽出可共享的文档目录与搜索逻辑。主站 /docs 保持兼容，独立入口使用单独 Vite 构建，不包含控制台路由或账户恢复。三栏阅读、独立滚动目录、搜索和前后篇导航在两个入口复用。跨域链接显式携带合法语言码，不共享认证 Cookie 或用户缓存。

独立站仅允许读取公开 status/pricing，剥离 Cookie、Authorization 和 New-API-User；拒绝其余 API 和非 GET/HEAD 请求。API 示例回退主站而非文档域名。站点部署独立目录与虚拟主机；先验证站点再切换文档入口，不更新业务应用容器或数据库。

## Related decisions

- 部分重叠：[动态文档](../../implemented/feature/2026-10-12-runtime-documentation.md)，保留主站身份过滤；独立站固定公开身份。
- 部分重叠：[全站语言](../../implemented/feature/2026-10-25-site-language.md)，复用资源，跨源只传语言，不传账户。

- 反代迁移、公开首页、政策、客户端错误排查及视频计费笔记不属于本次决定，保持不变。

## Alternatives considered

- 全站镜像参考文档会把其专有功能、账户流程和接口承诺带进本站，且没有可复用授权证据；仅参考布局，自有内容为准。
- 直接将整个业务应用反代到文档域名会扩大账户/API 暴露面，并使两个域名的登录状态和链接混乱，改用独立静态构建与两个公开只读端点。
- 另建一套文档框架需要复制十七语言与动态样例维护逻辑，现有渲染器已满足内容要求，优先共享。

## Testing

文档路由/搜索/链接/匿名请求七项、动态样例七项、导航十六项、全站语言及发布十三项回归通过；主站和独立站构建通过。Chrome 验证旧路由与独立深链刷新、正文搜索、复制、中文/日文切换、390 像素手机侧栏和暗色；失败时保留教程及主站 API 基地址，刷新恢复动态样例。DNS、证书与线上部署单独记录在发布验收中，不能由本地测试推定上线。

## Consequences

参考站内容多于本站当前教程，迁移只覆盖已验证的自有内容。公开目录不等同于某个登录账户或令牌的可用模型。DNS/证书需实际控制面验证，不能将本地预览或发布包当作上线。
