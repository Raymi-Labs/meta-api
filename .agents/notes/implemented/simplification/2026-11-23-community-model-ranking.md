# Agent Note: 模型广场直接链接社区模型榜

Status: implemented

## Problem

社区已有模型评分榜；在网关重复制作榜单，会让用户难以分清社区评分、外部评测和本站用量。

## Decision

在模型广场标题区保留 API 文档，旁边只增加一个社区模型榜链接。点击在新标签页打开固定的公开地址；不传筛选、模型、用户信息或来源页，不新增网关接口。

## Alternatives considered

- 撤回未发布的发现页、周用量聚合、第三方评测同步和本地榜单。它们不是跳转社区所必需的数据链路。
- 不内嵌社区页面，也不复制社区分数。排名更新由社区负责，社区不可用时不影响广场筛选和比价。

## Verification

匿名浏览器打开社区页面并读取到「模型评分榜」与实际综合榜条目。广场浏览器回归验证唯一外链、独立标签与不传来源、原文档入口、17 种语言、390px 宽度和原筛选流程；本地目录筛选 10 项及价格币种回归通过。未部署，也未请求任何模型服务。

## Consequences

广场不依赖社区响应即可加载，用户保留当前筛选。评分的来源和时效以社区页面为准；社区路径变更需要更新此外链。未发布的发现路由无需兼容跳转。
