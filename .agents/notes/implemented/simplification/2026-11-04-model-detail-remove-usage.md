# Agent Note: 移除模型详情分组用量模块

Status: implemented

## Problem

用户要求直接移除模型广场中的分组用量模块。该模块实际位于模型独立详情，既展示本站分组用量，也在缺少本站记录时切换为模型用量参考；两种状态属于同一展示入口。

## Decision

移除 ModelAnalytics 的用量区块、指标与天数选择、参考状态回调，以及详情目录中的对应项和专用切换样式。快速开始紧接性能对比。保留性能图、分组价格、共享健康接口及底层用量数据，避免把页面简化扩大为统计或 API 契约删除。

## Existing notes audit

- [空图参考](../../implemented/feature/2026-11-01-model-chart-reference.md)：部分取代用量展示决定，性能参考与后端数据契约继续有效。
- [详情接入顺序](../../implemented/feature/2026-10-29-model-detail-log-view.md)：部分取代快速开始紧接分组用量的顺序，其余详情与日志展示约束保留。
- [独立详情](../../implemented/feature/2026-10-25-model-detail-page.md)：部分重叠，沿用路由、可见性、返回状态和目录滚动机制。
- [P50补充](../../implemented/feature/2026-11-01-openrouter-performance-p50.md)：性能补值不受影响。

## Alternatives considered

- 仅隐藏本站分组图可以保留全网用量参考，但空数据模型仍显示同一用量模块，不符合直接移除的要求。
- 同时删除后端用量字段可减少数据读取，但会改变共享健康接口契约；本次限定页面展示范围。

## Verification

既有两套浏览器回归通过：本站记录和外部参考两种响应下均没有用量模块/目录入口，快速开始紧接性能对比；性能展示、桌面及390px手机深色布局保持可用，普通用户与管理员关联日志入口回归通过。10项导航、路由权限、性能与图表测试及 ESLint、Prettier 通过。前端完整构建、语言资源检查、五个公开页面 Chrome 预渲染、笔记校验和发布策略门禁通过。

## Consequences

原用量图不可再从模型详情访问；共享接口仍可返回用量数据，不影响日志、计费或权限，无数据库迁移。
