# Agent Note: 侧栏聊天复用站内模型体验

Status: implemented

## Problem

侧栏聊天来自 Chats 外部网站目录，空配置时父项没有跳转目标；现有模型体验已提供站内聊天，用户要求用自己的聊天替换旧入口。

## Decision

保留 chat.chat 配置键和现有权限开关，将侧栏项命名为模型体验并直达 /playground，移除侧栏对旧 Chats 缓存的解析和外部子菜单。侧栏、管理员及个人侧栏配置的分组均称「创作空间」，下列「元衡生图」「模型体验」。不再展示聊天会话管理说明。复用现有登录与工作台，不修改模型调用、会话、计费。旧 /console/chat/:id、Chats 配置、客户端接入保留兼容，本次只替换用户侧栏入口。

## Existing decisions

[统一企业导航](../../implemented/feature/2026-10-25-enterprise-navigation.md)对模型体验仅保留顶栏的决定在本次用户要求下部分替代；/playground 公开壳与登录回跳继续复用。[企业服务入口](../../implemented/feature/2026-11-13-enterprise-services-entry.md)与此次入口部分相关，业务内容不变。侧栏对齐回归复用真实页面检查。

## Alternatives considered

- 新增另一聊天页：重复工作台及会话能力，维护成本高，不采用。
- 继续外部子菜单：依赖配置且入口模糊，不能满足直接聊天，不采用。
- 同时删除全部旧路由及配置：会影响书签和客户端集成，超出侧栏替换需要，不采用。

## Verification

生产 Vite 构建通过；真实 Chrome 使用隔离合成 API 验证1440px管理员明暗、390px普通用户明暗、1440px关闭入口共五种情况，验证模型体验直达 /playground 并出现输入框、旧外部子菜单移除、配置隐藏、键盘激活、折叠与原日志导航。顶栏6项回归与ESLint通过，机械界面检测无发现，桌面与手机截图已查看。没有发送模型请求。开发预览遇到既有工作台锁提示，故浏览器回归明确使用生产构建；不修改会话锁实现。

## Consequences

同一功能增加侧栏快捷入口，与顶栏指向同一路由；模块开关仅控制展示，权限仍由原路由与后端负责。旧配置入口仍保留但不再驱动侧栏。
