# Agent Note: 移除渠道采购成本倍率与故障域

Status: implemented

## Problem

渠道设置里的 `route_purchase_ratio`（采购成本倍率）与 `route_fault_domain`（故障域）是为「健康相近时选最便宜线路」和已撤回的路由方案准备的。[有序健康选路](../feature/2026-11-07-ordered-health-routing.md)改为尊重管理员设置的优先级和权重后，这两个字段只在线路观测中展示，不参与选路和计费；线上也没有渠道填写采购成本倍率。保留它们会让管理员误以为填写后会影响路由。

## Decision

删除两个字段：`dto.ChannelSettings` 中的定义、渠道编辑页「高级设置」里的两个输入项、线路观测「渠道逐次尝试」表的两列、影子候选与观测接口中的对应字段，以及只供它们使用的 6 条界面文案（17 种语言）。渠道编辑页恢复为加入智能路由之前的版本。

已保存在渠道 `setting` JSON 中的旧值不主动清理：后端解析会忽略未知键；前端编辑渠道时按原 setting 合并，不会因此报错。想让低成本渠道多接流量，继续使用渠道优先级与权重。

## Alternatives considered

- 只保留故障域：它是以后做「供应商整体故障检测与告警」「换组时避开同一供应商」的基础，但这些功能尚未计划；在功能出现前它同样只是展示。需要时重新加入的成本很低。
- 继续保留为只读展示：改动最少，但界面上多出两项没有作用的配置，与项目「保持简单」的方向相反。

## Consequences

收益：渠道配置与观测页去掉无效项，路由只受优先级、权重和健康状况影响，语义更清晰。

代价：若以后要做按供应商的故障检测或成本统计，需要重新设计并加入相应字段。

## Verification
