# Agent Note: 模型卡片只保留浏览摘要

Status: implemented

## Problem

卡片重复展示详情页已有的协议、厂商计费类型、阶梯提示和缓存分项，增加浏览高度。用户明确要求移除这些信息，只保留输入与输出等核心价格，完整信息通过点击卡片进入详情查看。

## Decision

只调整 PricingCardView 的呈现，继续复用 getModelCatalogPricing 计算全部价格，使用已有 isCachePriceItem 分类从卡片过滤普通/动态/TTL 缓存项，并去掉单列时间倍率提示。普通文本卡片保留输入与输出价格；图片、音频、按次与按时模型保留真实输入输出或对应计费单位，不套用文本单价。移除卡片协议组件、厂商/计费副行及阶梯说明。名称、图标、复制、选择、详情导航、介绍、标签和性能保持现有行为。

表格、详情、协议筛选、计费数据及缓存计算保持现状；显示设置中显式开启的倍率信息继续有效。

## Existing notes audit

- [缓存价格一致性](../bug-fix/2026-10-28-catalog-cache-prices.md)：部分取代卡片展示所有价格的决定，保留正确字段、支持标记、零值语义及详情分类。
- [协议声明与示例](../feature/2026-10-28-model-protocol-display.md)：部分取代卡片可见协议入口，保留列表、详情快速开始、声明与未声明边界。
- [目录浏览](../feature/2026-10-25-model-catalog.md)、[参考布局](../feature/2026-10-26-reference-layout-alignment.md)：部分重叠，仅收窄卡片信息。
- 官方参考价/分组优惠、官方同步/Kimi 补齐、视频预检、模型体验与日志、看板指标笔记：数据或其他页面规则，不属于本次移除范围。

## Alternatives considered

- 修改共享价格 helper，可让卡片直接得到两项，但会同时影响详情和其他调用者的缓存价格；因此只过滤卡片呈现。
- 用名称包含 cache 判断更短，但此前已造成普通和动态价格不一致；复用明确的 isCachePriceItem 分类。
- 仅用 CSS 隐藏会保留重复 DOM 和组件计算；直接删除卡片渲染节点及失效样式。

## Testing

- 缓存计算、协议声明、详情导航、表格分页、四类筛选和币种共31项相关回归通过。
- 更新既有 protocol browser 流程，使用真实页面与合成只读 API：普通及动态卡片均仅显示输入/输出，精确金额保留；点击卡片后普通缓存读/写/1h价格仍存在，协议切换与复制正常；表格保留协议，声明筛选仍只计算真实支持。复制与选择不跳转；1440px浅色和390px深色均通过，无页面错误、写请求或横向溢出。
- `bun run --cwd web build` 完成36项语言/正文验证、生图构建、主站构建及5个公开页面预渲染。保留既有第三方 eval、大包和 Browserslist 警告。
- `bun scripts/release/check-policy.mjs`、`make verify-notes`、格式与差异检查通过。

## Consequences

目录不再直接展示缓存优惠与协议，需要多一次点击查看详情。该取舍提升浏览密度，不表示模型不支持缓存或未声明协议已可用；不修改配置、数据或生产部署。
