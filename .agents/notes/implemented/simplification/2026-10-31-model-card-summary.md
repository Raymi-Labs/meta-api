# Agent Note: 模型卡片只保留浏览摘要

Status: implemented

## Problem

卡片重复展示详情页已有的协议、厂商计费类型、阶梯提示和缓存分项，增加浏览高度。用户明确要求移除这些信息，只保留输入与输出等核心价格，完整信息通过点击卡片进入详情查看。

## Decision

只调整 PricingCardView 的呈现，继续复用 getModelCatalogPricing 计算全部价格，使用已有 isCachePriceItem 分类从卡片过滤普通/动态/TTL 缓存项，并去掉单列时间倍率提示。普通文本卡片保留输入与输出价格；标签简写为“输入/输出”，配文件入站/出站箭头图标，与金额同行，Token 单位以 /M 或 /K 简写并保留完整单位提示；价格项等宽两列，图标、标签、金额和单位统一行高并垂直居中，标题与复制/选择操作对齐；性能标签与数值分行对齐。图片、音频、按次与按时模型保留真实输入输出或对应计费单位，不套用文本单价。移除卡片协议组件、厂商/计费副行及阶梯说明。名称、图标、复制、选择、详情导航、介绍和标签保持现有行为。性能值保持现有取值与格式，首字均值仅移除行内“沿用最近有效值”注释，悬停 title 继续提供来源时间。

普通及动态首档输入/输出、已有原始单价的按次/按时价格在卡片中用原始换算金额四舍五入为两位小数，避免由已舍入字符串再次舍入；悬停保留原始单价。非零价格若会舍入为 0.00 则显示小于 0.01（保留对应币种），实际零价仍显示 0.00；倍率和参数型价格不按金额误处理。

表格、详情、协议筛选、计费数据及缓存计算保持现状；显示设置中显式开启的倍率信息继续有效。

## Alternatives considered

- 修改共享价格 helper，可让卡片直接得到两项，但会同时影响详情和其他调用者的缓存价格；因此只过滤卡片呈现。
- 用名称包含 cache 判断更短，但此前已造成普通和动态价格不一致；复用明确的 isCachePriceItem 分类。
- 仅用 CSS 隐藏会保留重复 DOM 和组件计算；直接删除卡片渲染节点及失效样式。

## Consequences

目录不再直接展示缓存优惠与协议，需要多一次点击查看详情。该取舍提升浏览密度，不表示模型不支持缓存或未声明协议已可用；不修改配置、数据或生产部署。
