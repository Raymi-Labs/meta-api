# Agent Note: 移除看板覆盖率与常驻统计说明

Status: implemented

## Problem

用户要求删除缓存命中率、综合单价卡片的“部分记录 / 记录覆盖 / 排除条数”，以及卡片下方保留日志和未知用量说明。现有说明占据概览空间，本轮目标是精简展示。

## Decision

直接移除共用看板组件中的覆盖率行和常驻说明段，清理专用格式函数、样式与翻译。保留服务端有效子集统计、覆盖计数字段、前端响应校验、卡片数值与已有指标定义悬停提示。普通用户与管理员共用修改，不新增请求或配置。

## Existing notes audit

- [独立指标覆盖](../../implemented/bug-fix/2026-11-04-dashboard-partial-metrics.md)部分重叠：本篇取代其可见覆盖标注，保留计算、字段校验和紧凑数字决定。
- [统一结算日志](../../implemented/bug-fix/2026-11-03-dashboard-settlement-statistics.md)部分重叠：本篇移除其常驻说明，保留数据来源、结算与权限边界。
- [模型测试排除](../../implemented/bug-fix/2026-11-04-cache-rate-exclude-model-tests.md)的筛选规则继续适用；只同步展示事实。
- 检索命中的上游现金收益、厂家价格来源与官方价覆盖笔记不涉及看板文案，无关。

## Alternatives considered

- 将原文移入悬停可保留解释，但用户明确要求去掉这些文案，因此直接移除。
- 连同后端覆盖字段删除可减少响应字段，但会改变已验证的响应契约，且与界面精简无关，因此保留。

## Verification

16项前端回归、36项语言资源检查、生图与主站生产构建通过。普通用户1440px桌面与管理员390px窄屏隔离浏览器流程通过，完整、部分和未知用量均不显示指定文案；单价6.8291、缓存率81.1%、紧凑Token完整提示、负净消费、旧响应拒绝和迟到响应隔离保持。公开五页使用本地Chrome完成预渲染，未访问生产或付费模型。

## Consequences

概览不再直接说明子集的记录覆盖程度，不能据此声称结果覆盖完整历史。后端仍保留可核实子集与计数，后续专门分析需求可复用；本轮不调整生产数据或部署。
