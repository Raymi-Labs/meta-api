# Agent Note: 企业级其余型号按原厂分项价格校准

Status: implemented

## Problem

八型号纠正后的全量审计发现旧价残留、美元漏换算、缓存比例和条件档位偏差。用户要求处理审计发现，并明确排除 k3、kimi-k2.8、kimi-k2.8-code。206 个企业级型号并非全部具备原厂价证据，不能将缺少元数据的型号推测为正确或统一重定价。

## Decision

复用普通倍率、固定图片单价和请求表达式。美元分项乘33换算能量，原厂人民币分项乘5；充值0.2元/能量、分组和时段规则保持。按官方来源逐项修正已确认文本、图片和视频价格，补 Grok 200k、MiniMax 512k、GLM 32k 边界、Qwen Plus 思考模式，按公开优惠修正 Qwen3.7 Plus 和 Wan3.0。缓存按原厂标准单价与显式/隐式模式区分；活动无明确终止日，不编造自动恢复时间。Kimi 默认缓存写入按输入价，不声称上游已提供所有 TTL 用量。视频本次纠正输出秒价；上游输入媒体附加计量不能以输出时长推测。

复用 root options API 和原子 tiered_bundle，先完整表达式承接普通型号，再同步不生效的倍率，最后恢复普通路径；固定图片仅原子更新 ModelPrice 两项。每步重读核对目标旧值、保留非目标键；私有快照和失败日志支持仅目标恢复。不更新程序、不停服、不修改渠道或上游限价。全局基础单价适用于这些名称的所有分组。

Z-Image 沿用 Ali 图像路径已有的 prompt_extend 两倍和数量/重试逻辑；实际路径核验通过，撤回上一轮漏算两倍的审计结论。GLM 使用国内官方来源，不将 Z.AI 国际美元价套入国内档位。

## Alternatives considered

- 全部按旧价乘统一系数：简单，但无法解决不同输出比、缓存、思考模式及分辨率的独立偏差。
- 套用国际 GLM 或猜测 Kimi 别名：可以凑齐价格，但型号与地域证据不足；GLM 改用国内官方来源，三个别名按用户要求排除。
- 新增应用计费机制并发布：可拓展更多输入媒体语义，但本次已确认单价和条件档位可复用既有配置，避免把配置修正变成没有真实用量来源的计量改造。

## Verification

29个精确名称通过7次管理API写入并读回；codex-auto-review按既有gpt-5.3-codex别名同步，共30个可见名称受影响。独立全目录比较确认194个其他名称逐字段不变，三项用户排除名称和前次八项均保持。分组、充值和渠道摘要保持，生产仍为v1.12.1。

59136项实际价格/用量/表达式检查、357项前端检查、96项图片预扣/数量/重试检查和关联回归通过。26条真实短请求中19条成功，日志和令牌扣费一致；三个Grok无可用渠道、两个Qwen Plus名称两种模式共4条上游响应解析错误，7次均无消费、临时令牌全部删除。8个视频分辨率档位通过生产本地实际适配预估，无付费生成。缓存命中、长上下文和图像/视频上游完成未做付费实测。

首次目录读回受一分钟缓存影响，等待其正常刷新后本地与外部目录一致。初始非目标哈希差异来自继承别名，原始报告保留并补194项逐字段核对。三条Claude OpenRouter Chat初次验收误用原生Messages截断；按实际Chat路径四舍五入复算原日志和已删除令牌记录全部一致，不重复请求、不修改账单。

[配置说明](../../../../docs/channel/enterprise-price-alignment.md)、[审计JSON](../../../../docs/channel/enterprise-price-alignment-audit-2026-11-01.json)保存精确来源和前后配置。服务器私有目录保存操作、原始失败和修正后的验证资料；仓库仅保存脱敏证据。

## Consequences

旧倍乘基准与货币漏换算已纠正，Qwen思考/缓存、Grok与MiniMax长档、GLM边界和视频分辨率均有明确表达式。全局基础价影响这些名称的所有分组，既有分组与时段规则保留。公开优惠没有明确截止日，因此不编造自动恢复任务；Qwen缓存按原厂标准输入价基准，优惠仅调整有公开依据的输入输出项。

价格不回溯历史账单；在途请求使用快照。普通型号桥接期间取整最多差1 quota。固定图价和输出秒价不自动覆盖输入媒体附加计量；Kimi非Claude用量未建立独立1h分区证据。剩余无官方参考的型号不被推定正确。Z-Image沿用既有改写两倍逻辑，经检查撤回先前“缺失两倍”的推测。五个型号价格配置已校验，但当前渠道失败使真实推理/扣费验收未完成；保留失败，不把配置通过等同于上游可用。

仅生产配置和文档更新，没有应用发布内容，不创建版本或Release。
