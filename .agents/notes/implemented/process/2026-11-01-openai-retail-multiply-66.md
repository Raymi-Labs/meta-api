# Agent Note: OpenAI 全部已配置模型现价乘 6.6

Status: implemented

## Problem

用户要求 GPT 当前价格乘 6.6，并明确选择 OpenAI 全部模型，含 o 系列、独立 Codex、Sora、Whisper 等。生产同时存在普通倍率、按次价、272k 阶梯和 Codex 共享计费别名，单独改 GPT 文本基础倍率会遗漏当前收费路径。

## Decision

按现有厂商元数据与明确 OpenAI 型号族核对配置键，不把 360gpt 等其他厂商误归入。处理 49 个有价格来源的名称：30 个 ModelRatio、10 个 ModelPrice、8 个阶梯表达式，另一个 codex-auto-review 自动继承 gpt-5.3-codex。包括大小写/空白历史配置键，不顺手改名。12 个当前启用型号全部覆盖。

每个普通型号只将基础倍率乘 6.6，输出、缓存、图像、音频相对倍率保持，避免重复乘倍。按次价直接乘 6.6，原有数量/分辨率/时长计算方式保持；阶梯仅乘 8 套表达式中的货币系数，272000 条件、标签、模式不变，通过原 tiered_bundle 原子发布。没有当前基础价/启用渠道的 o 系列、Whisper 等不补造现价；相对倍率不是独立售价。

复用 options 管理 API、生产快照、预期旧值保护与按实际写入字段回退。保留官方参考价、独立工具调用费、分组/用户/时间倍率、充值价、其他厂商、路由和所有渠道。用户要求模型单价，不修改共享工具默认价或程序中的工具生图价格，避免波及 Claude/Gemini。

## Existing notes audit

- [Claude 现价调整](../../implemented/process/2026-11-01-claude-retail-multiply-66.md)：部分重叠，复用逐项倍乘与原模式保留；本次另外覆盖按次、图片/视频和别名继承，不修改其既有价格。
- [官方参考价](../../implemented/feature/2026-10-30-model-official-pricing.md)、[官方同步](../../implemented/feature/2026-10-31-official-pricing-sync.md)：独立展示元数据不变，不将站内售价当成官方价。
- [目录补齐](../../implemented/feature/2026-10-31-model-catalog-reconciliation.md)：厂商归属和启用能力用于核对，不自动增加渠道或型号。
- 命中的供应商过渡与上游安全笔记无销售定价规则变更。

## Alternatives considered

- 只按 gpt 前缀改动最少，但用户明确扩大到全部 OpenAI；使用厂商与型号族交叉核对，包含已配置 Sora、DALL·E、旧 GPT 文本和 Codex。
- 为未定价 o/Whisper 补默认 37.5 再放大可以造出数字，但这些名称没有正在使用的售价，改变可用性超出当前价倍乘；保留未定价状态。
- 全部转成表达式可一次切换，但改变按次/数量计费与普通日志语义；保持现有模式并按完整选项图更新。

## Verification

49 个名称和 12 个在用目录读回一致；1050 项实际 Go 计费检查、8 套前端表达式解析、相关后端和前端展示测试通过。4 类真实调用（普通 GPT、阶梯 GPT、Codex 别名、图片固定价）均返回内容，实际日志与令牌单笔扣费一致，文本覆盖缓存。前两次 Codex 测试令牌缺少归一化后的权限名称，403 且零消费；修正测试限制后成功，6 个临时令牌全删除。

写入完成时其他选项和渠道摘要一致；最终复核有同期外部分组倍率/渠道分组更新，本任务未写这些字段，也不回滚。目标价格、非分组选项和官方元数据最终匹配。按每条请求冻结的组倍率核算，不将最终分组账单描述为统一 6.6 倍。

## Consequences

其中5个旧型号的价格决定已由[按官方价修正](2026-11-01-retail-official-correction.md)部分取代；新记录按官方USD×33重建输入、输出、缓存及适用长档，其他范围和本篇历史验收记录保留。

整数 quota 的既有舍入规则保留，单笔旧整数费用乘 6.6 不一定等于新单价结算后的整数。部分历史名称和非在用语音/视频无法做真实调用；不擅自启用或重新定价。短测试不证明所有上游能力，历史账单不追溯修改。
