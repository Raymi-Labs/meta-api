# Agent Note: OpenRouter 渠道迁移到用户当前账号

Status: implemented

## Problem

既有厂商接入复用了旧渠道 1461 的 OpenRouter 密钥，Gemini 1638 也沿用该密钥。它与用户当前浏览器账号的密钥并不相同：旧账号有实际调用记录，但 Gemini 最小请求返回提供商服务条款 403；当前账号已充值 50 美元，浏览器 Gemini 2.5 Flash Lite 已实际返回 OK。API 路由元数据表明旧请求尚未选中服务商，现有错误不足以认定具体账号、地区或提供商条款原因。

## Decision

用户明确要求所有渠道切到当前账号。复用现有管理员渠道更新接口，只替换经核实的 47 个 OpenRouter 渠道密钥（含已暂停的旧渠道 1461）；类型、模型、映射、分组、限价、启停状态与其他配置在凭据迁移阶段保持不变。使用专用密钥，消费总限额和有效期与旧密钥一致（250 美元、不重置、无到期时间），不修改账号自动充值、隐私或风控规则。新密钥只交给当前生产网关，不入 Git、输出或本地清单。

先保留生产私有快照与旧凭据，验证当前账号新凭据可用，再逐渠道通过 API 写入并读回。1638 恢复须另行通过原厂价格复核、实际请求、语音 usage 和消费验收；旧账号返回 403 的具体原因仍未知，不把账号迁移解释为解除旧账号限制。

实际新账号 3 个 TTS 和 1 个 STT 都返回 200，TTS 的 generation 用量延迟约 6–16 秒可查，暴露当前仅 4 次、总计至多 8 秒查询会提前失败。复用现有只查询元数据的等待路径，将总上限调整为 60 秒、单次查询 8 秒、间隔最多 2 秒，仍禁止重发语音或估算 Token，客户端取消立即结束。适配修复随正式版走受保护更新后，再验收真实结算。

## Existing notes audit

- [厂商接入](../../implemented/feature/2026-10-31-openrouter-vendor-onboarding.md)：部分取代；本篇承接旧密钥到用户当前账号的明确迁移，不改变厂商分组和未审核模型暂停规则。
- [Gemini 语音](../../implemented/feature/2026-11-01-openrouter-gemini-audio-pricing.md)：部分重叠；原 403 证据属于旧密钥，恢复要求和真实计量条件继续适用。
- [原厂限价](../../implemented/feature/2026-11-01-openrouter-price-routing.md)：复用；凭据迁移不能清空参数覆盖或启用未通过审核的型号。

## Alternatives considered

- 在当前浏览器账号调整隐私或提供商黑名单：页面未显示相关禁用，且该账号并非旧生产密钥的账号，无法据此修复旧密钥的 403。
- 继续使用旧密钥：其他模型可用，但不符合用户明确要求全部切换到当前已充值账号。
- 直接统一启用所有渠道：操作少，但会误启用没有原厂报价或上游超价的模型，必须保留原暂停状态，按验收结果单独恢复 Gemini。

## Verification

47 个目标渠道逐一写入并读回同一新密钥，生产密钥 SHA256 与浏览器新建专用密钥标识匹配。迁移阶段 21 启用、26 暂停及其他静态配置保持，原值保存在生产权限 0700 的私有目录。新密钥直接调用 Gemini 和 Inception 均为 200；23 个 Gemini 候选最新报价复核通过，19 个非语音型号均实际返回文本、图像或向量，3 个 TTS 返回 PCM 与原生 Token，STT 返回 Hello.、29 输入及 2 输出 Token。密钥不出现在公开输出、Git 或本地清单中。

TTS 实际用量在音频返回后约 6–16 秒可查，暴露旧 4 次、至多 8 秒的查询过早失败。现有元数据查询总上限扩展到 60 秒，单次限 8 秒、间隔至多 2 秒；客户端取消中止，不重发语音、不估算 Token。延迟超过旧次数和等待中取消回归、相关控制器计费测试及 Go 构建通过。应用发布与生产恢复分别验证。v1.11.12 已通过受保护更新上线，1638 恢复 23 个审核型号，其他 46 渠道静态配置保持；11 个网关代表请求的真实用量、单笔消费和令牌扣费一致，后台默认测试通过，临时令牌全部删除。操作证据和恢复位置见[最终验收](../../../../docs/channel/openrouter-gemini.md#当前账号最终验收2026-11-01)。

## Consequences

新账号与旧账号的模型权限、隐私规则或余额不同，单次浏览器成功不能证明所有 API 和语音路径可用。无价格证据的模型继续暂停。旧密钥保留在生产私有恢复材料中，不自动删除账号里的旧凭据。
