# Agent Note: Claude 当前站内价格统一乘 6.6

Status: implemented

## Problem

用户要求 Claude 模型价格按当前价格乘 6.6。生产同时存在普通倍率、Haiku 5.5 的 100k 阶梯表达式，以及三个在用但未单独配置基础价格的旧别名；仅改显式倍率会遗漏阶梯和当前目录展示的默认价。

## Decision

复用根管理员 options API 与 tiered_bundle。23 个现存 Claude ModelRatio 条目乘 6.6，三个在用旧别名以当前目录及后端共同使用的 37.5 默认倍率为基线明确配置为 247.5；Haiku 5.5 两档的五个货币系数乘 6.6，100000 阈值不变，共 27 名称、14 个在用。仅有历史缓存配置但没有基础价格/渠道的名称不补造价格。

每个普通型号只调整基础倍率，输出、缓存读取、5m 写入和派生 1h 相对倍率保持，避免重复放大。普通模式保持原有取整和缓存语义；阶梯保持原模式，通过原子 bundle 发布。保留分组、充值价、官方参考价、其他厂商与所有渠道配置。私有服务器操作目录保存快照、逐项前后值、执行回执；写入前比对原值，失败仅恢复本次已写项目，防止重复乘倍。

## Existing notes audit

- [Claude 缓存一致性](../../implemented/bug-fix/2026-10-08-claude-cache-billing-consistency.md)：部分重叠，复用普通倍率与 TTL 语义，不改变协议或结算规则。
- [Gemini 调价](../../implemented/process/2026-11-01-gemini-retail-fixed-666.md)：复用在线快照与管理 API 的操作方法；本次基准是当前站内价，不取代其官方价公式。
- [官方默认属性](../../implemented/feature/2026-10-31-model-official-defaults.md)、[目录补齐](../../implemented/feature/2026-10-31-model-catalog-reconciliation.md)：官方参考元数据与目录归属独立，不改。
- 其他命中的跨协议缓存、DeepSeek 与 Gemini 分组笔记不持有本次销售定价决定。

## Alternatives considered

- 所有型号统一转换表达式可一次切换，但会改变普通 Claude 的取整方式与日志模式；保留两种现有模式、各自原子发布价格更小且可审核。
- 只改显式基础倍率最少，但遗漏 Haiku 阶梯和三个在用旧别名。三个别名按当前展示默认价格计算，不以不同正式型号或官方价代替；此后它们有明确价格，也不再依赖自用模式的未定价放行设置。

## Verification

生产 27 项配置、14 个在用目录读回一致，非目标价格、相对倍率、分组/充值配置和渠道静态摘要与快照一致。实际 Go 计费引擎的 522 项核验通过，覆盖普通及阶梯、缓存读/5m/1h/未细分、分组倍率、99999/100000/100001 边界。相关后端回归与实际前端表达式提取、缓存公式、阶梯展示检查通过。

调价后的 4 条实际成功消费记录已只读复算，涉及 Opus 5、Opus 5.5 和 Sonnet 5.5；新基础倍率 99/66/33 生效，输入/输出及实际分组倍率一致，其中一条包含 31951 个缓存写入 Token，4 条 quota 全部匹配。

主动测试请求有限制：首次顶级华强北组不在可用组目录，令牌创建被拒绝；换用原可用组后，1427/1512 上的 Sonnet 5 和 1512 上的 Opus 5 测试均返回 403。不能把业务日志核算通过称为主动测试令牌/阶梯真实调用通过，也不能由这些测试请求推断整个渠道不可用。三个失败临时令牌均在 finally 删除，最终查询无残留，渠道静态摘要仍一致；不修改权限或上游配置以通过测试。

[操作文档](../../../../docs/channel/claude-retail-66.md)和[逐项审计](../../../../docs/channel/claude-retail-66-audit-2026-11-01.json)记录完整范围。服务器私有目录保留快照和恢复材料。仅配置与文档变更，不创建新应用版本或 Release。

## Consequences

整体价格显著提高；普通按整数截断、阶梯四舍五入，因此单笔旧整数账单乘 6.6 不一定等于按新单价结算后的整数。三个旧别名默认价偏高，但本次严格按现价计算，不改为推测的官方价。不修改历史账单或追溯扣费。
