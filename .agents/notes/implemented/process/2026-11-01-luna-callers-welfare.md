# Agent Note: Luna 调用令牌迁入福利

Status: implemented

## Problem

Luna 渠道已限定福利、优选、企业级，用户继续要求将调用 Luna 且不在这些组内的令牌统一迁入福利。保留日志中的 2800 个未删除调用令牌里，2686 个仍引用范围外分组，114 个已合规；另 46 个范围外令牌只在模型白名单配置 Luna、没有调用记录。不能用无模型限制等同于调用过，亦不能把 Lunaris 当作 Luna。

## Decision

以现有消费和失败日志的 token_id 为调用证据，涵盖 Luna 正式型号、历史名及实际请求中的 Luna 别名，排除 Lunaris。只迁移未删除且实际分组包含三个通用组之外引用的调用令牌。固定令牌主组设为福利，多组令牌将范围外的主组、groups、model_groups 引用替换为福利并按首次顺序去重，已有允许组保留。29 个多组配置中 4 个仍保留优选；模型规则键和模型白名单不变。只有配置、没有调用记录的令牌保持。

复用同 MySQL schema 临时表演练、旧值和所有者组保护的事务列更新、Redis HMAC 定向失效。仅写 group/routing_config，不写密钥、额度、用量、状态、有效期、套餐、IP、来源、用户组或渠道。2686 个目标中 215 个只有失败记录、42 个停用、66 个过期、88 个来源为 image_playground；统一迁移当前分组但不启用、不续期、不改变来源。福利对四种用户组的适用倍率均为 0.6。

## Existing notes audit

- [Luna 限定分组](../../implemented/process/2026-11-01-luna-restricted-groups.md)：此前只处理渠道并明确不迁移业务令牌；本次是用户后续授权的令牌迁移，不改变渠道限制与先前结论。
- [default 继承令牌迁入福利](../../implemented/process/2026-11-01-default-token-inheritance-welfare.md)、[Gemini 迁入福利](../../implemented/process/2026-11-01-gemini-groups-merge-welfare.md)：复用列更新、保护并发配额、同引擎演练及缓存验证。
- [多模型分组](../../implemented/feature/2026-10-27-token-model-groups.md)：同步主组和全局/逐模型路由的契约，不仅改主组而留下旧引用。
- controller/image_playground.go 会在未来刷新内部令牌时重新选组；本次迁移当前记录，不扩展成创建/刷新策略或全局强制规则。

## Alternatives considered

- 迁移所有可调用 Luna 的无限制令牌容易覆盖，但会把从未使用 Luna 的大量令牌迁走；按实际调用证据圈定。
- 只处理成功消费能确认实际使用，却遗漏用户在渠道收窄后请求失败的令牌；包含失败日志中的 Luna 请求。
- 多组令牌全部清空成单组福利实现最少，但会删除已经获准的优选路由；仅替换范围外引用。
- 本人令牌 API 无跨用户局部更新能力，全量写回可能覆盖在线消费；使用有旧值条件的路由列事务。

## Verification

同生产 MySQL 引擎/schema/排序规则的正常迁移、旧路由冲突和用户组冲突三项演练通过，保护列一致。2686 个目标的主组全部成为福利；2657 个固定组、29 个多组令牌完成事务更新，其中 4 个多组令牌仍保留优选。114 个已合规令牌的路由和密钥摘要不变，所有者组/状态和全局价格/分组选项一致；目标密钥、权限及其他非路由字段核对通过，运行中的消费计数不写回。

定向失效 10 个已有 Redis 缓存，全部目标缓存无旧组/旧路由。11 个真实迁移令牌只读 `/v1/models` 鉴权均为 200，覆盖四种用户组、固定/多组、模型白名单、Luna 逐模型规则及 image_playground 来源；缓存 Group=福利，RoutingConfig 与数据库补丁一致。带模型白名单的一个样本只允许其他模型，目录正确不包含 Luna，未为测试放开白名单。

从首次扫描开始时间前覆盖完整扫描窗口补查日志，再从日志 ID 水位增量核对；最终已知 Luna 调用令牌在三个允许组之外的引用为零。没有付费推理或重启，验收时生产自行已处于 v1.12.1，本次不执行应用发布。见[操作与边界](../../../../docs/channel/luna-token-welfare.md)及[脱敏审计](../../../../docs/channel/luna-token-welfare-audit-2026-11-01.json)。

## Consequences

迁移是整个令牌的分组调整，因此同令牌其他模型也按新分组可用性和倍率处理；模型白名单保留不保证每个模型都有福利渠道。历史账单不重算。既有停用/过期/删除用户权限保持，目录探针不代替每种模型的真实推理测试。日志留存之外的调用无法从当前数据证明；未来新建或重新配置令牌不属于本次快照迁移。
