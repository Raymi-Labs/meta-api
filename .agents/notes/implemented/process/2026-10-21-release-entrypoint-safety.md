# Agent Note: 退役临时发布入口并保护正式更新流程

Status: implemented

## Problem

2026-10-20 源站临时缓存发布脚本先停止主服务，再执行渠道 SQL；MySQL 排序规则冲突使流程在启动新容器前退出，且没有失败恢复。服务器上的脚本、SQLite 演练入口以及已禁用 timer 的旧自动更新脚本仍可被手动执行。正式 `scripts/newapi-release` 已有同一发布锁、在线备份、MySQL schema 预检及失败恢复，不应另造部署路径。

## Decision

三个已确认的旧入口备份到 root 私有目录，并以无副作用、非零退出的说明脚本替换；直接运行和 Python/Bash 调用都不能触发原逻辑。只回源到已停止演练容器的 Nginx 8443 入口停用，演练源码、数据及候选镜像保留。正常更新前要求源容器正在运行且状态接口可达，避免已经离线时继续耗时备份；回退入口保持可用于故障恢复。HUP/INT/TERM 显式转为非零退出并进入现有恢复路径，恢复期间避免同类信号再次打断。

独立临时目录和 Docker/HTTP 命令替身用于演练真实 Bash 更新/恢复流程的备份失败、预检失败、部署失败、健康失败和信号中断；不在生产制造停机。生产安装运维工具、封存旧入口并平滑 reload Nginx，应用镜像和缓存候选功能保持原状。故障回归接入路径限定的 `release-safety.yml`，后续修改发布脚本必须通过；仓库 AGENTS 明确在线备份、同引擎预检和正式发布入口边界。

## Existing notes audit

- `2026-10-17-ssh-key-only`：相邻独立决定；不调整 SSH 密钥或登录方式。
- 活跃笔记没有临时发布入口或正式更新失败恢复的归属；其他应用功能发布记录不合并。

## Alternatives considered

- 修补临时脚本的 SQL 和 try/finally：能继续上线候选功能，但会保留第二条修改生产渠道的部署路径；本次目标是消除停机风险，不是批准候选功能上线，因此退役入口。
- 增加自动拉起所有被停止容器的 watchdog：可缩短遗漏恢复的停机，但会干扰维护期间的有意停止和数据库/版本切换，故不采用。
- 只去掉执行权限：修改简单，但 `python3 script.py` 或 `bash script.sh` 仍会执行，不能防止重复事故。

## Verification

- macOS 本地和服务器 Linux 的隔离回归各11项通过，包含 HUP/INT/TERM 三种信号子用例。备份/预检失败不切换容器；切换或健康失败恢复旧镜像、Compose、发布状态；成功不回退；离线更新在拉取/备份前拒绝，离线回退可用。该测试隔离外部 Docker/HTTP，不等于生产真实故障演练。
- Bash/Python 语法、`make verify-notes`、差异检查通过。源站安装的三个说明脚本及正式工具 SHA-256 与仓库内容一致。
- 三个已退役入口在生产分别以直接执行和解释器调用验证，均返回78；先核对安装内容再调用，未执行旧脚本。Nginx 安装前后语法校验通过并平滑 reload；8443 无监听，正式入口保持正常。
- 应用、MySQL、Redis 的容器 ID、镜像、启动时间、运行状态及重启次数安装前后逐项相同。发布状态 synchronized；应用继续运行 v1.0.0-compat.48。公网 `/` 与 `/api/status` 为200/success=true，未认证 `/v1/models` 和 `/api/user/self` 为401。
- 原文件位于源站 `/root/newapi-release-safety-20261021-mCaS0G/originals/`（目录0700、文件0400），验收快照为同目录上级的 `verification.json`；缓存源码、SQLite 数据和候选镜像保留。没有更改渠道、数据库记录或 SSH 凭据。

## Consequences

离线后的同版本恢复由 [newapi-restart](2026-10-21-fast-container-restart.md) 补齐，复用同一发布锁，直接恢复既有容器；其健康判断不复用更新时的全新容器假设。

已知危险入口不再能误执行，正常更新的中断恢复有自动回归覆盖；代价是原候选流程不能直接继续，离线状态也不能通过普通更新等待备份后顺带恢复，必须先修复运行状态或使用回退。入口封存不是限制 root 的安全边界。SIGKILL、断电、Docker 卡死或不可逆数据库迁移仍不能由 shell trap 保证恢复。保留的演练源码不可在生产直接运行；未来上线候选功能须走正式流程并验证生产数据库语义。此次仅发布工具与运维规则变化，不产生应用版本或应用 Release。
