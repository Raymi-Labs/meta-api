# Agent Note: 全站 Gemini 按官方参考价乘 6.66 再乘 5

Status: implemented

## Problem

站内 Gemini 混有旧低倍率、按次图片价和前次 ECB 快照换算价。用户明确要求所有 Gemini 统一为官方美元参考价 × 6.66 × 5，并确认没有官方价的旧型号/平台别名保留原价、列为待核实。

## Decision

复用 models.official_pricing、Google 当前公开价格和既有 options 管理 API。精确型号与仅去除 google/ 的同名条目共用参考价；不推断 preview、latest、thinking 或平台别名的等价关系。跳过已排除的 batch。每百万 Token 能量价为美元价 × 33.3，按输入、输出、缓存、图像、语音和 200k 长上下文档分别计算。覆盖旧低价，已有图片按次价转为参考价的 Token 单位。

通过现有 billing_setting.tiered_bundle 原子发布表达式和模式，使多维价格同时生效且在途请求保留冻结快照；随后同步同型号基础倍率并删除被替代的按次价。复用现有表达式引擎和公开定价接口，无应用代码、数据库结构或运行版本变更。生产管理 API 写入前保存快照并逐项比对最新值，失败按本次实际写入项恢复，不能覆盖并发无关改动。

官方参考价展示、分组/用户/时间倍率、充值单价、其他厂商、渠道映射、密钥与 OpenRouter 原厂限价不变。无自动调价任务，未来促销到期需重新核价。当前元数据没有声明的附加工具、缓存存储、音频缓存分项不凭空补价或声称已经覆盖。

## Existing notes audit

- [Gemini 语音与公开汇率](../../implemented/feature/2026-11-01-openrouter-gemini-audio-pricing.md)：部分取代销售价格的公开汇率、只降不升和保留按次价选择；协议、语音核价、实际用量和上游限制保留。
- [分组官方对比](../../implemented/feature/2026-10-30-model-group-official-discount.md)：展示口径仍有效，固定销售汇率不改变独立 ECB 官方对比。
- [原厂限价](../../implemented/feature/2026-11-01-openrouter-price-routing.md)：无改变；销售价与上游限价分离。

## Alternatives considered

- 继续保留较低价与已有按次价可减少客户价格变化，但与本次明确统一公式的指令不符。
- 只更新基础倍率最简单，但会遗漏已有图像表达式和长上下文档；多次分量写入也会短暂产生混合价格，因此先用已有原子计费配置切换。
- 以正式版报价覆盖所有 preview/平台别名能减少未处理项，但无法证明型号一致；用户已选择保留原价并列出。

## Verification

生产 v1.11.12 经原管理 API 完成 38 个名称、150 个选项条目更新，其中 23 个当前在用。原子表达式切换后同步基础倍率，移除 gemini-3.1-flash-lite-image 的 1 能量固定按次项。23 项公开 pricing 模式与表达式读回一致，全部渠道静态配置、其他型号价格、分组及充值配置与写入前相同。操作材料位于生产私有 `/opt/meta-api/operations/gemini-retail-666-20261101`，包含快照、逐项前后值、执行脚本与验收回执。

复用实际计费引擎完成 504 项价格/结算检查，覆盖 38 名称、缓存/图像/语音分量、200000/200001 上下文边界和 1/0.2 分组倍率。原始成本与独立官方价 ×33.3 一致；其中 4 个恰好半 quota 的合成用例暴露现有浮点取整比十进制半入少 1 quota（0.000002 能量），按现有引擎规则记录，不将此配置操作宣称为金额取整程序修复。相关 billingexpr、billing_setting、service 测试通过，前端 tiered-billing-display 检查通过。

6 笔真实请求全部 200 且只有一条消费：3.8 Flash 的 5/85 Token 收 5370 quota，2.5 Pro 的 5/26 收 4433，向量 3/0 收 7，Flash Lite Image 的 8 输入/1120 图像输出收 559473，TTS 的 2/26 收 2614，STT 的 29/2 收 1365。每笔与独立十进制公式、消费日志及测试令牌消耗一致；全部临时令牌删除。首次验收 SSH 在 banner 阶段超时，未运行验收程序；重连后全部通过。

102 个名称/历史配置键中其余 64 项按用户确认保留（含已排除 batch），不自动推定旧 preview/平台别名。配置审计列出每项及在用渠道。仅配置和操作文档提交推送，未修改应用程序/版本，不创建新 Release。

## Consequences

固定 6.66 与独立 ECB 展示汇率可能有小幅差异；统一公式会提高旧低价。未核实型号保留旧价，不能宣称全部历史条目都已改价。上游未返回模态用量时无法验证未披露的分项；不扩展本轮的计量协议。
